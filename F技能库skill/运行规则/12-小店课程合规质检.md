# 12 · 小店课程合规质检（微信小店 · 教育培训）

> **用途**：写任何要上小店或要在直播间讲的内容之前／之后，跑一遍。
> **顺序**：平台底规 → 五道闸门 → 词表 → 话术十问 → 交付合规。四步全过才交付。
> **与 `01-合规网关` 的关系**：01 管医疗口径（疾病/功效/指标），本文管平台口径（类目/禁售/交易）。**两套叠加，取更严的那条。**

## 一、平台底规：平台到底在管什么

### 1.1 类目结构

教育培训是一级类目，下挂 8 个二级，**定向准入**（报白），不是开店就能上。

常用的二级与三级：

| 二级类目 | 三级类目（现行） | 资质档 |
|----------|------------------|--------|
| 创业理财 | 创业知识、金融科普 | 低（基础三项） |
| 生活兴趣 | 烹饪/烘培/茶酒咖啡、摄影摄像、礼仪气质、收纳技巧、人文社科、成人音乐/舞蹈/书法、时尚穿搭、美容美妆等 | 低—中 |
| 学历资格/职业技能培训 | 办公技能、自媒体运营、设计创作、IT/编程、财务/会计等 | 中（部分要讲师证） |

**已关闭的三级类目**：生活兴趣 › 其他兴趣生活、学历资格/职业技能培训 › 烹饪烘焙小吃餐饮培训（2025-01-09 起）。

**基础三项资质**（所有类目都要）：营业执照（经营范围含教育咨询/教育培训）+《产品经营说明书》+ ICP 备案或《增值电信业务经营许可证》，**三者主体必须一致**。

### 1.2 禁售九项（运营规范 2.1.2，2025-08-26 生效）

1. 赌博、封建迷信、侵权、危险品制作、医疗咨询、股票证券、偷税避税、情感咨询、精神控制、催眠、K12、**以欺诈为实的副业网赚**相关课程
2. 旅游、游学、研学课程
3. 玉石珠宝、文玩鉴定课程
4. **利用 AI 开展商业活动**或营利性模仿他人形象的课程
5. **以运营特定平台账号（视频号、抖音、小红书、淘宝等）为教学核心的自媒体运营、电商运营、变现教学课程**
6. 易影响青少年身体发育的少儿运动课程
7. **需线下交付的课程**
8. 实际成交价**低于 5 元**的不合理低价
9. 脱离教育培训属性的商品（单独卖虚拟软件、实体商品、纯娱乐影视、定金尾款等）

### 1.3 平台专属运营课的唯一出口

《类目管理规则》4.1.3 f：

> 禁止以运营具体平台账号（包括但不限于视频号、抖音、小红书、淘宝等）为教学内容的针对性自媒体运营、电商运营、直播运营、带货运营及变现等教学。**仅允许不指向具体平台的直播、短视频及自媒体相关的全平台通用型运营课程。**

→ **判定词是“不指向具体平台”+“通用型”。** 这是唯一的合法写法。

### 1.4 医疗类：另一套更重的刀

《发布违禁信息》实施细则把「**医疗课程、诊断及咨询服务**」列为**一级违规**，明确含：在线诊疗、医美、口腔治疗、基因检测、产后康复、心理咨询、问诊、针灸、整形、**减脂**、增高、疾病治疗、偏方秘方课程、**涉及食材药材课程**、保健课程、两性健康及孕产课程、**医学科普**。

> 商品信息、直播话术、客服话术、社群话术，都在抽检范围。

### 1.5 交易与交付

- 禁诱导站外／私下交易（加微信、转账、站外链接、二维码）
- 禁定金、尾款、代金券、补差价形式售卖
- 虚拟商品须付款后 **48 小时内**交付
- 「去上课」必须**直达已购课程内容**，不得跳加好友页／广告页／商品页／空白页
- 不得用小程序默认页**强制用户加企业微信**或去站外领上课链接
- 实际交付（形式、平台、课时、有效期、权益）必须与申报一致

### 1.6 商品信息规范

**标题公式**：品牌/讲师（选填）+ 人群（选填）+ **教学领域（必填）+ 主要教学形式（必填）**，≥5 字。

**主要教学形式枚举（现行）**：线上视频课 / 直播课 / 付费社群 / 读书卡·会员卡 / 题库·软件。
（线下课、训练营、付费咨询已从枚举中删除）

**后台必填参数**：适用人群、发货形式（客服激活/自动发货）、学习平台、开课形式、课程有效期（**3 个月–10 年**）、总课时、学习资料。

**主图**：≥3 张且不重复，需含课程封面、讲师资历、履约方式、有效期与退款规则。详情图 ≥1 张。

**详情页八件套**：讲师是谁 / 解决什么问题 / 完整大纲 / 怎么交付 / 适合谁不适合谁 / 价格与退款 / **不含什么** / FAQ 三条。

> **关于商品名**：名称本身只要不点名具体平台、不含数字结果与承诺，单看名称不构成违规。真正的判定看**详情页、大纲、课程内容、直播话术**——名称是壳，描述是核。

## 二、五道闸门（写内容时逐条过）

### G1 平台闸 · 禁“教某个平台怎么运营”

- **禁**：以视频号/抖音/小红书/淘宝/快手/B 站/公众号等具体平台为教学核心的运营、带货、变现实操
- **可写**：不指向具体平台的通用方法——定位、选题、结构、表达、拍摄、剪辑、发布节奏、复盘
- **判定法**：把平台名去掉，这句话还成立吗？成立 → 可写；不成立 → 这句话就是在教那个平台，删
- **注意**：平台名作为**个人经历背景**出现一次不算违规；作为**教学主线**就是违规

### G2 结果闸 · 禁收益与结果承诺

- **禁**：涨粉数、播放量、月入、多久起号、快速变现、副业刚需、网赚、兼职项目、招商加盟、分销返佣
- **禁**：包过、包会、保证爆款、稳赚、零风险
- **判定法**：这句话能不能被截图当作“你承诺了结果”的证据？能 → 删

### G3 医疗闸 · 禁疾病、指标、功效

- **禁**：疾病名、诊断、问诊、治疗、调理、改善、治愈、替代药物、降糖降压、减脂减肥瘦身、养生、食疗食养、体质、偏方秘方、食材药材的**功效**、保健课程、医学科普
- **可写**：怎么做菜、怎么买菜、三餐怎么安排、生活习惯、运动动作
- **判定法**：这句话是在说“吃了会怎样”，还是“怎么做”？说结果 → 删

### G4 AI 闸 · 禁“用 AI 赚钱”

- **禁**：AI 创业、AI 获客、AI 变现、AI 提升营业额、AI 换脸换声、AI 批量做号
- **可写**：工具安装、账号注册、本地部署、参数设置、流程演示、出错排查
- **判定法**：去掉“赚钱/获客/涨粉”三个词，这套内容还成立吗？成立 → 可写

### G5 交易闸 · 禁站外与私下

- **禁**：加微信、扫码、私信转账、站外链接、未申报的第三方平台、二维码
- **禁**：线下交付、面授、到店、场地
- **可写**：订单页客服承接、申报过的教学平台、群内教学

## 四、三产品字段速查（写内容时对照，不作判定）

| 产品 | 建议类目 | 主要教学形式 | 重点盯哪道闸门 |
|------|----------|--------------|----------------|
| ① 饮食共修付费社群 9.9 | 教育培训 › 生活兴趣 › 烹饪/烘培/茶酒咖啡 | 付费社群 | **G3 + G5 最重**（无营养/健康类目；“涉及食材药材”属违禁）；群性质须是做饭打卡群，不是健康答疑群；入群邀请只走订单页客服，不发二维码 |
| ② 个人 IP 课 49 | 教育培训 › 创业理财 › 创业知识 | 线上视频课 | **G1 + G2 最重**（详情页与大纲最易被判平台专属 / 结果承诺） |
| ③ 陪跑社群 499 | 教育培训 › 创业理财 › 创业知识 | 付费社群 | **G2 + G4 最重**；AI 只讲部署；“1v1 咨询”写“1v1 答疑” |

**类目补充**：
- ① 不能报“学历资格/职业技能培训”，也不存在营养类目；烹饪档不接受线下交付
- ① 付费社群的群规必须写死：不讨论疾病、用药、指标、体重目标；群内不发第三方链接
- ② 不要报“职业技能培训 › 自媒体运营”——要讲师证 + 劳动合同，医师资格证不在认可清单
- ③ “陪跑”不是官方教学形式，只能进商品名与权益描述，字段必须选“付费社群”

**课程有效期**：统一填 1 年（平台区间 3 个月–10 年）。付费社群课时无法预估时，可填“以实际授课时长为准”。

**课程权益可写项**（官方列举）：社群答疑、直播答疑、作业点评、1v1 答疑、打卡督学、模板资料、考试测评。
→ **“1v1 咨询”不在其中，一律改“1v1 答疑”。**

## 五、话术十问（直播稿 / 短视频 / 社群，逐条打勾）

1. 有没有把具体平台名当“教你怎么做”的主语？
2. 有没有数字结果（涨粉/播放/收入）？
3. 有没有时间承诺（多久起号、几天见效）？
4. 有没有收益暗示（月入/副业/变现）？
5. 有没有疾病、指标、功效、减脂、食疗？
6. 有没有 AI 赚钱/获客/变现？
7. 有没有加微信、扫码、私下转账、站外链接？
8. 有没有包过、保证、稳赚？
9. 有没有线下、面授、到店、咨询？
10. 讲的内容和商品页写的，是不是同一件事？

**十问全“否”才挂车。中一条，先改再挂。**

## 六、交付合规（卖出去之后照样罚）

- 付款后 48 小时内交付
- 「去上课」直达课程内容
- 不强制加企微、不引导站外领课
- 群公告写明：禁止发布第三方链接与站外交易信息
- 实际服务与申报一致（形式、平台、课时、有效期、权益）

## 七、违规后果

| 级别 | 后果 |
|------|------|
| 一级违规（医疗课程、违禁信息） | 下架商品 + 禁止上架 + 延长结算／限制提现 15 天（一般 30 天，严重至处理完毕） |
| 严重 | 永久禁止上架 + 收取违约金 + 限制提现 |
| 类目违规 | 清退类目、优选联盟清退、观察期内不得推广 |
| 造假（P 图、借资质） | 永久封店 + 关联主体拉黑 |

## 九、一句话记法

**平台禁的是“教你运营哪个平台”，没禁“教你把自己的经验讲清楚”；禁的是“吃了会怎样”，没禁“怎么做”。所有文案往“方法”和“做法”上收，别往“结果”和“疗效”上走。**
