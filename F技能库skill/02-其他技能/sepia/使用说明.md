## 一句话

两个工具合起来用：sepia 先修**结构层**（叙事架构 / 段落流 / 信息顺序），humanizer-zh 再扫**句子层**（24 条中文 AI 词句套路）。中文另加载 `references/languages/zh.md` 做校准。顺序不能反：先结构，后词句。

## 标准流程（五个模块统一）

```
稿件 → sepia review（只诊断，不改稿）
     → sepia refactor（按诊断最小改动，修结构）
     → humanizer-zh 词句扫描（24 条中文 AI 痕迹）
     → ai-detector 复核
     → 交付
```

## 四个操作（怎么选）

| 操作 | 什么时候用 | 产出 |
|:---|:---|:---|
| `write` | 从零写 | 按文体规则直接写出人味稿 |
| `review` | 只想看问题、不想改 | 缺陷清单 + 引用证据，不动稿 |
| `refactor` | 稿子框架没问题，局部有 AI 味 | 先全量诊断，再逐条最小改动（删改优先于新增） |
| `recreate` | 结构烂、重写比修便宜 | 先抽事实与意图，再整篇重写 |

**质检默认组合：`review` → `refactor`。** 不许跳过 review 直接换皮——那会把 AI 指纹改得更明显。

## 中文怎么走

1. 文体选「其他非虚构」路线（不是小说、不是新闻特稿）
2. 走 `professional-pass.md` + `style-pass.md`，跳过小说专用表
3. 目标文本是中文 → 在 style pass 那步加载 `references/languages/zh.md`
4. 简体中文内容**不套** zh.md 里的台湾标点/数字规范（那节只对繁体台湾场域生效）

## 与 humanizer-zh 的关系（双引擎）

- 两个都用，不是二选一：**sepia 修结构 → humanizer-zh 扫词句**
- sepia 负责深层：叙事架构、段落流、信息顺序、句式模板、节奏
- humanizer-zh 负责表层：24 条中文 AI 痕迹清单（AI 词汇、三段式、否定排比、填充语、通用积极结论等）
- 顺序不能反：先跑 humanizer 只改词句，sepia 再动结构，会把刚改好的句子又推倒
- 实体：humanizer-zh 在 `B自媒体大脑/01-视频号创作/创作Skill/humanizer-zh/`（`~/.claude/skills/humanizer-zh` 亦有）

## 几条硬边界（照做）

- 不编事实：数字、时间、引用必须来自原文或用户，缺就留 TODO / 问，不猜
- 尊重作者声音：张医生本来的口头禅、土味比喻、短句砸下来，不许"改正规"
- 双引擎顺序：先 sepia 后 humanizer-zh；只跑一个就交付 = 没过关
- 宁删不增：机器最爱加限定、加总结、加升华；sepia 反过来，删改优先
- 别全条规则一起上：每条只挑 3–5 个动作，全上会变成另一种机器味
- 改完念出声：念着像背稿、像公文、像颁奖 = 还有味
