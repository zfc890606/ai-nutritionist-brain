> **一句话：** 公众号贴图 = 微信用"更轻的图文"抢碎片时间的新流量入口，**发布门槛低、不依赖粉丝、算法强推**；核心打法"**窄人群 + 小主题 + 痛点-方法-行动三图 + 7 天测试**"不变，但人群从 C 端换成 B 端，主题从"怎么吃"换成"**怎么做内容**"。

## 〇、先认清战场：贴图为什么现在流量高

| 变化 | 对张医生的意义 |
|------|--------------|
| **官方战略级扶持** | 2026 把"贴图"提到与公众号、视频号并列；服务号信息流有专门版块、主页有贴图标签页、"看一看"密集推荐、"搜一搜"新增贴图号分类入口 |
| **转发即大图** | 贴图转发到聊天时以 **3:4 大图全屏**展示，天然比链接标题更抢眼 |
| **推荐机制 ≠ 订阅机制** | 贴图走"发布"而非"群发"，系统不主动推给粉丝、**主要靠算法推荐** → 零粉/低粉也有机会拿大流量（实测单篇推荐率 90%+） |
| **数据肉眼可见的好** | 首批开通流量主的贴图号创作者：贴图内容平均阅读比传统图文高 **3-5 倍**，停留时长 +40%（网络教程口径） |
| **窗口期红利** | 现在做的人少、内容供给不足、平台还在补贴期 → **普通人成本最低的公域入口之一** |
| **长尾强** | 视频 7 天没流量就死，贴图发了一个半月还在涨，可持续带阅读和转化 |

> 📌 **v2 结论：** B 端知识卡天然适合贴图——**可收藏、可截图、可转给同行**。你发的是"爆款拆解卡 / 提示词卡 / 后台数据卡"，不是食谱清单。前者吸引准伙伴，后者只吸引看客。

## 一、爆款底层：让人"看完想转发"的 5 种心理

不是图好看才爆，是**戳中一种转发动机**才爆：

| 类型 | 触发点 | 例子（B 端版） |
|:---:|------|------|
| ① 共鸣类 | "说的就是我" | "有专业、没人看"的医生 / 营养师 |
| ② 互动类 | 自带话题钩子，评论区吵起来 | "你卡在第几关"列表型 |
| ③ 利他类 | 读者想转给在乎的人 | 转给同样在做健康号的同行 |
| ④ 猎奇类 | 反常识 + 悬疑不点破 | "这条爆款，起作用的不是内容" |
| ⑤ 怀旧类 | 老物件老照片勾回忆 | 少用（B 端不适用） |

**可直接套用的 3 个结构模板：**
- **列表排序型**：按数字排档配话（"内容没人看的 5 个死因，第 3 个最致命"）
- **反转段子型**：悬念 → 误会 → 反转（"我以为缺的是文笔，其实是缺转发理由"）
- **人生感悟型**：一句金句 + 干净大图（适合身份线）

## 二、选题方法论（贴图作为"选题探针"）

### 2.1 窄人群公式（先定人群，再定主题）

> **我帮助【某类人】，在【某个场景】里，用【一种简单方法】，解决【一个小问题】。**

**B 端版示例：** 我帮助【有专业但不会做内容的医生/营养师】，在【想开始做公众号】的场景里，用【一套 AI 工作流】，解决【写了没人看】的问题。

人群越具体越有画面感。忌"做给所有人看"——那等于没人看。

### 2.2 高流量主题方向（B 端优先）

自媒体方法论 · 职场成长 · 医生/营养师转型 · AI 工具落地 · 个人品牌 · 内容复盘 · 副业认知 · 健康行业观察

### 2.3 AI×营养内容方法论 4 类选题（张医生主场）

| 类型 | 公式 | 例子 |
|:---:|------|------|
| **爆款拆解卡** | "一条爆款 + 3 个关键动作" | 《这条营养科普 10 万+，我只改了标题》 |
| **提示词卡** | "场景 + 可直接复制的提示词" | 《营养师选题，用这 1 条提示词出 20 个题》 |
| **数据卡** | "真实后台数字 + 一句结论" | 《700 粉到 2 万，我做对了什么》 |
| **避坑卡** | "反常识 + 3 个坑" | 《医生做公众号，前 50 篇最容易死的 3 个坑》 |

- **每张卡只讲一件事**：一个案例 / 一条提示词 / 一个数据 / 一个坑。
- **信息块三件套**：结论 + 具体动作 + 一句人话解释；整篇配字 80-150 字即可。
- **合规提醒**：不写"保证涨粉""月入 X 万""包教包会"；自己的数据标注"个体案例"。

### 2.4 新手"7 天 7 组"测试法

每天发 1 组，每组 3-6 张图，每组只讲一个主题，连续记录数据。复盘看 **5 个指标**：
1. 哪类标题更容易被打开
2. 哪类图更容易被点赞
3. 哪类主题更容易被评论
4. 哪类内容带来新增关注
5. 哪类能带动旧文章/旧视频阅读

> 阅读不错但没人关注/评论 = 泛流量；有人留言"想学/想要" = 这个主题值得深挖。

## 三、单篇结构：3 图 + 配字 + 标题

### 3.1 三图结构（新手默认框架）

| 第几张 | 任务 | B 端示例 |
|:---:|------|------|
| 第一张 | **戳痛点**（让目标人群停下） | "有专业，写出来没人看" |
| 第二张 | **给方法**（干货/清单/步骤） | 3 个动作 / 1 条提示词 / 1 个数据 |
| 第三张 | **给行动**（收藏、转发、关注理由） | "收藏这张卡，下次写稿直接用" |

### 3.2 配字 80-150 字
只做两件事：① 补充图片没说清的信息；② 引导读者关注你的持续价值。

### 3.3 标题 / SEO / 标签
- 标题直接决定打开率（收集 10-20 个爆款标题喂 AI 生成相似款）
- 标题、内容、合集名**嵌入关键词** → 吃"搜一搜"搜索流量
- 每篇加 **2-4 个话题标签**：`#AI营养师 #公众号运营 #AI做内容 #健康自媒体 #医生转型`

## 四、做图：找图 / 官方AI / 第三方AI / 封面规范

### 4.1 官方免费路径（最省事）
- **公众号后台"AI 配图"**（腾讯混元）：新建文章 →"图片"→"AI 配图"；支持比例 1:1 / 4:3 / 2.35:1（公众号封面 1024×436）。提示词结构：主体+动作+场景+风格+色彩+情绪+镜头。
- **手机"文字海报"**（仅公众号助手 App）：输入文字（≤140 字）→ 一键生成海报封面，现有 6 个模板。

### 4.2 第三方 AI 生图（批量/质感更可控）
- 工具：**豆包、即梦、文心一格**；**GPT Image 2**（质感好，注意按平台比例生成）。
- B 端卡片优先"**文字海报**"而不是插画：结论字要大、对比要强、背景干净。
- 去 AI 味：加风格词打底（电影级质感/浅景深/柔和光线/4K/真实摄影）；**AI 出图文字常错 → 标题字后期用修图软件加**；饱和度可降 10-15%。
- 找图渠道：抖音/小红书/百度搜图 → 转风格、改滤镜、裁剪去重（避版权）。

### 4.3 封面规范（唯一值得花钱的地方）
**3:4 竖版为主 + 字要大 + 主体单一 + 对比强烈**；固定模板、固定配色、固定字体，让读者一眼认出你的号。

> ⚠️ **AI 真相：** AI 制作内容**不限流**；AI 批量自动发低质内容**才限流**。做法：AI 做初稿 → **人工审核每一张** → 手动发布。

## 五、发布 SOP（关键开关别漏）

### 5.1 手机端（最快，5 分钟内）
1. 打开**"公众号助手"App**（或微信内"我 → 视频号和公众号/作品 → 发贴图"）
2. 点"贴图" → 创作方式三选一：**拍照 / 文字海报 / AI 生图**
3. 加标题 + 简短描述
4. ⭐ **关键开关**：打开"**平台推荐**"（否则不进推荐池）+ 打开"**赞赏 / 留言区广告**"（收益来源）
5. 发布

### 5.2 PC 端
公众号后台（mp.weixin.qq.com）→"新的创作"→"贴图"→ 上传（本地上传 / 图片库 / 微信扫码 / AI 配图四种）。

### 5.3 频率与养号（v2 修正）

- ❌ **B 端贴图号不要发生活/风景/绿植"养号"**——那会把账号标签打歪，系统不知道你是"内容方法论号"还是"生活号"。
- ✅ **直接发 3-5 条 B 端知识卡定标签**：爆款拆解 / 提示词 / 数据 / 避坑，同一类连发，让系统认出你。
- **手动发布，不要定时**；一天 **3-5 条**即可，频繁会被判批量操作限流。
- **稳定 > 高频**：固定节奏，别一天 5 条然后停一周。
- > 注：v1 写的"先养号 5-7 天"只适用于 C 端生活类贴图号；本项目走 B 端，按本条执行。

## 六、账号与涨粉

- **垂直到窄人群**：账号名要直白——`AI营养师张医生` 直接占住身份，别用高大上的抽象名。
- **贴图里藏定位**：只发好看的图没给关注理由 = 流量留不住；封面/结尾金句做得好，用户会帮你截图转发。
- **长尾运营**：好的贴图会被收藏、转发、长按截图，回访旧图 → 新关注。
- **跑通后升级**：把数据好的贴图升级为 ①长文拆解 ②系列栏目 ③陪跑/伙伴入口（见第八节联动）。

## 八、与张医生主系统结合（v2 单主线）

### 8.1 主线：B 端三支柱
- **爆款拆解卡**：一条内容怎么起来的（选题/标题/开头/数据）
- **AI 工作流卡**：一个环节用什么工具、什么提示词、怎么操作
- **身份结果卡**：医生转型、700 粉到 2 万、踩过的坑

例：《这条营养科普 10 万+，我只改了标题》《营养师选题，1 条提示词出 20 个题》《700 粉到 2 万，我做对了什么》

### 8.2 移出：C 端食谱 / 清单
- 健康食谱、清单、对比图**不再发在公众号贴图** → 交给**小红书 / 视频号**（C 端获客）
- 公众号贴图只服务"想做内容的人"，不服务"想看怎么吃的人"

### 8.3 "一条内容双发"联动（库内已验证打法）
**贴图讲浅 → 公众号长文讲深 → 长文里带"完整版看同名公众号"**；贴图同时测哪个主题能爆，爆了再升级短视频/长文/微课，形成探针-放大闭环。

> ✅ **自动化已接线：** 「写公众号 → 推草稿箱」默认自动附带一组同主题贴图浅版草稿（说"不要贴图"才跳过）。执行规则见 [[公众号创作总控台]]「附录 A3 · 贴图浅版」。

## 九、合规红线（v2 · 双红线）

> 产出前先过 [[F技能库skill/运行规则/01-合规网关]]，一票否决。

**自媒体方法论类：**
- 不承诺收益：不写"月入 X 万""包教包会""保证涨粉""跟着做就能成"
- 自己的数据可以写，但标注"个体案例，不代表普遍结果"
- 招商话术不进正文："安利 / 招人 / 收入"→ 私域 / 直播

**健康类（仍适用）：**
- 说"**营养素**"，不叫"保健品"
- 不写功效/绝对化/治疗类词（美白、补气血、治疗、降三高…）→ 改生活化表达
- 三条红线：不引导问诊 / 不引导评论区谈病情 / 不引导平台外学医领资料
- 营养类结尾加免责

**通用：**
- AI 出稿必须人工审核；后台发布勾选"含 AI 生成内容"
- 图片版权：别直接用别人图，AI 生成或找图后转风格去重

## 十、避坑清单（v2）

- ❌ 只发好看的图，没给"这说的就是我 / 我能收藏 / 能转给同行"的价值感
- ❌ 只盯流量，不设计关注理由（贴图里要藏清晰定位）
- ❌ **做成泛 AI 工具号**：涨一堆白嫖粉，一个伙伴都转不出来
- ❌ **脱离营养垂类**：只讲涨粉、不讲健康内容，身份就散了
- ❌ 用生活/风景图"养号"，把 B 端标签打歪
- ❌ 盲目抄爆款结构，却不服务一个具体人群的具体场景
- ❌ 一上来追求高频、乱换赛道
- ❌ 批量自动发布 = 粗糙 = 平台不推
- ❌ 照搬夸大收入截图、轻信"每天半小时躺赚"
