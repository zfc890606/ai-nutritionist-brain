# 📌 公众号商业定位 v2（AI营养师 · B端版）

> **一句话：** 公众号 = 张医生生意里的「**B端信任放大器**」——不讲营养知识，只讲"一个三甲医生，怎么用 AI 在营养赛道把内容做起来"。让**想在健康/营养赛道做内容、做事业的人**相信"跟着这个人能做成"，再流向陪跑、伙伴与私域。
> **定位公式：** 细分赛道 + 目标人群 + 差异化价值 + 后端承接
> **本卡定位：** 战略层（往哪打 · 写什么/不写什么）。运营层（怎么发）→ [[公众号创作总控台]]；写稿层（怎么写）→ [[公众号写作手册]]
> **一句话人设：** `AI营养师张医生——5000台手术的麻醉医生转型，不讲营养知识，讲营养内容怎么用 AI 做成爆款。` 记忆点三个词：**医生出身 · 真做成了 · AI 工作流**

## 〇、v2 改版说明（2026-10-21）

| | v1（2026-09-29） | v2（2026-10-21） |
|---|---|---|
| 读者 | C 端：中老年 / 管全家健康的妈妈 | **B 端：想在营养赛道做内容、做事业的人** |
| 讲什么 | 营养认知 / 消费避坑 / 医生见闻 | **爆款怎么拆 + AI 怎么用 + 我怎么做成** |
| 后端 | 营养方案 / 私域顾客 | **陪跑 / 伙伴 / 事业机会** |
| 平台角色 | 身份信任放大器（C 端养熟） | **B 端深度信任（同行与准伙伴）** |

**为什么改：** 老号粉丝少、营养科普数据跑不动；C 端获客本来就不是公众号的强项，应该交给视频号。公众号改做 B 端深度信任，反而**直接对齐 FC**——吸引想做健康事业的人，再筛选成伙伴，补上"团队接不住、个体做不大"的系统缺口。

**不变的四条：** 医生身份、营养素口径、合规红线、真人原创。

## 一、公众号在生意里的位置（平台分工）

```
视频号  = C端获客主战场（营养 / 健康 / 家庭场景）→ 涨粉 + 破圈
公众号  = B端深度信任（AI × 营养内容方法论）→ 养熟 + 筛选 ⭐本卡
小红书  = C端搜索卡位 + 信任资产沉淀
私域    = 成交场（陪跑营 / 伙伴 / 营养方案）
```

- **公众号不再抢 C 端流量**，专做"同行与准伙伴"的深度信任；
- **公众号只对第一人群说话**——想在营养赛道做内容的人，不是纯看养生的中老年，也不是纯 AI 工具爱好者；
- **定位锚 = 身份锚**：所有内容都围绕"**一个真做成的医生，把方法拆给你看**"这一条轴。

## 二、四问定位（写死 · 所有选题先过这里）

### ① 人群：谁在看公众号？

| 层 | 是谁 | 怎么对 |
|----|------|--------|
| **第一人群（说话对象）** | 想在营养 / 大健康赛道做内容的人：医生、护士、营养师、健康管理师、宝妈、想转型的职场人 | 讲"有专业怎么被看见 / 不会 AI 怎么上手 / 做了没数据怎么办" |
| **第二人群（后端承接）** | 被内容吸引、想做健康事业的人（潜在伙伴 / 陪跑学员） | 先靠"他真做成了"聚拢，再在私域 / 直播里自然浮现 |

> ❌ **不是**：只想看养生知识的中老年（那是视频号 / 小红书的活）
> ❌ **也不是**：纯 AI 工具爱好者、只想涨粉的白嫖粉（涨了也不转化）

### ② 痛点：戳哪一个？

| 优先级 | 痛点 | 说明 |
|:---:|------|------|
| **第一痛点（主力）** | *我有专业，但写出来没人看* | 最痛、最普遍 |
| **第二痛点** | *想转型做健康内容，不知道从哪开始* | 方向焦虑 |
| **第三痛点** | *AI 工具太多，不知道怎么用到内容里* | 工具焦虑 |
| **第四痛点** | *做了很久没数据，怀疑自己不适合* | 信心崩塌 |
| **第五痛点** | *医生 / 营养师身份，怎么变成个人品牌* | 身份变现 |

### ③ 价值：看完得到什么？

三种价值**至少占 1 个强的**（见 [[公众号写作手册]] 三价值检验）：

- **认知价值**：爆款是设计出来的，不是写出来的（*选题占 70%，标题定生死*）
- **实用价值**：可直接复制的 AI 工作流 + 提示词 + 后台数据（*照做就能用*）
- **情绪价值**：一个同行者的真实路径（*三甲医生 → 700 粉 → 2 万粉 → 100 万播放*）

→ 一句话：**一个真做成的医生，把"营养内容怎么做"拆给你看。**

### ④ 方向：能不能一直做下去？

**能。** 每做一条内容，就是一个新案例；案例源源不断，方法可以反复拆。
但**必须锚定"营养 / 健康"垂类**——不做泛 AI、不做泛自媒体。

反面（不进公众号）：
- 纯工具测评（Claude Code 安装、AI 软件横评）→ 泛粉，跟生意无关
- 纯涨粉技巧 / 平台八卦 → 同行号，不转化
- 纯招商话术（安利怎么做 / 招人 / 收入）→ 合规高危

## 三、内容三支柱（40 / 40 / 20）

| 支柱 | 占比 | 写什么 | 硬要求 |
|------|:---:|--------|--------|
| **① 爆款拆解** | **40%** | 我这条是怎么起来的：选题怎么来的、标题改了几版、开头怎么写、结构怎么搭 | **必须带真实后台截图 + 数字** |
| **② AI 工作流** | **40%** | 我具体怎么用：工具、提示词、步骤、卡在哪、怎么绕过 | **具体到"复制就能用"** |
| **③ 身份与结果** | **20%** | 医生为什么转行、做成了什么、踩过什么坑、带团队 | **建立"这个人真做成了"的信任** |

> 三者关系：①证明"方法有效"，②证明"方法可复制"，③证明"这个人可信"。缺一条，转化就断。

## 四、栏目化排期（让算法认得出你）

栏目名固定，别随机发：

| 周几 | 栏目 | 内容 | 对应支柱 |
|:---:|------|------|:---:|
| **周二** | 爆款拆解 | 一条内容的完整复盘：选题 → 标题 → 开头 → 数据 | ① |
| **周四** | AI 工作流 | 一个环节的工具 + 提示词 + 操作步骤 | ② |
| **周日** | 后台复盘 / 读者问答 | 本周数据、失败案例、读者问题 | ③ + UGC |

- **频率：每周 2–3 篇，绝不日更**（一篇推荐周期 3–7 天，日更会冲掉自己的流量）
- **时间：晚 8–9 点**（B 端读者下班后）
- **稳定 > 高频**：固定节奏，别一天 3 篇然后停一周

## 五、起号前 10 篇（直接排）

1. 700 粉到 2 万播放，我只带了一个 AI 员工
2. 我一条营养科普爆了 10 万+，真正起作用的不是内容
3. 医生做公众号没人看？我前 50 篇全踩了这 3 个坑
4. 营养师别手写文案了：我的 AI 选题工作流，10 分钟出 20 个题
5. 同一篇营养稿，我只改了标题，阅读从 300 到 3 万
6. 我拆了 50 条健康爆款，发现开头只有 5 种
7. 不会剪辑的医生，怎么用 AI 做出能发的视频
8. 你的营养科普没人转，缺的不是知识，是"转发理由"
9. 我停更 3 个月，账号反而涨粉——公众号的长尾有多狠
10. 一个三甲医生，为什么开始教人用 AI 做内容

> 起号节奏：前 10–15 篇定标签；前 1 个月单篇阅读不足 100 属正常；单篇破 1000 进入"潜力池"。

## 七、发布前四问自检（一票否决）

1. 这条是写给**"想在营养赛道做内容的人"**吗？还是写给了纯看养生的中老年 / 纯 AI 爱好者？
2. 有没有**一个真实案例 + 真实数据**？（没有 → 先去做，别写）
3. 读者看完能不能**拿走一个可复制动作**？（不能 → 是感想，不是内容）
4. 有没有**锚定"营养 / 健康"垂类**？（没有 → 不发）

> 四问过不了 → 换题，别写。

## 八、合规红线（一票否决）

> 产出前先过 [[F技能库skill/运行规则/01-合规网关.md|01-合规网关]]。

- **不承诺收益**：不写"月入 X 万""包教包会""保证涨粉""跟着做就能成"
- **自己的数据可以写**，但标注"个体案例，不代表普遍结果"
- **健康内容仍说"营养素"**，不写功效 / 治疗 / 绝对化词（美白、补气血、治疗、降三高…）
- **招商话术不进正文**："安利 / 招人 / 收入"→ 私域 / 直播
- 三条红线：不引导问诊 / 不引导评论区谈病情 / 不引导平台外学医领资料
- **AI 合规**：AI 出框架 + 人工注入真实经验；后台发布勾选"含 AI 生成内容"

## 九、v1 → v2 落地动作（本周就能做）

1. **改门面**：名称 / 简介 / 菜单 / 关注自动回复，一次改完
   - 简介建议：`三甲医生转型｜不讲营养知识，讲营养内容怎么用 AI 做成爆款`
2. **旧文不删**：不相关的设"仅自己可见"，一天不超过 2 篇（全删 = 系统失去坐标）
3. **前 2–4 周过渡**：新旧内容穿插，逐步往新标签靠，别断崖式切换
4. **粉丝少不用关群发**；等粉丝过几千、人群错配明显了再考虑
5. **前 10–15 篇定标签**；重打标签周期 3–6 个月，别看 3 天就判死刑
6. **数据线**：阅读率 ≥5% / 完读率 ≥30% / 互动率 ≥3% / 转阅比 ≥8% / 盯常读用户数

## 十、最大风险与对策

| 风险 | 表现 | 对策 |
|------|------|------|
| **变成同行号** | 涨一堆想做自媒体的泛粉，不转化 | 每篇锚定营养垂类 + 内容里筛人（"如果你是医生 / 营养师…"） |
| **变成知识付费号** | 卖课、卖方法，偏离 FC | 后端只接"想做健康事业的人"，不卖课 |
| **案例耗尽** | 写几篇就没东西讲 | 边做边记录，内容生产即案例生产 |
| **身份分裂** | 视频号讲健康、公众号讲方法，像两个人 | 同一条身份轴：医生 → 用 AI 做营养 → 教你怎么做 |
