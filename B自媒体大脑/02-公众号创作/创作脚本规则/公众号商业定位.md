# 📌 公众号商业定位（张医生版 · 身份锚）

> **一句话：** 公众号 = 张医生生意里的「**身份信任放大器**」——不招商、不卖货，只干一件事：让**关心中老年健康的人（含管全家健康的妈妈）**相信"这个懂医的人，是真懂营养的"，把「**AI营养师**」这个身份钉进他们脑子里，再流向私域与直播。
> **定位公式：** 细分赛道 + 目标人群 + 差异化价值 + 后端承接
> **本卡定位：** 战略层（往哪打 · 写什么/不写什么）。运营层（怎么发）→ [[公众号创作总控台]]；写稿层（怎么写）→ [[公众号写作规则系统]]
> **一句话人设：** `AI营养师张医生——5000台手术的麻醉医生转型，用医学视角讲营养，帮你不交智商税。` 记忆点三个词：**医生出身 · 营养避坑 · 算账说话**

## 〇、为什么公众号要单独定一次位（2026-09-29 立卡）

公众号此前只有"**怎么写**"（规则系统 / 标题卡 / 结构模板 / 排版 / 发布流程 这 7 个文件），**没有一张回答"写给谁、解决什么、为什么只有你能讲、方向能不能一直做"** → 结果是**三线混发**（营养线 / 创业线 / AI工具线），算法认不出你是谁。

本卡对标 [[B自媒体大脑/03-小红书创作/创作脚本规则/小红书商业定位.md|小红书商业定位]]，把四问（**人群 / 痛点 / 价值 / 方向**）在公众号侧写死。**冲突时以本卡为北极星。**

## 一、公众号在生意里的位置（平台分工）

沿用 [[B自媒体大脑/自媒体平台矩阵.md|自媒体平台矩阵]]：

```
视频号  = 爆款主战场（获客第一阵地）→ 涨粉+破圈
公众号  = 身份信任放大器（医生身份深度背书）→ 养熟 ⭐本卡
小红书  = 搜索卡位 + 信任资产沉淀 → 精准抓人群
私域    = 成交场（营养方案 + AI营养师陪跑营）
```

- **公众号同时服务两条线**：营养线（抓顾客）+ 创业线（养出未来的伙伴）；
- **但公开内容纪律：公众号只对"第一人群"说话**——「AI营养师」是让人记住你的**身份标签**，不是讲给同行听的招商话术。
- **定位锚 = 身份锚**：营养 / 创业 / AI 都围绕"**医生转型 AI 营养师**"这一条身份轴 → 用身份涨粉、用身份承接后端。

## 二、四问定位（写死 · 所有选题先过这里）

### ① 人群：谁在看公众号？

| 层 | 是谁 | 怎么对 |
|----|------|--------|
| **第一人群（说话对象）** | 关注中老年健康的人 + 30-50 岁管全家健康的妈妈；**大多不知道安利、也不关心 AI** | 只讲"营养素别交智商税 / 体检报告怎么看 / 怎么吃才对" |
| **第二人群（后端承接）** | 从第一人群养熟后，被"AI营养师"这个人吸引、可能有创业意向的人 | 先靠身份认同聚拢，再在私域 / 直播里自然浮现 |

> ⚠️ 公众号的传播机制（转家族群、早 6-8 / 晚 7-9 双高峰、正文 14px）决定了**第一人群就是中老年 / 妈妈**。写给他们，别写给同行。

### ② 痛点：戳哪一个？

| 优先级 | 痛点 | 弹药库 |
|:---:|------|:---:|
| **第一痛点（主力）** | *我吃的营养素 / 补的东西，到底有没有用？是不是智商税？* | ①② |
| **第二痛点（护城河）** | *医生为什么不告诉我这些？* | ④ |
| **第三痛点（高共鸣）** | *体检正常，身体却一年不如一年。* | ⑤ |

### ③ 价值：看完得到什么？

三种价值**至少占 1 个强的**（见 [[公众号写作规则系统]] 三价值检验）：

- **认知价值**：颠覆"营养素=智商税"（*不是智商税，是你买的方式不对*）
- **情绪价值**：医生共情（*我在手术台见过太多指标一塌糊涂的身体*）
- **实用价值**：可收藏的清单（*买鱼油前先看这 3 个数*）

→ 一句话：**一个"懂医的人"帮他把营养讲明白，且值得长期关注。**

### ④ 方向：能不能一直做下去？

**能。** 身份轴天然无限：手术见闻写不完、营养认知误区写不完、AI×营养的落地案例写不完。
反面：*"安利怎么做 / 怎么招人 / 收入多少"* 这类题写 20 篇就空了，且合规高危 → **不进公众号。**

## 三、内容方向：三锚结构（留 / 改 / 移出）

| 内容 | 处理 | 弹药库 | 占比 |
|------|------|:---:|:---:|
| **营养认知 / 消费避坑** | ✅ **主线**（第一人群主菜） | ① 37 + ② 18 + ③ 20 | **60%** |
| **医生身份 / 见闻**（护城河 · 身份锚核心） | ✅ **主线** | ④ 23 | **25%** |
| **健康观念 / 体检认知** | ✅ 无认证期白名单安全区 | ⑤ 24 | **15%** |
| **纯招商**（安利怎么做 / 招伙伴 / 收入） | 🔴 **移出** → 朋友圈 / 私域 / 直播 | ⑥ 招商半边 | — |
| **纯 AI 工具教程**（Claude Code 安装…） | 🔴 **移出** → AI 应用号 / 抖音 | article-A 系列 | — |
| **身份类创业故事**（医生为什么做这件事 / 价值观） | 🟡 归入「医生身份线」**留用**（身份认同·无合规风险） | ⑥ 身份半边 | 计入 ④ |

> **关键动作：把弹药库⑥拆开用。** 146 条创业线里——
> - *"医生为什么做这件事 / 价值观 / 我的十年"* 这半边 = **身份认同 → 留**；
> - *"安利怎么做 / 怎么招人 / 收入多少"* 那半边 = **招商 → 移出公众号**。

## 四、栏目化排期（让算法认得出你）

对齐弹药库 40/40/20 节奏，但**栏目名固定**，别随机发：

| 周几 | 栏目 | 内容 | 弹药库 |
|:---:|------|------|:---:|
| **周二** | 营养认知 | 避坑 / 消费对比 / 认知颠覆（产品教育 40%） | ①②③ |
| **周四** | 医生夜话 ⭐ | 身份故事 / 医生见闻（行业洞察 40% · **身份锚核心位**） | ④ |
| **周日** | 读者来信 | 评论区高频问题 / 读者故事（UGC 20%） | ⑤ + 评论 |

> 每条线有固定栏目名 + 关键词 → 算法能打标签 → 推荐更准。

## 六、发布前四问自检（一票否决）

1. 这条是写给**第一人群**（中老年 / 妈妈）看的吗？还是写给了同行？
2. 戳的是「智商税 / 医生不说 / 体检正常却变差」里**哪一条**？
3. 读者看完**得到什么**（认知 / 情绪 / 实用，至少占 1 个强的）？
4. 这条属不属于**身份锚主线**（营养认知 / 医生身份）？**不属于 → 它该发在哪儿（朋友圈 / 私域 / AI号）？**

> 四问过不了 → 换题，别写。

## 七、合规红线（一票否决）

> 产出前先过 [[F技能库skill/运行规则/01-合规网关.md|01-合规网关]]。健康类额外注意：

- 说"**营养素**"，不叫"保健品"
- 不写功效 / 绝对化 / 治疗类词（美白、补气血、治疗、降三高…）→ 改生活化表达
- 三条红线：不引导问诊 / 不引导评论区谈病情 / 不引导平台外学医领资料
- 营养类结尾加免责；后台发布勾选"含 AI 生成内容"
- **招商内容一律不进公众号**（合规高危 + 稀释人群标签）
