### 卡脚本（3-5 张默认结构）

1. **封面**：大钩子标题（≤16 字）+ 一句痛点/收获

3. **干货 ①**：一个核心结论大字 + 一句大白话解释
4. **干货 ②**（可选）：第 2 个要点 / 清单
5. **CTA 末卡**：想看完整版 → 同名公众号搜长文标题

## A4. 推送失败自愈 · IP 白名单「3 分钟自动重推」

> 推送返回 `errcode=40164`（`invalid ip … not in whitelist`）时，**自动挂 3 分钟后的重推，不再让张医生回来喊**。

1. **读出被拒 IP**：从报错取 `invalid ip`；可复核本机出口 `curl -s https://ipv4.icanhazip.com`（微信只认 IPv4）
2. **告知 + 挂任务**：告诉张医生去 **mp.weixin.qq.com → 设置与开发 → 基本配置 → IP 白名单** 加入该 IPv4；同一条消息说明"3 分钟后我自动重推"，并挂一次性任务（会话内 `ScheduleWakeup`，`delaySeconds≈180`；跨会话用一次性 `CronCreate`）
3. **到点自动重跑**：
   ```bash
   cd ~/.claude/skills/gzh-AI-Design-skill && python3 scripts/wechat_push.py "output/{标题}_{日期}"
   ```
4. **仍 40164 → 再挂下一个 3 分钟**，上限 10 次（≈30 分钟），超限停下等指令
5. **成功 → 收尾**：记录 media_id（长文 + 贴图两件），回填推送记录，提醒后台勾选「含 AI 生成内容」

**注意：**
- IP 是**动态**的，每次重推前重新读报错里的 IP，别让张医生加错
- 自愈只作用于"推草稿箱"这一步；写作/排版/质检不自动重试
- 说"先别推 / 手动来" → 立即停自愈

### 动效铁律（2026-10-21）

- 公众号正文会清掉 `<style>` / `@keyframes` / `<script>` / `<svg>`，**任何 CSS 动效贴进去都变静图**；能动只有 GIF。

## A7. 常见问题

**Q：图片怎么办？**
封面图和文中图片需到公众号后台补充（API 只传文字内容）。

**Q：格式乱了怎么办？**
先核对固定令 v4.0：正文 15px / **行高 2.5** / 字距 0.3 / 首行缩进 2em / **段距 40px、每段 3–4 行最多 4 行** / 墨靛 #252F3D／虚线脊 #CFD8E1／章节头圆点 + ORBITAL 编号 + **24px 细体居中标题（字距 0.5em）**／金句深卡 ≤2／**引用 14px 浅灰居中无框无线 ≤2**／提示词左侧细线不套框／无目录卡／固定 3 张图（头部动图·流程动图·16:9 名片）／人像名片文字压图上／2000–2500 字。再用 `validate_gzh_html.py` 跑一遍；**出现蓝色 #007AAA 小标题、行高 1.75–1.88、段距 10px、标题加粗、引用放大加框、无虚线脊、或全篇一个字号一个粗细 = 排版不合格，按 v4.0 重排**。

**Q：如何更新已发布文章？**
公众号已发布文章无法改正文（只能改最多 20 字）。需要更新：修改后重新发布为新文章，并注明更新说明。

**Q：没有 API 配置怎么办？**
管线完成 Phase 1+2 后，把 HTML 复制到剪贴板，手动粘贴到公众号后台。
