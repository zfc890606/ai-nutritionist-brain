你好，我是张医生。
三甲医院麻醉科做了将近十年，现在全职做AI营养师。
用AI做自媒体一个半月，粉丝从700到2万，总播放100万，十条过了十万。

它讲的不是营养素，是：医生为什么不学营养学。
很多人问我这条到底赢在哪，我说不出玄的。
今天我把它拆成3个元素，一个都不藏，你照着改就能用。

## 01 · 元素一 选题：拆一句全民都信的话

选题不是找一个话题，是找一句“所有人都在默认、但没有人点破”的话。像查体，病人说得出的地方，你往往查不出问题；真正要命的，是他自己没意识到的那一处。

很多人选题靠“我今天想讲什么”。于是每条视频都像在跟自己说话，讲得都对，观众划过去。

我以前先想“我知道什么”；现在先问一句：“现在正被多少人默认着的，是哪句话？”

“医生最懂营养”，就是这句话。它不需要论证，它已经长在所有人心里。我拆它，不是拆医生，是拆这句共识。

而这个题，换个人真拆不了。拆它要两样东西：一是在手术室里待过近十年，二是亲手经历过病人问“回家该吃啥”、我答不上来的那一刻。

这件事最要紧的地方在于，它不扎人。不是哪个医生偷懒，是结构里本来就没有这一节。国务院办公厅《国民营养计划（2017—2030年）》写着一句话：将营养融入所有健康政策，加强营养人才培养。官方文件都在补这块，说明这块本来就是空的。

所以选题这个元素，真实动作只有一步：把“我想讲”换成“大家在默认”。前者是你的日记，后者才是公共话题。

```prompt 提示词一 · 选题独占性诊断
你是我的选题审稿人。选题是：【一句话写清这个题】。
请依次回答四件事，每件不超过三行：
一、这句话现在被多少人默认着？它是不是一句不用论证、大家就信的话？
二、拆它需要什么经历或位置？我有的写出来，我没有的标一个“缺”。
三、换一个同行来讲，他能不能讲得一样好？能讲一样好，就说明我不独占。
四、这个题会得罪谁？分“事”和“人”两栏，靶子只准落在“事”上。
最后给我一句判断：写，还是不写，理由一句话。
```

## 02 · 元素二 表达：一个画面，一笔账

观众记不住道理，只记得住画面和数字。道理是散的，画面是钉子，钉子钉进去，他才有东西拿给别人看。

很多人讲得很对，观众却转不出去。因为他手上没东西，只剩一句“你说得对”，而这句话没法转。

我以前讲“营养很重要”。现在讲：医学是急救箱，营养是米缸。急救箱能救命，米缸得自己过日子，你不能拿急救箱当饭吃。

还有一个画面：临床是4S店。车撞了，钣金、喷漆、换件，手艺好的师傅能恢复原样。可你每天加什么油、走什么路、多久保养一次，4S店里没有工位。

数字不要拿来压人，要让人自己算。世界卫生组织的一组数据被反复引用：影响健康的因素里，行为和生活方式占六成，医疗服务只占八个点。

六成在你自己手里。这个数，医生替不了你，药也替不了你。观众听到这句会“咯噔”一下，因为账是他自己减出来的，他没法反驳。

数字还有一个坑：别连着报。一条视频里塞四组数据，中段就开始掉人。正确排法是一个数字跟一个画面，一个画面跟一句反问。

画面和账，本质是同一件事：让他带走一句他自己能复述的话。复述得出来，他才转得出去。

```prompt 提示词二 · 画面与账
把我的核心观点压成三样东西，每样不超过25个字：
一、一个生活里的画面（厨房、修车、盖房、送快递都行，越日常越好）；
二、一笔观众能自己算的账（给公式、给数字，让他自己减出缺口）；
三、一句反问（用这笔账，反问他现在的生活）。
禁止出现：很重要、要重视、科学表明、众所周知。
每一条后面标一句：这句话能不能被原样转述给另一个人听。
```

## 03 · 元素三 结尾：一个动作，一个转发对象

结尾不是关门，是送到电梯口。送到门口还不够，手里得塞给他一样东西。

“关注我，分享更多有价值的内容”，这句是对的，也是空的。它只对你说，不对他做。

我以前写“希望对你有帮助”，现在写：下次复查，你可以顺口问一句，我平时该怎么吃？

一个今晚就能做的动作，比十个正确的观点有用。动作要小到不用准备，小到他明天下楼就能试。

还有一件更少人注意的事：你要替他写清楚“转给谁”。写成“转给我担心的那个人”，这条容易进朋友圈；写成“转给那个反对我的人”，它就只进私聊。

这条视频我用的是后者，所以它拉动的是评论和私下讨论，没进朋友圈。想让一条视频进朋友圈，转发对象得选关心型。

最后是护盘。这条视频底下第一条置顶是我自己发的：我说的是课表，不是医生。真到救命那一下，医生就是神。得罪事，不得罪人。靶子打在结构上，人才不会觉得被冒犯。

三个元素凑齐，一条视频就立住了：选题拆得准，表达记得住，结尾带得走。少一个，观众就少一个转出去的理由。

```prompt 提示词三 · 3元素自检
这是我视频或文章的结尾：【粘贴结尾原文】。
只做一件事：检查观众看完，手里有没有三样东西——一个数字、一个画面、一个动作。
逐项打分：0 是没有，1 是提到了但没给全，2 是给全了。
缺哪一项就补哪一项，然后给出改写后的结尾，不超过80字。
最后补一句：这条内容最该转给谁？在“我担心的人”和“反对我的人”里选一个，并说明为什么。
```

你今晚就能做的第一步：打开你最近一条没起量的视频，只回答一个问题——观众转它的时候，手里拿着什么？

答不出来，就去改结尾，把数字、画面、动作里最缺的那一件塞进去。改完再发一次，你会看到差别。
