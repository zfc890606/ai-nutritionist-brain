你好，我是张医生。三甲医院的麻醉医生做了快十年，现在全职做AI营养师。45天，粉丝从700到2万，总播放100万，连着10条10W+。

不是我忽然会拍了，是我把一条视频拆成了七个颗粒。七个颗粒，各管一段，顺序不能乱，这篇全摊开，连提示词原文一起给。

一条三分钟的成片，我从选题到定稿四十分钟。其中二十分钟，只花在第1颗和第3颗上，剩下的AI跑。

1. 选题打分——这个题值不值得写
2. 定类型——是观念、案例，还是答疑
3. 磨开头——前八秒留不留得住人
4. 立观点——有没有一句能被截图的话
5. 收结尾——读者能拿走什么
6. 做交付——给表、给提示词，还是给动作
7. 过质检——一个字错，整条白做

四十分钟怎么分：选题十分，磨开头十分，立观点五分，收结尾五分，做交付五分，质检五分。时间不够先砍结尾，别砍开头。

规矩只有一条：同一时间只磨一个颗粒。七颗一起改，数据动了，你也不知道是哪颗起的作用。

> AI时代的爆款不是灵感，是流水线。

![[flow-7.gif]]

下面把最卡人的三段讲透，一段配一条提示词。最后再教你用四个数据，定位到底是哪一颗坏了。

## 01 · 选题：这个题值不值得写

一条内容能不能起，选题占七成。

这个比例不是感觉。我把两百多条视频回头对过：同样的拍法，选题分高的那些，播放中位数是分低的三倍以上。我以前凭感觉挑题，十条里八条是废的，废在我以为我想讲的，就是别人想听的。

现在让AI打分，只看四件事，每件十分。痛感：这群人会不会为这件事睡不着，会就八分往上；资格：我有没有真东西可讲，麻醉医生讲术后营养有，讲护肤没有。

反差：结论跟大众认知拧不拧，拧得越狠分越高；可转：读者会不会转给同类人，心里冒出“我那个同事肯定要看”，就是十分。

四项里有两项不到六分，这个题就不写。不写不是浪费，是把时间省给能起的题。举个真打分，题一「术后第一周该怎么吃」：痛感九，家里有病人就慌；资格九，麻醉科天天见。

反差六，大众多半只知道喝粥；可转八，家属会互相转，三十二分，能写。题二「三伏天为什么不能喝冰水」：痛感五，不喝也不会怎样；资格三，这不是我的专业。

反差七，说得挺狠；可转六，二十一分，扔。还有一条：AI打分会偏高，它舍不得给低分，所以我拿到分先自己砍两分，只留三十二分以上的。

题过了，第二步定类型，三种，别混。观念型纠正一个错误认知，涨粉最快，新号先用它；案例型讲一个具体的人、一件具体的事，建立信任，适合已经在接咨询的人。

答疑型回答一个高频问题，收藏最高，适合已经有粉丝、开始掉播放的人。类型定错，后面全白费，新号天天讲案例，没人认识你，讲了也白讲。

```prompt 提示词一 · 选题打分
我在做营养健康赛道，目标读者是想转型的医生、护士、营养师。
给我十个选题，每个按痛感、专业度、反差、可转发四项各打十分，每项写一句打分理由。
总分低于三十二的直接删掉，只留三个。
每个题用一句话说清：为什么这个题现在会被点开。
```

## 02 · 开头和观点：前八秒，和那句能截图的话

开头只干一件事：让人停下来。

微信和视频号是同一个逻辑，前八秒决定后面全部。我的标准很死：第一句必须是一个数字，或者一个判断。不给判断，读者就走了。

三种句式换着用。数字反差：45天，从700粉到2万；身份反差：三甲医院的麻醉医生，现在天天研究怎么拍视频；反常识判断：你越专业，越没人看，这不是你的错。

把第一句单独念一遍，念完自己不想听第二句，就重写。原句「今天跟大家聊一聊，营养对术后恢复有多重要」，这是自我介绍，不是判断，划掉。

改成「手术做完，第一口吃错，伤口愈合慢一周」，一个动作，一个后果，人才会停下来。判断立住了，再往下拆观点，观点是骨，别的都是肉。

一句合格的观点的公式是：不是A，是B。不是“营养很重要”，是“营养不缺道理，缺的是能执行的那一口饭”；不是“AI很好用”，是“AI不难，难的是你没东西喂给它”。

《科学》期刊上有一份研究，麻省理工和哈佛的两位学者做的，四百五十三个人，用了AI以后时间少四成、质量高一成八。更有意思的是后半句：原来水平越低的人，提升越大。

翻译成人话：AI先把执行拉平了。执行一拉平，拼的就不是谁会写，是谁手里有真东西。

```prompt 提示词二 · 开头前八秒
我的视频主题是这一句：【填你的主题】。
给我五个开头，每个不超过六十个字。
第一句必须是数字或者判断，不提背景，不自我介绍。
写完把每个开头念一遍，判断哪一个会让人想问“然后呢”，告诉我为什么。
```

## 03 · 结尾、交付、质检：读者能拿走什么

结尾不是总结，是交付。读者看完，手上得能拿走一样东西。

三类交付，一条内容只给一个。一张表，让人能对着自查，比如“孩子挑食的五个类型”；一条提示词，让人能直接复制去用，比如这篇的三条。

一个动作，让人今晚就能做，比如“打开你上条视频，只看前八秒”。三个都给，等于一个都没给。结尾的句式也固定：一句定论，加一个动作，再加一句转发理由。

质检放最后，因为它最容易被跳过，一个字错、一句违规，整条白做。

| 三种做法 | 一条提示词丢过去 | 七段各管一段 |
| --- | --- | --- |
| 你干的活 | 一次性丢给AI | 你定标准，AI分段执行 |
| 出错以后 | 整条重来 | 只重做卡住那段 |
| 长期结果 | 每次都不一样 | 越磨越稳 |

四条质检，逐条过。有没有一句能被单独截图转发的话；有没有一个读者今晚就能做的动作；有没有夸大、承诺收益、讲医疗功效的表述；有没有超过三十四字还没断开的长段。

最容易漏的是第三条。我自己的黑名单：根治、逆转、治愈、无副作用、彻底好、包好、最有效、第一，写进正文，轻则限流，重则删文。

中国互联网络信息中心的报告里写着，到2024年底，生成式AI用户2.49亿，其中77.6%的人拿它问答。问一句，答一句，答完就散。

> 这哪是生产线，这就是问路。

```prompt 提示词三 · 成稿质检
你是我的内容质检员，下面是成稿。
按四项逐条挑问题：一，有没有一句能被截图转发的话；二，有没有一个可执行的动作。
三，有没有夸大、承诺收益、医疗功效的表述；四，有没有超过三十四字的长段。
只列问题，不要改写。
```

## 04 · 收尾：哪颗颗粒坏了，看数据就知道

这套拆法最值钱的地方，不是让你一次做对，是让你知道错在哪。以前一条视频没起，我只能说“网感不行”，然后整条重来。现在我看四个数，就能定位到具体那段。

三秒完播低，是开头，前八秒没给判断，或者给了背景。完播高、转发低，是观点，话说得对，但没有能被人拿去指的靶子。

转发高、收藏低，是交付，听完爽，手上空。收藏高、不涨粉，是选题，人群太宽，谁都沾一点，谁都不觉得是说给自己听。

一段一句，改那一段就行，这条视频不白拍，下一条就少走一次弯路。「低」要有基线，别跟全网比，跟自己比：取最近三十条播放的中位数，低于中位数一半才算低。

复盘每周一次，周日晚二十分钟：把这周播放按高低排队，最高三条和最低三条各看一遍，找它们共有的那一个特征。找到之后，下一周只改那一个颗粒，连拍三条再看，一条是运气，三条才算数。

国务院的文件里写着，到2027年，智能体等应用普及率要超过七成。再过两年，没人会把会用AI当本事。

AI会像电一样，通到每个行业里。到那时候，拼的是你在行业里，攒下了多少别人问不出来的问题。

一条提示词写一条视频，那是问路；七条提示词各管一段，那才是生产线。

爆款不是灵感，是流水线。灵感会断，流水线不会。
