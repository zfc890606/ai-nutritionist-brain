# 医生到底走没走？看数字

- 北上广深 → **只有 10%** 计划五年内离开
- 地级市及以下 → **23%**，翻了一倍还多
- 三级医院医师离职意愿 → 总体 **44.2%**

> 真正该问的不是"走没走"
> 是**谁在走，谁又留了下来**

---

# 压垮他们的，是三座山

- **钱** · 中级职称年人均收入 **7.39 万**，一周干 **51 小时**（法定只有 40）
- **尊严** · 进门先录音，出了事先投诉、先扣奖金
- **晋升** · 会看病的评不上，会写本子的评上了

> 培养一个能独立看病的医生要 **14 年**
> 留下他，有时只需要一个说得过去的理由

---

# 那他们，后来都去了哪？

1. **药企 / 医疗器械** → 医学事务、临床监查
2. **私立医院 / 诊所** → 只看临床能力和口碑
3. **健康管理 / 营养 / 科普** → 专业就是护城河
4. **干脆转行** → 开餐厅、做咨询、做医疗律师

> 走的往往不是最差的那批
> 是**最好用的那批**
