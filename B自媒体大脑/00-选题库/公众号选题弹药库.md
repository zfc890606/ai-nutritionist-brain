# 📚 公众号选题弹药库 v3（大健康超级个体 · 一人公司闭环）

> **这个号只做一件事：** 吸引并转化 **B 端**——想在大健康行业做“超级个体／一人公司”的人。
> **不讲营养。** 营养是另一个号的事；这里只讲“一个大健康从业者，怎么用 **自媒体＋AI** 把自己做成一家公司”。
> **后端：** 「相信未来超级个体俱乐部」＋陪跑群。正文只做**筛人**，不硬招商；入口放作者卡／菜单／关注自动回复。
> **用法：** 从本库取题 → 过 [[公众号写作手册]] 选题卡（4 问＋8 分＋三价值＋搜索词）→ 开写。写作流程与风格不在这里，本库只管“写什么”。

## 0. 业务链条地图（选题按这条链长出来）

```
① 选对行业：大健康
        ↓
② 做自媒体：先定商业定位
        ↓
③ 执行细节：朋友圈 / 短视频 / 表现力 / 研究自媒体
        ↓
④ AI 应用：个人知识库 / AI 工作流 / 放大选题与文案
        ↓
⑤ 一人公司全闭环：AI × 自媒体 × 大健康
        ↓
⑥ 同频共创：超级个体俱乐部 / 陪跑群
```

> 一句话：**大健康是坡，自媒体是车，AI 是发动机，一人公司是终点。** 所有选题都挂在这条链上，不写链外的东西。

**编号与状态：**

| 记号 | 含义 |
|:--:|---|
| A / B / C / D / E | 对应上面 ①–⑤ 五个环节 |
| ❌ | 未写（优先） |
| 📝 | 已写（公众号已发） |
| 🔄 | 待更新（数据跑过，换角度重写） |
| ⭐ | 优先写（本周排产） |

**不查重原则（2026-11-12 定）：**
1. **不跟任何库查重**——包括 [[B自媒体大脑/00-选题库/超级个体选题库]]。公众号是“改写发布”，同一观点可以再写一遍，不算重复。
2. 同一观点可以按**不同环节、不同靶子、不同身份场景**写成多条，各自独立成立。
3. 只有一种情况要合并：同一组里标题几乎一字不差——换个靶子或换个角度即可，不必删。
4. 一条题如果只剩“观点”，没有案例、没有动作、没有靶子——不建卡，退回挖矿。

### 1.3 挖矿公式（把别人的题，换成张医生的题）

> **原题 → 换身份 → 换靶子 → 换数字 → 换落点**

1. **换身份**：加“我在医院那几年／35 岁从三甲辞职／亏过 30 万”的具体场景（只作故事层，不作专业背书）。
2. **换靶子**：把“很多人”换成能被指认的人——“做了半年没起色的营养师”“想辞职又不敢的 90 后”“报了 3 个自媒体课的宝妈”。
3. **换数字**：用自己真实数据（5000 台手术、700 粉、2 万粉、100 万播放、亏 30 万），不编。
4. **换落点**：结尾不喊“加我”，只做筛人句——“这类问题我在俱乐部里带着做，这里只拆方法”。

**三不挖：** 不挖纯招商／收入承诺；不挖平台违规玩法（刷量、搬运、矩阵号）；不挖自己没做过的事。

## 7. 更新机制（让弹药库能一直长）

### 7.1 每周挖矿（30 分钟 · 固定动作）

1. **选 1 个博主**：按 1.1 的环节轮换，本周缺哪一环就挖谁。
2. **看最近 10 条**：只记“观点＋靶子＋原话”，不抄全文。
3. **过 4 换公式**：换身份→换靶子→换数字→换落点。
4. **不用查重**：不跟任何库对比；只在同一组里看一眼有没有一字不差的标题，有就换个靶子。
5. **写回**：进对应组，编号顺延（A-017、B-023……），标 ❌ 或 ⭐。
6. **登记来源**：在“挖自”写博主名，方便回查。

### 7.2 每月盘点（1 小时）

- 新增 2–3 个博主，补进 1.2 表；连续 3 个月不产出的，降级或移出。
- 把已发题的 📝 更新为数据结果（阅读/转发/加微），跑得好的标 ⭐，跑不动的标 🔄。
- 每月至少补 **10 条**新题，保证库里始终有 30 条以上 ❌。

### 7.3 状态流转

```
❌ 未写 → ⭐ 本周排产 → 📝 已发 → 🔄 数据复盘后重写 → 📝 新版
```

## 9. 合规红线（一票否决）

1. **不承诺收益**：不写“月入 X 万”“包教包会”“保证涨粉”“跟着做就能成”；自己的数据标注“个体案例，不代表普遍结果”。
2. **健康内容不越界**：不碰疾病治疗、用药、指标；不讲功效、不引导问诊、不引导评论区谈病情；统一用“营养素”口径。
3. **招商话术不进正文**：安利/招人/收入/俱乐部招募 → 放私域、直播、作者卡、菜单；正文只做筛人句。
4. **AI 合规**：AI 出框架＋人工注入真实经验；后台勾选“含 AI 生成内容”。
5. **引用有出处**：外部观点/数据必须能点开；不编造博主原话，不把“网传”当事实。
