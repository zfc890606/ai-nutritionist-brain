# 胆固醇 · 全息知识手册

> **一句话核心**：血里的胆固醇，七八成是**肝脏自己造的**，不是吃进来的。所以要解决"胆固醇高"，重点从来不是"少吃蛋黄"，而是**肝脏为什么造太多 + 身体为什么清不掉**。
>
> **来源说明**：本文整合自全网权威检索（PubMed / AHA / 《中国血脂管理指南2023》 / 膳食纤维-胆汁酸-菌群机制研究等），为内部知识底稿，供营养咨询与内容创作调用。

## 一、认知纠偏：胆固醇从哪来

**人体胆固醇 = 外源(吃) + 内源(造)，比例大约 2 : 8。**

| 来源 | 占比 | 说明 |
|------|------|------|
| ① 膳食摄入（外源） | 约 **20%–30%** | 只来自动物性食物（蛋黄、内脏、脑髓、肥肉） |
| ② 肝脏内源合成 | 约 **70%–80%** | **主角**。肝脏合成一半以上，小肠、皮肤、肾上腺补其余 |

> 关键事实：膳食里的胆固醇对血胆固醇的影响，**远小于**饱和脂肪和反式脂肪。
> 常见误区："我吃得很素，怎么胆固醇还高？"——因为问题出在 **②内源合成** 和 **清除能力**，不在①。

**三个必须记住的名字（内源合成三件套）：**

1. **HMG-CoA 还原酶（HMGCR）** —— 胆固醇合成的**总闸门/限速酶**。它快，胆固醇就多。
2. **SREBP-2** —— 细胞里的"胆固醇传感器"。肝细胞胆固醇低 → 它被激活 → 上调 HMGCR（造）和 LDL 受体（收）。
3. **LDL 受体（LDLR）** —— 把血里"坏胆固醇"（LDL）**回收**进肝脏的抓手。抓手多 → 血胆固醇低；抓手少 → 血胆固醇高。

## 二、全链路逻辑拆解

### 2.1 一张图看懂胆固醇的"出入账"

```
        【入账 / 生成】                    【出账 / 清除】
   ┌──────────────────┐            ┌──────────────────┐
   │ ① 肠道吸收膳食胆固醇 │            │ ④ 肝→胆汁酸→排泄   │← 主出口
   │ ② 肝脏内源合成(主角) │──→ 血液 ←─│ ⑤ LDL受体回收进肝   │← 关键闸
   │ ③ 胆汁胆固醇重吸收   │            │ ⑥ 胆道直接排胆固醇   │
   └──────────────────┘            └──────────────────┘
                    胆固醇平衡 =（排泄 − 摄入）+ 胆汁酸排泄
```

**逻辑核心：血胆固醇高低 = 生成速率 − 清除速率。**
任何一头失衡，血胆固醇就升高。

### 2.2 肝脏自己造的胆固醇，本来是给谁用的？（用途，不是废物）

- **合成胆汁酸** → 帮助消化脂肪（最大去向）
- **构成细胞膜** → 维持细胞结构
- **合成激素** → 性激素、皮质醇、维生素 D 的前体
- **合成维生素 D** → 皮肤经日晒转化

**所以胆固醇本身不是坏东西，是"量"失控了。** 目标不是把它清零，而是**让生成与清除重新平衡**。

### 2.3 一套"恒温器"（负反馈稳态）

肝脏里有一个自动调节回路：

```
肝细胞胆固醇低  →  SREBP-2 被激活  →  ① HMGCR↑（多造）
                                   →  ② LDL受体↑（多回收）
肝细胞胆固醇高  →  HMGCR 被抑制  →  合成下降（刹车）
```

**胆固醇高，本质是这个"恒温器"失灵了——要么油门卡死（合成过多），要么刹车不灵（回收/排泄受阻）。**

## 三、内源合成过多：6 大成因

> 这是本手册的核心。肝脏 HMGCR 合成速率"相对身体需要**不适当过高**"，就是内源生成过多的定义。下面逐条拆解。

### 3.1 LDL 受体缺陷 / 家族性高胆固醇血症（遗传，最硬的成因）

- **机制**：LDL 受体基因（LDLR）突变 → 肝细胞"抓手"变少 → 血里 LDL 清不掉；同时因肝内胆固醇不足，**SREBP-2 反向激活 HMGCR → 合成更多**。清除变差 + 合成变多，双重叠加。
- **数据**：约 **85%–90%** 的家族性高胆固醇血症（FH）变异在 LDLR 基因；杂合子 LDL-C 约为常人 **2 倍**，纯合子可高达 400–1000 mg/dL。相关基因还有 APOB、PCSK9、LDLRAP1。
- **识别线索**：LDL-C ≥ 4.9 mmol/L（约 190 mg/dL）、父母/兄弟姐妹同样高、年轻就心梗、皮肤/跟腱有黄色瘤。
- **要点**：这类是"主因压过饮食"，**必须就医 + 基因筛查 + 家族级联筛查**，光靠饮食不够。

### 3.2 胰岛素抵抗 / 代谢综合征（现代人最常见）

- **机制**：胰岛素抵抗 → 肝脏大量分泌**富含甘油三酯的 VLDL** → 经 CETP/肝脂酶交换水解 → 生成**小而密 LDL（sdLDL）**。sdLDL 更坏（更易钻进血管壁），但**胆固醇含量低**——所以常规 LDL-C 可能看着"正常"，实际颗粒数已在升高，**风险被低估**。
- **要点**：这条链的核心是**甘油三酯/VLDL 过多**，往往早于糖尿病出现。控制胰岛素抵抗（减精制糖、减内脏脂肪、增肌运动）是断链关键。
- **识别线索**：腰围大、甘油三酯高、HDL 低、空腹血糖偏高、脂肪肝。

### 3.3 肥胖

- **机制**：肥胖常伴随全身胆固醇合成增加。研究显示**肥胖者肝 HMG-CoA 还原酶活性比正常体重者高约 60%**，肝脏是肥胖者胆固醇产量增加的主要贡献者。
- **要点**：**减重 5%–10%** 就能显著改善血脂谱，这是最划算的一步。

### 3.4 饮食因素（怎么"喂"出内源合成过多）

> 注意：这里说的不是"吃了多少胆固醇"，而是**哪些食物在催肝脏合成、堵肝脏清除**。

| 饮食因素 | 作用机制 | 方向 |
|------|------|------|
| **饱和脂肪**（肥肉、黄油、椰子油、奶油） | 直接**促进胆固醇吸收 + 促进肝脏胆固醇合成**，升高总胆固醇与 LDL-C | 催合成 ↑ |
| **反式脂肪**（部分氢化油、植脂末、酥皮点心） | 升高 LDL、降低 HDL，最坏的一类脂肪 | 双向恶化 ↑↑ |
| **精制碳水**（白米白面、甜点、含糖饮料） | 餐后血糖飙升 → 胰岛素分泌 → 肝脏把糖变甘油三酯 → VLDL↑ → sdLDL↑；同时促甘油三酯分解酶活性下降 | 催 VLDL ↑ |
| **果糖**（含糖果汁、蜂蜜、加糖饮料） | 主要在肝脏代谢，是**肝脏游离脂肪酸的重要来源**，促进脂肪肝和胰岛素抵抗；升甘油三酯能力 **果糖 > 蔗糖 > 淀粉** | 催脂肪肝/胰岛素抵抗 ↑ |
| **膳食纤维不足** | 见 3.5——纤维是把胆固醇"拉出去"的关键 | 堵排泄 ↓ |
| **酒精** | 增加肝脏甘油三酯合成 | 催 VLDL ↑ |

> **一句话**：真正在"喂养"高胆固醇的，是**饱和脂肪 + 精制糖/果糖 + 纤维不足**的组合，而不是鸡蛋本身。

### 3.5 胆汁酸肠肝循环受阻（清除端堵了）

这是最被忽视、也最能解释"吃素也高"的一条。

- **机制**：胆固醇的最大出口是**在肝里变成胆汁酸 → 排进肠道 → 随粪便排出**。正常情况下，约 **95%** 的胆汁酸会被肠道**回收**送回肝脏（肠肝循环）。
- 如果肠道**把胆汁酸截留、随粪便排掉**了 → 肝脏回收到手的胆汁酸变少 → 肝细胞胆固醇随之下降 → **SREBP-2 被激活 → 肝脏加班合成胆固醇来补**。
- **两条通路**：
  1. **可溶性膳食纤维**（燕麦β-葡聚糖、车前子、果胶、瓜尔胶）→ 结合胆汁酸、增加肠道黏度 → 胆汁酸重吸收↓ → 肝脏上调 CYP7A1 把更多胆固醇转成胆汁酸 → 血胆固醇↓。
  2. **肠道菌群** → 把初级胆汁酸转成次级胆汁酸，改变 FXR/FGF15 信号；菌群发酵纤维产**短链脂肪酸(SCFA)**，丙酸增多可**抑制内源胆固醇合成**。
- **要点**：纤维和好菌群，是"帮肝脏开口排泄"的天然手段。**纤维吃不够，等于把胆固醇的排污管堵了。**

### 3.6 药物与反跳 / 甲状腺 / 其他

- **他汀停药反跳**：他汀抑制 HMGCR 后，肝细胞胆固醇降低，会通过 SREBP 通路**代偿性上调 HMGCR 和 LDL 受体**；突然停药，肝脏合成可骤增约 **5 倍**——所以降脂药**不能自行骤停**。
- **核受体激活（如 PXR）**：某些药物（如利福平）可诱导 HMGCR 表达、上调 PCSK9，增加胆固醇合成。
- **甲状腺功能减退**：甲减会**下调 LDL 受体**、减慢 LDL 清除 → 血胆固醇升高。**血脂顽固不降，要查甲功。**
- **肾病综合征 / 胆汁淤积**：也会通过不同途径升高胆固醇。

### 3.7 成因汇总速查表

| 成因 | 卡在哪 | 典型识别线索 | 主要对策层级 |
|------|------|------|------|
| LDL受体缺陷/家族性高胆固醇 | 清除端（遗传） | LDL-C极高、家族史、黄色瘤 | **就医**（药物为主） |
| 胰岛素抵抗/代谢综合征 | 合成+颗粒质量 | 腰围大、甘油三酯高、HDL低 | 饮食+运动（减糖减内脏脂肪） |
| 肥胖 | 合成端 | BMI/体脂高 | 减重5%–10% |
| 饮食（饱和脂肪/精制糖/纤维不足） | 合成↑+排泄↓ | 饮食结构 | 膳食重塑 |
| 胆汁酸循环受阻/纤维不足 | 排泄端 | 便秘、纤维摄入低 | 可溶性纤维+菌群 |
| 甲减/药物反跳 | 清除/合成 | 怕冷乏力、正在服药 | **就医** |

## 四、解决方案：四层干预

> **总思路**：不是"少吃胆固醇"，而是三管齐下——**① 减少肝脏合成　② 提升肝脏清除　③ 增加肠道排泄**。

### 4.1 第一层：膳食重塑（基础，人人可做）

1. **脂肪换质不换量**：把饱和脂肪（黄油、肥肉、奶油）换成不饱和脂肪（橄榄油、菜籽油、坚果、深海鱼）；**彻底避开反式脂肪**（植脂末、部分氢化油）。这一替换本身即可带来可观 LDL 下降。
2. **可溶性纤维吃够**：目标每天 **5–10 g**。来源——燕麦/燕麦麸、大麦、豆类、苹果、梨、莓果、车前子壳（5–10 g/天）。研究显示可达 LDL 降 **5%–10%**。
3. **加植物甾醇/甾醇酯**：每天约 **2 g**，竞争性抑制肠道胆固醇吸收，LDL 降 **5%–15%**。
4. **砍精制糖与果糖**：不喝含糖果汁/饮料，少吃甜点；主食一半换全谷粗粮。这是断"VLDL→sdLDL"链的关键。
5. **增加 ω-3**（深海鱼、亚麻籽、核桃）：主要降甘油三酯、护血管。
6. **膳食胆固醇**：中高危人群和高胆固醇血症者，建议每天 **< 300 mg**（约 1 个蛋黄的量级）；普通人不必过度忌蛋。
7. **组合拳最强**：类似"组合膳食法(Portfolio Diet)"——可溶性纤维+植物甾醇+大豆蛋白+坚果同吃，临床一年 LDL 降约 **13%**，依从性好者可达 **13%–30%**。

### 4.2 第二层：生活方式（放大膳食效果）

- **运动**：每周 **≥150 分钟**中等强度有氧（快走/骑车/游泳）+ 每周 2 次力量训练。提升脂蛋白脂酶活性、升 HDL、降甘油三酯。
- **减重**：目标减 **5%–10%** 体重，LDL 与整体血脂谱同步改善。
- **戒烟 + 限酒**：吸烟降 HDL、伤血管内皮；酒精升甘油三酯。
- **睡眠与压力**：长期高皮质醇/睡不好 → 加重胰岛素抵抗 → 间接推高血脂。
- **复查节奏**：生活方式干预 **4–6 周**开始见效，**12 周**评估，之后每 **6–12 周**复测血脂。

### 4.3 第三层：营养素支持（营养师视角）

> 以下为**营养支持方向**，非药物替代，务必在专业指导下使用；用"营养素/膳食补充"表述。

| 方向 | 代表 | 作用点 |
|------|------|------|
| 阻断肠道胆固醇重吸收 | 植物甾醇、（茶族等） | ↓吸收 |
| 促进胆汁酸排泄 | 可溶性膳食纤维、益生元 | ↑排泄 |
| 降甘油三酯、护血管 | ω-3 鱼油 | ↓VLDL/TG |
| 改善胰岛素敏感性 | 膳食纤维、镁、抗氧化 | 断 VLDL→sdLDL 链 |
| 抗氧化、护血管内皮 | 茶多酚、维生素C/E、辅酶Q10 | 减少 LDL 氧化 |

> 内部既有呼应：`6类慢病营养修复方案.md` 中"胆固醇高 → 阻断肠道重吸收 + 促进肝脏代谢"，本手册是其**机制展开版**。

### 4.4 第四层：医学干预边界（必须就医的情形）

- **LDL-C ≥ 4.9 mmol/L（约 190 mg/dL）或强烈家族史** → 怀疑家族性高胆固醇，需就医 + 基因检测 + 家族筛查。
- **LDL-C 目标（《中国血脂管理指南2023》）**：
  - 普通健康者：**< 3.4 mmol/L**
  - 40 岁以上糖尿病等高危人群：**< 2.6 mmol/L**
  - 极高危（已有心梗/脑梗等）：**< 1.8 mmol/L**，且较基线降低 **> 50%**
- **药物**：他汀、依折麦布、PCSK9 抑制剂等，需医生处方；**他汀不可自行骤停**（反跳）。
- **红线**：生活方式是基础，但对极高危者**不能替代药物**；本手册不构成诊疗建议。

## 五、速查卡与口诀

**🔑 逻辑口诀**
> 胆固醇高 = 肝脏造太多（合成↑）＋ 身体清不掉（清除↓）＋ 肠道排不出（排泄↓）。
> 不是"吃进去的油"这么简单。

**🎯 三管齐下**
1. **减合成**：砍饱和脂肪、戒反式脂肪、控精制糖/果糖。
2. **增清除**：运动、减重、改善胰岛素抵抗、查甲功。
3. **促排泄**：吃够可溶性纤维（5–10 g/天）+ 植物甾醇（约 2 g/天）。

**⚠️ 三个"别只盯着"**
- 别只盯"蛋黄"——影响远小于饱和脂肪。
- 别只盯"总胆固醇"——**LDL-C 才是靶心**，进一步看甘油三酯/HDL。
- 别只盯"饮食"——**胰岛素抵抗、甲减、遗传**都是幕后推手。
