# ⚙️ 内容系统 · 一鱼多吃工作流

> **一句话**：每周只做一篇「母体内容」，然后拆到所有平台。不是每个平台做一份新内容，而是**一个好内容榨干**。
>
> **原话大意**：「我宁愿每周做一篇极好的内容，把全部注意力放进去，再分发到所有地方，也不愿为每个平台做一份平庸的新内容。」

---

## 一、整体飞轮（4 步）

```
验证选题 → 写 Newsletter（母体）→ 录 YouTube → 拆成短内容
   ↑                                              ↓
   └──────────── 数据反馈，回到选题 ────────────────┘
```

### 1. 先验证，再投入

选题来源只有两个：
- 近期数据好的推文 → 扩写成 newsletter。
- 赛道内已被验证的 YouTube 热门话题。

**原则**：先小成本测试，再重投入。写过 280 字还没讲清的想法，说明还没成熟。

### 2. Newsletter 是母体

- 一封深度长文 = 完整论证 = 同时是 YouTube 脚本大纲。
- 所有平台的内容都从这里「原子化」拆出。
- 母体质量决定全部下游内容的质量。

### 3. YouTube 是放大器

- 每周固定一天录制。
- 一个母体 → 一条长视频。
- 长视频又可切成 shorts / 播客 / 图文。

### 4. 短内容原子化

- 从母体里抽观点、金句、反常识、案例。
- 先写成 X 的 280 字版本（约束最强），再适配其他平台。
- 每天 2–3 条，持续供给。

## 二、五层系统

### 第 1 层 · 短内容验证

- 先写推文，用最小成本测试市场反应。
- 点赞、转发、评论 = 绿灯。
- 没反应的想法，不进入生产线。

### 第 2 层 · 验证后扩写

- 推文 → Newsletter → YouTube → 短视频/播客/图文。
- **不要每天想新东西，把一个好东西榨干。**

### 第 3 层 · 建立素材库（Swipe File）

- 收集标题、结构、句式、案例。
- 看到同行爆款，拆「为什么爆」，而不是照抄。
- 品牌 = 一组和你绑定的观点，素材库是观点的弹药库。

### 第 4 层 · AI 是助手，不是代笔

- AI 做什么：把几小时视频总结成研究简报；拆解爆款结构（钩子、痛点、转折）。
- AI 不做什么：写最终稿。
- **原话大意**：「AI 是你的实习生，不是你的代笔。」

### 第 5 层 · 比例创新

- 约 30% 用已验证的内容，70% 测试新角度/新形式。
- 哪个方向数据起来，就加倍投入。

## 三、固定六段式大纲

Dan Koe 常用的内容骨架：

1. **Audience** —— 明确对谁说话
2. **Exaggerated truth** —— 一个夸张但真实的判断
3. **Pain point** —— 对方正在承受的痛
4. **Novel perspective** —— 一个反常识的新视角
5. **Unique mechanism** —— 你自己的方法/机制
6. **Core takeaway** —— 一个能带走的核心结论

> 这个骨架适合长文、口播、公众号。视频号可压缩为：**人群 → 痛点 → 反常识 → 机制 → 结论**。

## 四、一周节奏（参考）

| 时间 | 动作 |
|------|------|
| 周一 | 定选题（从推文数据/热点里选） |
| 周二–周三 | 写 Newsletter 母体（每天约 2 小时） |
| 周四 | 录制 YouTube / 长视频 |
| 周五 | 拆短内容、排期 |
| 周六–周日 | 分发、互动、收集反馈 |

**关键**：写作是每天固定的，不是等灵感。

---

## 五、工具与流程细节

1. **一个项目文件夹**：所有素材、灵感、草稿放一处，减少切换。
2. **先收集再列纲**：先翻旧推文、素材库、旧 newsletter，再动笔。
3. **深度研究**：把视频/文章链接集中，用 AI 做摘要与交叉提问。
4. **边写边记**：写作过程中冒出的短内容想法，随手记下。
5. **批量生产短内容**：把母体喂给 AI，拆主题、矛盾点、金句、可延展角度。
6. **AI 出标题与分镜建议**：只做辅助，最终判断由人做。

## 六、对张医生的落地方案

### 你的母体是什么

- **视频号长口播 / 公众号长文** 作为母体（每周 1 篇）。
- 一篇母体同时产出：1 条视频号 + 1 篇公众号 + 3–5 条朋友圈 + 若干图文。

### 建议节奏

| 时间 | 动作 |
|------|------|
| 周一 | 定题（从选题库/上周数据） |
| 周二 | 写母体（公众号长文或视频号长稿） |
| 周三 | 录视频号 |
| 周四 | 拆公众号 / 朋友圈 |
| 周五 | 微课 / 社群分发 |
| 周末 | 复盘数据，回流选题库 |

### 你的六段式

1. 人群：30–55 岁、身体开始出问题的人
2. 夸张真话：你不是老了，是身体在漏
3. 痛点：睡不好、没力气、指标开始异常
4. 反常识：问题不在吃什么，在系统
5. 机制：万病寻源 / 身体资产模型
6. 结论：先堵漏，再进补

### AI 的边界

- 用 AI 做资料整理、结构拆解、初稿扩写。
- 最终观点、医学判断、个人故事必须你自己写。
- 医疗内容必须过合规网关，AI 不能替你担责。

## 七、常见误区

1. **每个平台单独做内容** → 产能被稀释，这正是「聚焦在散」。
2. **每天追新选题** → 没有复利，越做越累。
3. **让 AI 直接写终稿** → 没有个人声音，也没有判断。
4. **只做短内容** → 没有母体，观点无法沉淀。
5. **只做母体不分发** → 好内容浪费。
