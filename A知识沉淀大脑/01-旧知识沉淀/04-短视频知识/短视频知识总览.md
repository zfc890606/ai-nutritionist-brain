## 一、核心主题：短视频的「表现力」

表现力是短视频 IP 的第一本质。没有表现力，很难成为真正的 IP。

### 1.1 表现力是什么？

表现力起源于演员这个职业——演员的专利，是他们吃饭的家伙。一个优秀的演员能一秒入戏，把观众带入他的情绪和思维世界。

但普通人不需要成为专业演员。**每个普通人每天都在表演**——因为你日常就有无限的情绪呈现：

- 干饭聊天/喝酒时——自然融入
- 给员工开会时——气场/愤怒
- 得意洋洋时——自信
- 带小孩时——真实的烦躁与爱
- 夫妻之间——有情绪共鸣

**表现力的本质 = 情绪的表达能力。** 观众停下来看你的视频，是因为被你视频中的情绪感染了。

### 1.2 为什么表现力重要？

> 很多人上了一天班，被老板 PUA 了一天，回到家刷短视频是来寻求情绪价值的。你一上来很凶、很丑，他就划走。画面要有美感，先有停留，才有后面的内容。

张飞自己的案例：只拍了约14-15个抖音视频，已有2个陌生粉丝各支付了8940元给他——验证了表现力带来的信任和成交力。

## 二、提升表现力的两大关键要素

### 要素一：文案（内容层）

**核心原则：文案不是用来读的，是用来听的。**

#### ❌ 常见错误
- 对着提词器逐字念，眼神空洞
- 一上来就拍，对内容不熟悉
- 把文案当"稿子"而不是"大纲"

#### ✅ 正确方法

| 要点 | 说明 |
|------|------|
| **抄爆款** | 普通人不必自己创造，抄爆款文案（开头不要改，因为它已被平台验证过） |
| **熟悉内容** | 先看几遍，理解文案在讲什么核心内容。**熟能生巧，熟就会自然** |
| **提词器 = 导航仪** | 不是逐字念稿，而是帮你记住下一段要讲什么，用你自己的口语表达出来 |
| **分段拍摄** | 文案太长就一段一段拍，拍完一段停一下再继续 |
| **加入口语化词** | 如"比如这样"、"那么呢"，让对方感觉你在跟他说话 |

> **一句话总结**：提词器是你大脑的导航仪——快速锁定内容大纲，用自己口语表达出来。

### 要素二：镜头的情绪（表现层）

**核心原则：你是在跟一个真实的人对话，不是在跟镜头说话。**

#### 「拜小人」技巧

源自罗振宇的方法：每次拍视频前，先在脑海中刻画出一个真实的交流对象——想清楚他长什么样、鼻子有几根毛、脸上有几个孔，把他请到你面前来，然后跟他对话。

- 跟"小人"聊天，而不是读稿
- 想象他就在你面前，用你平时跟朋友、家人说话的方式
- 你会用逐字稿跟你老妈聊天吗？不会。所以拍视频也一样。

#### 情绪的呈现技巧

| 技巧 | 示范 |
|------|------|
| 抑扬顿挫 | 有快有慢，有停顿，有强调 |
| 手势配合 | 自然的手势帮助表达 |
| 语言停顿 | 讲到关键处停一下，制造节奏 |
| 情绪反差 | 参考疯狂小杨哥——开头巨大的情绪反差吸引停留 |

#### 交流感 vs 顶级 IP

- **入门级**：跟"小人"对话，找到交流感→这是大部分博主应该做的
- **顶级 IP**：跟自己对话，把自己讲感动→这是拥有大量粉丝后的境界

## 三、拍摄实操指南

### 3.1 画面设置

| 设置项 | 操作要点 |
|--------|---------|
| **九宫格线** | 打开网格线，**眼睛对齐上方那条线** |
| **镜头倍数** | 调到 **1倍**（不要用0.5倍默认），让人物在画面中饱满 |
| **背景虚化** | 拉至 **20-30-40**，增加纵深感、高级感，突出主体 |
| **灯光** | 注意打光，灯光非常重要 |
| **脸型优化** | 大饼脸→**侧一点**，头发**放下来不要扎**（女生） |
| **身体位置** | 身体刚好过画面两边即可 |

### 3.2 拍摄流程

```
① 调好画面设置（九宫格、倍数、虚化、灯光）
② 熟悉文案内容（练几遍，理解在讲什么）
③ 请出"小人"（闭眼想象交流对象）
④ 打开提词器作导航，用自己的话说
⑤ 开拍——正常聊天，不要念稿
```

#### 关键心态

- **允许出错**：讲错了停下来重新讲就行，剪辑软件会自动去掉重复部分
- **不必一次过**：可以一段一段拍，哪段情绪不够就重拍哪段
- **批量生产**：一个下午可以狂拍 **30-60条**，后面慢慢剪

### 3.3 剪辑要点

| 步骤 | 说明 |
|------|------|
| 速度 | 设为 **1.1倍** |
| 降噪 | 打开降噪功能 |
| 封面 | 选一帧好看的画面做封面 |
| 模板 | 套用固定模板，保持风格统一 |
| 背景音乐 | 加上BGM，音量调至 **18左右**，不要盖过人声 |
| 练习目标 | 初学者剪一条约10分钟，熟练后2分钟搞定 |

## 四、课程总结

> **把视频拍好，表现力就两件事：**

1. **文案**——不是照着念，是让别人听的。必须熟悉内容大纲，知道自己在讲什么。
2. **镜头表现力**——你是在跟一个真实的人在对话。用"拜小人"的方法找到交流感。

**不断在这两个方向上打磨自己，你一定能成为一个短视频 IP 博主。**

张飞说：**"我不管你能否成为大V，你起码做到1万粉丝绝对没问题——只要你懂得抄爆款，懂得提升表现力，一定可以在短视频这里走出去。"**

### 开场：我们今天聊什么？

好，大家先安静一下啊，我们下午的课开始了。

今天下午我们要聊什么呢？就是聊一个话题——**短视频的表现力**。

很多人会问，张老师，什么叫表现力？表现力重不重要？我告诉你，太重要了。如果你想做短视频，如果你想做IP，表现力这个东西你是绕不过去的。它是短视频的第一个核心本质。

来，我先跟大家讲一个场景。你们想一下啊，很多人上了一天班，对不对？被老板PUA了一天，累得跟狗一样。回到家他干嘛？他躺在沙发上，刷短视频。他是来找什么？他是来寻找情绪价值的，他是来让自己开心的。结果一刷到你，你那个脸凶巴巴的，画面灰蒙蒙的，整个人看起来又丑又紧张，他啪一下——划走了。

他连停都没停下来，你后面讲得再好有什么用？没有用。所以大家一定要记住一个点：**画面要有美感，要有情绪，观众才愿意停留。** 他都没有停留，你讲什么都没有用。

那我自己的抖音号，我做控场那个号，我拍了多少个视频呢？大概就拍了15个，可能14个吧。但是呢，就这么十几个视频里面，已经有两个陌生人，就是完全不认识我的，每个人都转了8940块钱给我。8940，你们算一下。这说明什么？说明我的视频他愿意看下去，他愿意相信我，他愿意跟我成交。所以表现力这个东西，它不是虚的，它直接关系到你的转化。

那今天下午我们就把这个问题解决掉——怎么提升你的表现力，怎么把这个视频拍得更好看。好，我们正式开始。

---

### 第一讲：表现力的本质——情绪

好，我们首先来理解一下，到底什么叫表现力？

其实表现力这个东西呢，最早是演员的专利。你们看过电影电视剧吧？那些演员，他往那一站，一秒就入戏了。你看他演戏的时候，你甚至看着看着，不知不觉眼泪就流下来了。为什么？因为你被他带进去了，你被他整个的感染力带动了。他的情绪传递给你了，这就是表现力。

但是人家演员是干嘛的？人家是经过专业训练的。在电影学院，人家学四年、学十年，天天练这个。那我们普通人怎么办？我们也要去电影学院学四年吗？不需要。

我告诉大家一个真相：**我们每一个普通人，其实本身就是表演大师。**

为什么？因为你每一天都在不同的情绪里面活着。你想想看啊：

你跟朋友出去喝酒的时候，你是不是很自然？你是不是一下子就能把气氛带起来？那是情绪。

你给员工开会的时候，你那个气场，你那个压迫感，你骂人的时候，那是不是情绪？那是愤怒，那也是情绪。

你得意洋洋的时候，你觉得"哇我好牛"，那是不是情绪？那是自信。

你带小孩的时候，小孩狗都嫌，在你面前闹，你是不是有情绪？烦躁、无奈、又好气又好笑，全部都是情绪。

你跟老婆老公吵架的时候呢？那更有情绪了。

所以你发现没有？**你根本不需要去学表演，你本身就活在各种各样的情绪里面。** 你只是没有把这些情绪带到镜头前面来而已。

好，那我给大家看一个东西啊。来，帮我点一下那个视频。

（播放示范视频）

大家看，同样是一句话——"我不在乎"。但是通过不同的语气、不同的表情、不同的节奏，它可以表达出完全不同的情绪。

逞强的时候——"我不在乎"（硬撑的语气）。
敷衍的时候——"我不在乎"（不耐烦的语气）。
嘲讽的时候——"我不在乎"（轻蔑的语气）。
释然的时候——"我不在乎"（放下的语气）。
开心的时候——"我不在乎"（真的不在意的语气）。

你看，同样四个字，是不是感觉完全不一样？你有没有被它感染到？有一点点对吧？这就是表现力。**表现力的本质就是——你能不能把这个文字背后的情绪，给它表现出来。**

观众停下来看你的视频，不是因为你的文案写得有多漂亮，是因为他被你的情绪钩住了。理解了没有？好，这是第一层。

---

### 第二讲：如何提升表现力——两个关键

好，那我们知道了表现力很重要，它的本质是情绪。那具体怎么提升呢？我告诉大家，就两件事。

#### 第一个关键：文案

很多人会觉得，文案嘛，不就是写稿子吗？不对。

文案它不是写给你读的，文案是写给别人听的。你注意这个区别啊——**文字是用来读的，口语是用来听的。** 你在拍短视频的时候，你是在跟一个人说话，你不是在念报纸。

那文案从哪里来？对普通人来说，最简单的方法就是——**抄爆款。**

你不用自己创作，你去找那些已经火了的视频。人家那个文案能火，是经过平台验证的，它一定有它的逻辑。你把它抄回来，稍微改一改，就可以用了。特别是开头那几秒，你最好不要改，因为那个是人家验证过的钩子。

好，那文案有了之后呢？很多人犯一个错误——文案一拿到手，立刻打开提词器，对着镜头就开始念。结果念出来的效果是什么？眼神是死的，表情是僵的，一看就是在念稿。观众一看，啪，划走了。

那正确的方法是什么呢？

你拿到文案之后，第一件事——**熟悉它。** 你多看几遍，理解这段话到底在讲什么。它的核心观点是什么？它的逻辑是什么？你把它变成你自己的东西。

我问问大家，你们有没有上台讲过话？比如说你朋友结婚，让你上去讲两句。你什么时候讲得最自然？是那个你提前准备好了、心里有数的时候，还是被人突然拉上去的时候？肯定是有准备的时候，对吧？因为你对你讲的内容熟悉，你就不紧张，你一放松，你的自然状态就出来了。

**所以提词器是什么？提词器不是读字器，是你大脑的导航仪。**

你打开提词器，扫一眼，哦，我下一段要讲这个。然后你就离开它，用自己的话讲出来。你平时怎么跟朋友聊天的，你就怎么讲。你想想，你会拿着稿子跟你妈聊天吗？不会吧。你会拿着稿子跟你兄弟喝酒吗？也不会吧。那就对了，拍视频也是一样的道理。

#### 第二个关键：镜头的情绪

好，这个是很多人最缺的。

我刚才讲了，你日常是有情绪的。但是一站到镜头前面，情绪全没了，整个人像个木头一样。为什么？因为你把镜头当成一个冷冰冰的机器了。你跟机器说话，你当然没有情绪。

所以我教大家一个方法，这个方法不是我发明的，是罗振宇罗胖讲的，我觉得特别好。

他每次录视频之前，会做一件事——**拜小人。**

什么叫拜小人？就是他往那一坐，先不着急拍。他闭上眼睛，在脑海里面刻画一个人——他想像中的那个用户。这个人长什么样，鼻子长什么样，眼睛长什么样，他甚至会想"这个人鼻子里有几根毛"。他要把他想得非常具体，然后把他请到自己面前来。

然后他睁开眼睛，这个人就坐在他对面了。他不是对着镜头说话，他是对着这个人说话。他在跟他聊天，在跟他掏心窝子。

罗振宇原话是这么说的：我往这一坐，我就在等一个小人出现。如果我那段录完了，我觉得不对劲，我就说"小人没来"，全部重来。周围的人都觉得莫名其妙——这不挺好的吗？为什么要重来？但是他知道，小人没来，就不行。

我告诉大家，这个方法我也在用，非常管用。

你现在试试看，你闭上眼睛，想一个你最想帮助的客户——他长什么样？他有什么困扰？你想跟他讲什么？好，你把他请到面前来。然后你睁开眼睛，打开提词器，好，兄弟你来了啊，我跟你讲啊——你看，你这个时候出来的语言，是不是自然的？是不是有交流感的？

**拍短视频的本质，就是你在跟一个真实的人对话。** 你找到那个感觉了，你的情绪就出来了，你的表现力就有了。

当然，这个也需要练。但好消息是，它不需要你成为专业演员，你只需要把你日常的那些情绪，搬到镜头前面来就行了。

---

### 第三讲：实操——画面怎么调

好，理论讲完了，我们来讲点实在的——实拍的时候，你的画面应该怎么调。

大家记住啊，下面这些都是细节，但是细节决定成败。

#### 第一步：打开九宫格线

这个一定要打开。打开之后你会看到屏幕上有个九宫格。你的眼睛要对齐在哪？**上面那根线。** 眼睛在这个位置，整个人在画面里面是最好看的。

#### 第二步：镜头倍数调到1倍

这个很重要。很多手机默认是0.5倍，0.5倍拍出来整个人是变形的，而且离得远，画面很空。你要把它调到1倍，这样你整个人在画面里面是饱满的，有质感的。

#### 第三步：背景虚化

在设置里面找背景虚化，拉到20、30到40。为什么要虚化？因为虚化了之后，你的背景就模糊了，人物就突出了。这个叫纵深感，有了纵深感，画面就有了高级感。

#### 第四步：大饼脸的补救方案

如果你的脸比较大，记住两点：

第一，**侧一点拍。** 不要正面对着镜头，稍微转一点点，脸会显小。

第二，女生注意啊——**把你的头发放下来。** 你脸已经大了，你还把头发扎起来，那不更大吗？拍完了你再扎回去，拍的时候放下来，遮一遮，画面好看很多。

#### 第五步：打光

灯光非常非常重要。同样的一个人，光打对了和没打对，完全是两个效果。你们自己去研究一下怎么打光，前面的光、侧面的光、顶光，去试一试。但是无论如何，一定要把你的脸打亮。

好，画面调好了，下一步干嘛？拍。

---

### 第四讲：实操——怎么拍

好，画面调好了，文案也熟悉了。这个时候开始拍。

那拍的时候要注意什么呢？

**第一，允许自己出错。**

很多人一上来就要求自己一条过。结果讲了两句卡住了，就"哎呀重来重来"，然后又重来，搞得很紧张。

我告诉你，不需要。你讲错了没关系，停下来，把刚才那句话重新讲一遍就行。现在的剪辑软件很智能的，它会自动识别重复的内容给你剪掉。你不需要一条过，你一段一段拍都可以。觉得这一段情绪不够，重拍这一段就行了。

**第二，批量生产。**

找一个下午，把你的文案全部准备好，然后一个下午拍它30条、60条。怎么拍？就按我刚才讲的，一条一条来。拍完了之后你就有几十条素材了，每天有空的时候剪一条发出去。这样你就不会每天为"今天发什么"发愁。

**第三，节奏放轻松。**

你是在跟人聊天，不是在完成任务。放松一点，自然一点，口语化一点。你甚至可以加一些废话，比如"那么"、"也就是说"、"我跟你讲啊"——这些词让你的语言更加口语化，更像一个真人在说话。

---

### 第五讲：剪辑——收尾工作

好，拍完了，最后一步是剪辑。

剪辑其实不难，我给大家说一下流程。

先调速度，我一般是**1.1倍速**，稍微快一点点，节奏更紧凑。

然后是**降噪**，打开就行。

然后是**封面**，在视频里面选一帧好看的画面做封面。选那种看起来比较有感觉的画面，一看就是大咖的那种感觉。

然后是**模板**，我建议大家每次都用同一个模板，这样风格统一，观众一看就知道是你。

最后是**背景音乐**。加一首BGM，但是音量不要太大，我一般调到**18左右**，不能让人声被音乐盖住了。

你刚开始剪的时候，一条可能要10分钟。但是你剪多了，像我一样，2分钟就搞定了——嚓嚓嚓嚓嚓，很快。所以一开始慢一点没关系，多剪就熟了。

---

### 总结：送给大家的话

好，今天的课就讲到这里，我最后给大家做一个总结。

**表现力这个事情其实很简单，就两件事：**

第一，**文案。** 文案不是用来读的，是用来让别人听的。你要熟悉它的内容，把它变成你自己的话，用口语的方式讲出来。

第二，**镜头的表现力。** 记住，你是在跟一个真实的人对话。用"拜小人"的方法，把那个交流对象请到你面前来，跟他聊天。你的情绪自然就出来了。

你只要在这两个方向上不断地打磨自己，你就一定能成为一个短视频IP博主。

我不管你以后能不能成为大V，我也不给你画那个大饼。但是——你做到1万粉丝绝对没有问题。只要你懂得抄爆款，懂得提升表现力，你一定可以在短视频这里走出去。

好了，那接下来的时间，我们实操环节，大家一个个来过。谁先来？

## 2. 底层认知：超级个体时代

> 这是徐沪生一切方法论的**地基**。先接受这个认知，方法才有意义。

### 2.1 什么是"超级个体时代"

- **核心公式**：**优质内容 + 超级个体 = 未来最佳模式。**
- **算法时代的规则**：从"完播率"时代，进入"完播率 + **互动率**"时代。**无互动，则无流量；无点赞，则无流量。**
- **只有个人能拿到互动**：再优质的内容，如果不能和一个真实的个人结合，商业转化效率就会遇到巨大挑战。
- **为什么是个人而非品牌**：社交媒体时代，个人比品牌更容易获得信任、喜爱，更容易获得效率最大的商业转化。
- **所以**：**再优质的内容，也要与一个个人结合，否则就玩不转。**

### 2.2 关键论断

- 超级个体 ≠ 必须做娱乐网红，不代表只有"低俗化"一条路。
- 乔布斯不娱乐，马斯克不娱乐，黄仁勋也不娱乐。
- 美国媒体主持人塔克·卡尔森（Tucker Carlson）的个人IP影响力已超过一个电视台（他离职FOX当天，FOX股价跌5%）——而他做的是深度新闻节目，不是娱乐搞笑。
- **本质**：网红是表象，个人IP才是本质。抓住本质——**不做娱乐网红，也可以打造成功的个人IP。**

### 2.3 "转型不转行"（一条最核心的一句话）

- 载体（报纸 → 杂志 → 电视 → 互联网视频 → 短视频）一直在变，但**优质内容永远稀缺，行当没有变**。
- 他做一条后工作内容跟当杂志总编几乎一模一样，只是"采访多了一个摄像机，文字排版变成了视频剪辑"。
- **失败的业���，本质上都是"转了行"。** 只要聚焦生活领域、制作高审美内容，媒介变化再大都能跨过去。
- 判断：2023年他看到社交媒体上90%以上的视频都是个人IP发出来的 → 超级个体时代来临。

## 3. 核心命题：创始人IP ≠ 网红IP

> 徐沪生反复强调：**做创始人IP之前，"不做什么"比"做什么"更重要。**

### 3.1 唯一的共性

创始人IP、达人IP、网红IP**都是"个人IP"，都要有一个真实的个人**。但除此之外，很多环节的**标准、商业目的完全不一样，乃至截然对立、水火不容**。

创始人/专业人士学娱乐网红模式 = 三重错误：
- **A、邯郸学步**（放弃了自我）
- **B、削足适履**（搞错了类型）
- **C、刻舟求剑**（搞错了时间）

### 3.2 商业模式不同

| | 网红 / 广告达人 | 创始人IP |
|---|---|---|
| **目标** | 追求绝对流量 | 破圈、**精准获客** |
| **变现** | 把流量卖给广告主 | 卖**自己的产品/服务**（用户目标明确、产品有限甚至单一） |
| **终点** | 捞半年流量就撤 | 打造**有质感的好品牌**，构筑门槛，**穿越周期** |

### 3.3 优势不同

- **网红的优势是娱乐能力**：稀缺（全世界娱乐明星报酬极高，正因为成功概率极低），**难以复制**——俞敏洪复制不出第二个董宇辉，李佳琦也复制不出第二个李佳琦。网红的成功概率是千分之一、万分之一。
- **MCN不制造网红**：MCN是严格的淘汰制、跟踪制，本质是**经纪人模式**，不是内容服务模式、明星学校模式。"很成功的MCN，淘汰率是千分之999。"
- **创始人的优势是专业积累**：设计公司创始人最懂设计，食品公司创始人最懂美食，服装品牌最懂时尚——在自己的行业有10年、20年积累。**这是创始人IP的起点。**

### 3.4 要打破的四大错误观点

**错误观点1："做IP就要不要脸。"**
- "别太端着、别太装"没错；但"做人讲逻辑，做IP要讲情绪/要极端/要愤怒"就是错的。
- 不要为了做IP违反自己的价值观和做人习惯，否则会卷入无休无止的网络争吵。

**错误观点2："要学会抄爆款。"**
- 抄爆款既没尊严，也会让团队丧失原创能力。一个爆款一万人来抄就卷死了。**"抄袭，偶尔得中，长期必输。"** 最好的创意是原创。

**错误观点3："追求视频数量，拍1万条你就能成功！"**
- 这是过度理科生思维——用海量生产去博概率。当你一天拍100条，质量必然最低，已被自己框死。
- **"视频产能，不重要。质量最重要。一个原创爆款视频，等于一万条低质量的视频。"**
- 徐沪生本人：从未超过一周两条，忙起来甚至停更一周。**"优质的视频，持续的时间周期更长。"**

**错误观点4："专业是流量的敌人""品位是流量的敌人"。**
- 这两句话最典型地证明了把创始人IP混同于网红IP的认知错乱。
- **"专业不是流量的敌人，而是最好的朋友、最长久的的朋友。离开了专业，离开了品位，我就是nobody。"**

### 3.5 娱乐网红模式正在衰退

- 视频号、小红书的崛起 → 优质内容IP出现井喷前夜。连抖音都要"让算法学会品位"。
- 一般网红的生命周期已缩短到半年甚至更短，翻车层出不穷。创始人若追随网红模式，同样面临这些风险。

## 4. 生产模式：把自己做成一档视频节目杂志

### 4.1 视频节目模式

MCN 模式适应网红模式（靠个人娱乐能力，难以复制）；徐沪生做个人IP，更像**"视频节目模式"**——**我来帮你打造一个属于你的节目**，IP、粉丝、流量、影响力、商业价值未来都是你的。

打造一档视频节目，背后有一整套技术，吸收了报纸、电视、互联网视频、广告、营销的经验（只是在社交媒体时代，视频更短、更碎片化、人设更有活人感）。背后有专业编导团队：
- **A** 从你的商业模式出发，弄清用户目标
- **B** 制定全套社交媒体传播战略、战术
- **C** 制定全套内容规划
- **D** 指导你拍摄、找选题、讲故事、运营账号

**核心模式**：优质内容 + 超级个体。一开始靠优质内容，慢慢把个体养大。

### 4.2 追求更大的成功概率

- 娱乐网红成功概率千分之一、万分之一（"一将功成万骨枯"）；头部MCN底层网红几十万个，5万、10万粉才进视线。
- 创始人不能让自己成为1000匹赛马之一。
- **"一个电视台推出10档节目，不可能每档只有千分之一的成功概率，不然台长、策划总监就是废物了。"**
- 《鲁豫访谈》《锵锵三人行》——个人固然重要，但节目靠的不纯粹是他们个人，团队、选题、嘉宾都在保证质量。**开局更有保障，未来更能超越周期。**
- 徐沪生自己的预期：半年10万精准粉（结果一个月就破10万）。

### 4.3 "好内容，公司造"

- 过去创始人聚焦产品、服务，不知道**自己也可以成为拥有粉丝的账号主体**。
- **"在我做个人IP之前，我也没想到，寻寻觅觅，原来全公司最理想的个人IP，是我自己！"**
- 未来所有公司可以没有传统营销部门，**必须建立自己的内容部门**：
  - 儿童用品公司 → 打造中国最好的育儿内容
  - 好医院 → 打造医生个人IP内容矩阵、最好的健康科普
  - 好餐厅 → 打造美食视频
  - 服饰品牌 → 打造最好的时尚生活视频
  - 室内设计师 → 打造最好的室内设计内容
  - to B 公司 → 你的客户就在C端读者之中

## 5. 商业价值：优质内容是最好的营销

### 5.1 传统营销模式已接近崩溃

- 靠"好定位 + 好口号"取胜的年代结束；传统营销媒介（电视、纸媒）已死。
- 传统营销今天被简化成一个动作：**促销**！上午投钱、下午要转化，只要ROI算得过来就依赖投流。
- 促销卷到最后最好的方式是**打折**——但越打折越亏损，你永远算不过平台的算法。
- **"始于投流的品牌会死于投流。"**（刘润）

### 5.2 创始人IP不能靠切片投流

- 靠大量切片、投流获客，短期可行，**长期危害极大**。
- 一味依赖直播投流、促销打折，本质还是营销味很强的"白牌""杂牌"。说破大天，还是需要**品牌建设**。

### 5.3 不会做内容的公司赚钱越来越难

- 营销是在**别人的渠道**上一次次花钱；做内容是**建立自己的渠道，拥有自己的用户**。
- 做内容**试错成本最低**；内容一旦做起来，**增长的边际成本是零**——1万阅读和1000万阅读的视频，成本相差无几。任何别的商业模式都做不到。
- 一个优质爆款视频 = 一个超大规模的投放。

### 5.4 做个人IP，要先忘掉卖货卖课

- 徐沪生个人IP **80%的内容是利他的**（分享怎么做内容、怎么做传播，分享喜欢的节目主持人、摄影师、设计师、建筑师）。
- **"做营销是讲'我的产品有多好'；做内容是讲'读者要看，可以学到什么？'"**
- **"做内容，要先忘掉推广，忘掉卖货，忘掉卖课卖服务！"**
- **"营销目标是花粉，内容是传播花粉的风。"** 营销味道越强，受众越窄，越不符合算法，越得不到流量。
- **"唯一不会被平台限流的东西，是内容。"**

### 5.5 个人IP解决"用户增长"这个最大痛点

- 徐沪生每周在办公室接待10位以上创始人，都是看了他的视频而来。见面之前已对他了解、信任甚至喜欢 → **转化率很高，免去大量低效沟通与社交**。
- **"我一个销售都不养，销售成本是0，用户都是主动前来。"**
- 创始人做个人IP可以始终站在一线，掌握用户真实反应。**"用户行为数据，是公司最有价值的资产。"**

### 5.6 塑造一个美好品牌

- 中国供应链高度饱和，下一步是**品牌的时代、审美的时代、设计的时代**。
- 未来品牌塑造，很大程度上将由**优质内容 + 优质创始人IP**来完成。
- 他做过的事：帮设计师家具学员拍一条只有三五千阅读的视频，却带来**几十万销售**；学员在安徽开民宿，账号只有几千粉丝，**入住率常年90%以上**。

## 6. 人设：三种人设，一个真实的人

> 做创始人IP最容易犯的错误：只知道卖货，没有内容意识、读者意识、利他意识。

### 6.1 内容型人设（而非卖货型人设）

- 徐沪生IP有150多万粉，但**99.9%的读者永远不会下单**——他们不上IP课、不买创始人服务，但贡献了传播的力量。
- **"他们是传递花粉的春风。没有风，花粉飞不起来，到不了远方的花蕾。"**
- 所以创始人IP人设首先不能是卖货、卖服务的人，而应是**提供利他、有价值内容的专家**。

### 6.2 专家型人设（而非娱乐型人设）

- 徐沪生 = 内容/互联网传播专家；雷军 = 高科技产品专家。
- **专家型人设最适合绝大多数创始人。** 以此为出发点，超越自己的产品，去设计利他的内容——而不是去搞笑、娱乐大众（"在娱乐领域，我们是小白，怎么演怎么尬"）。

### 6.3 真实型人设（而非虚假型人设）

- 徐沪生几乎不提及个人生活、家庭，**不过度消费隐私**，但也不过于封闭。
- **所有内容和表达务求真实，切勿虚构、模仿、抄袭。**

### 6.4 创始人IP与品牌定位

- 一条没有 slogan——**"我们就是持续出品优质视频"**，从而在用户心里形成一个说不清道不明却实实在在的认知。
- 未来品牌塑造越来越**不依赖一句slogan，而是依赖持续、丰富、立体的内容**，更感性、更有效、更真实。
- 做创始人IP人设定位、内容规划、视频风格、封面标题时，无形中也在做品牌定位、VI系统。**"未来最重要的是视频内容的VI，而不是平面VI。"**

### 6.5 创始人不能出镜怎么办？——节目IP

- **上策**：个人IP、创始人IP
- **中策**：节目IP、媒体IP
- **下策**：品牌IP、公司IP
- 不愿出镜 → 打造一个节目（例：《关于IP的那些事儿》），而不是《一条IP课》（后者是品牌IP）。
- 案例：山下有松的"山下声"；GIADA 与鲁豫合作的播客《岩中花述》。
- 思路：品牌推广可以**媒体化**——现有一个品牌大号（可能已没活跃度），可以另起一个媒体性质的号，持续生产内容，等于自己办一个电视杂志节目。
- 比例：**50条视频里，可以10—20条跟产品有关，但一定要留很大比例给内容。**

### 6.6 我不蹭热点

- 热点之所以是热点，因为有两拨不可调和的人在吵架，你站哪边都有一半人骂你；不偏不倚，两边都骂你骑墙派。
- 全民热点**无法分层**，会吸引大量非目标用户，**污染用户画像**，一旦污染很难恢复。
- **"不自说自话，也不做泛泛的大众，做精准分众。破小圈，不破大圈。"**

## 7. 内容与选题方法论

> 视频 = 故事 + 画面。核心是**用优质视频讲好故事**。打造一个创始人视频IP，等于拥有一个自己的电视频道。

### 7.1 拍什么？怎么确定选题方向

与网红抄爆款不同，创始人IP的"拍什么"是**需要根据自己的商业模式单独设计**的事情。极简的内容选题方向与比例：

- **A、内容导向的故事 —— 占比 50% 以上**
- **B、自己的故事 —— 一般不超过 20%**
- **C、产品/服务的故事 —— 一般不超过 30%**

**选题从哪里来？** 只要是一个创始人，哪怕普通人，生活创业这么多年，不可能没有故事：
- 我一生中印象最深刻的事？
- 我最喜欢的偶像？
- 创业过程中刻骨铭心的事？
- 对我影响最大的几本书、几部电影？
- 行业里的大事件，我有什么独到见解（不必无懈可击）？
- 关于顶级公司、明星企业家，我有什么看法？

> IP班有一个非常详尽的《问题清单》，很多同学写完、经编导指导去拍，原本觉得自己平平无奇的人，录的时候当场就哭了。

### 7.2 内容的第一原则：利他

**核心动作：先忘掉卖货（房间、素食、产品），站在"利他"角度设计选题。**

以"民宿 + 素食"为例的四类利他选题：
- **选题A：素食教学** —— 我有10道拿手素食，每道都能拍一条
- **选题B：装修设计案例** —— 分享民宿的设计点，供观众家里装修借鉴
- **选题C：目的地风光历史** —— "吃好住好，全国文保"，吸引同好
- **选题D：民宿周围的吃喝玩乐** —— 网红咖啡馆、宝藏小店、人文景点

**转化逻辑（这段话极重要）**：用户从利他内容进入你的主页 → 看到你民宿的内容 **不会立刻下单** → 但他了解你、信任你、关注你 → 算法记住了他 → 一个月、两个月、半年后 **当他要旅行时就会想起你** → 价钱时间合适就来下单，而且他觉得"我认识老板"。

**传播逻辑**：用户绝不会去转发"这个产品多少钱、最近在打折"的视频。你要做个人IP号，做跟商业模式密切相关的**内容**，让用户主动帮你点赞、评论、转发。积累3个月、5个月、半年，**效果会很恐怖**。

### 7.3 关于讲故事这门手艺

- 讲故事的艺术是**成系统的、可传达、可交付的**。现代报纸业300年经验、电视业百年经验、一条10多年短视频经验。
- **"永远做自己擅长的事：从自己最熟悉的专业出发，学习内容的玩法。永远用自己认同的方式，讲述符合自己价值观的故事。"**

## 8. 脚本方法论（故事是灵魂）

> **"脚本，故事本身，一定是视频的灵魂。"** 一个3分钟视频约大几百字，5分钟约1000多字。

### 8.1 要有导演意识

视频的最大好处是**巨大的信息量**——一张照片的信息量远大于一段文字。做脚本一定要有"导演意识"，知道如何用画面讲故事。**能用画面交代的，有时就无需文字。**

### 8.2 5个W（讲故事的入门艺术）

**Who / What / When / Where / Why**——谁？什么事？什么地方？什么时候？为什么？
把这5个W说清楚，脚本就成立了。怕的是拉拉杂杂说半天，读者不知道你在说什么。

### 8.3 不要在一个视频里讲太多内容

- 最终脚本也就1000字左右，**五六个点、每个点讲几句就很完备了**。
- **一条视频讲一个小故事、一个具体观点**。不要把三个故事/三个观点塞进一条视频。
- 选题颗粒要**细**、要**具体**：不要讲"家庭与工作的关系"（讲8小时讲不完），而讲"我跟我的小孩关于某某问题是怎么处理的"——这种具体问题可以列举七八个十几个。
- 具体的那件事 + 你独特的一个观点 ≈ 你的标题点。

### 8.4 不要背稿子

- 每个选题大概聊40分钟。**切忌写好稿子后看字幕、背稿子**——我们不是演员，"只要进入背稿子状态，就会非常紧张、不自然"。
- 脚本要准备充分以免遗漏，但拍摄时要**放开来讲**。稿子放手边，忘了看一眼再继续。
- 表现不佳、重复来过的镜头，**后期都可以剪掉**。不要怕、不要紧张，像平时聊天一样。

### 8.5 录音整理 → 初步删减

- 讲一个故事半小时到一小时，转成文字大几千到一万多字，**要压到1000字左右**。
- 第一步：录完尽快（当天、第二天）删减——去掉口语废话、重复啰嗦，删到2000—3000字精简版。
- **关键技巧：把2000—3000字分行排列！**
  - 不分行，你意识不到很多话是多余、重复、啰嗦的；分行如写诗，会本能进入精简状态，否则容易"散文化""杂文化"。
  - **更重要的原因**：视频字幕本身就是分行的短句子，分行做脚本就是**逼近字幕形式**。

### 8.6 初稿

- 分行后按意思分段，每段五六行甚至两三行。
- 开始考虑：**哪句话放开头吸引读者？哪句话"有余味"放结尾让人点赞转发？**
- 一个事可能有三四个角度，**最重要的角度放第二、三段**，第四段转换角度，第五段加深层次。**切忌平铺直叙、简单重复。**

### 8.7 开头非常重要（黄金5秒 / 黄金15秒）

- 大家在随机刷手机，几秒没兴趣就滑走。90%用户刷走，平台就判断完播率低，**后面再精彩也不给流量**。
- 但这不意味着靠搞笑、耍宝、发神经来抓人（现在搞笑内容也看多了，难度越来越高）。
- **反而优质内容一出来就很差异化**：要么画面一出来就好看，要么故事很独特（Who? What?），一样能吸引人。

### 8.8 定稿

- 最后取舍：重复段落去掉，不是最重要的细节忍痛割爱。
- 减之又减，按内容干货程度决定时长：**3分钟？5分钟？6分钟？** 对应1000字、1200、1500……
- **长短不是关键，关键是长度与内容匹配**（也可以500字、2分钟）。

### 8.9 尽量少做纯口播

- 哪怕是口播也别一个人脑袋从头讲到尾（单调）——除非你表达能力特别强。
- **说到什么事就配相应画面**，让视频更像"纪录片"，更丰富、更专业。

### 8.10 夹叙夹议

- 故事与观念交叉着来。**素人一般最好是讲故事，而不是亮观点**（别人可能不care一个素人的观点），但**故事够特别就不一样**。
- 故事要口语化、颗粒要细（"某年某月某一天，某个事儿"），本身不能太复杂（复杂就hold不住）。
- **结尾一般是观点、价值观，所谓"升华"一下**——但要真实、符合身份，不要太宏大叙事，不要是"感觉是个人都有"的那种观点。

### 8.11 切忌过度抒情

- 主观色彩很强的抒情一般**没有具体信息**。你自己可能很感动，但我们是素人、nobody，读者很无感，觉得空洞，会迅速滑走。
- **记叙文、议论文、夹叙夹议都可以，尽量少写抒情散文。**

### 8.12 多分析好脚本

- 学写脚本最好的办法就是**多分析别人的脚本**——把值得学习的视频**转成文字**，就能看到它脚本的完整结构。
- 不要看热闹要看门道：仔细揣摩他怎么开头，第二段、第三段……怎么结尾。
- **"多看几遍，8遍不够看10遍。无他，唯手熟耳。"**

### 8.13 脚本是灵魂，创始人最好亲自打磨

- 徐沪生在自己的账号上花的时间越来越多：录音转文字**第一时间亲自整理**（过几天记忆就不清晰了，录音转文字不百分百准确，久了自己都分辨不出来）。
- **"什么都可以让别人做，脚本最好自己做。无他，你自己说的话，自己最清楚。怎么精简，自己最有感觉。"**
- **"社交媒体传播，90分的作品，可能流量比80分的作品大10倍，比60分的作品大100、1000倍。"**
- 他所有视频的标题都是自己起的，有时候反复起很多次，且要在选定封面上做出实际效果（**标题单看文字 vs 做在图片上，很不一样；一定要用手机预览，不要在电脑上看大图**）。
- 一条拍摄一条视频，从选题、前期沟通、拍摄、出脚本、剪辑到账号运营，**标准化动作多达221个**。

## 9. 出镜·口播·对谈·采访

### 9.1 面对镜头紧张怎么办？——不要对着镜头

- 徐沪生录视频时，**对面坐着一个人，跟Ta聊天的状态**。
- 对着空镜头、空椅子讲话我们没干过，只有受过表演训练的人才有经验。
- 面对镜头大家会紧张、不自然；但跟对面的人讲话，我们做了一辈子，不需要训练。

### 9.2 做自己就可以

- 大多数创始人表达能力比一般人强很多（工作之一就是说服、沟通）。
- 回到正常状态、回到过去就可以，就不紧张了。**有手势、有语病，后期都可以剪掉。**
- 录半小时一小时，最后剪出3—5分钟，不好的都能剪掉——**这不是直播。你平时怎么讲话就怎么讲话。**

### 9.3 怎么做对谈视频？

- 掌握找选题、写脚本、做口播后，做对谈、采访也一样，**无非是多一个和对方的事先沟通**。
- 机位：**两到三个机位**——一个拍全景，一个拍你，一个拍嘉宾。后期剪辑。

### 9.4 如何做采访？

- 外景采访多了外景拍摄，摄影师需**提前踩点、沟通**。
- 拍摄时充分拍全：全景、中景、特写、说话镜头。后期按逻辑主轴剪辑。
- **创始人在现场拍完自己出镜的画面就可以离开**，空镜头、细节特写团队留下来慢慢拍、拍到极致——**毕竟创始人时间最有限**。

## 10. 白痴用户思维

> 徐沪生反复强调：**这一点非常非常重要。**

- 在找选题、写脚本、视频开头、起标题时，**一定要跳出自我，站在用户角度审视自己的内容**。
- 视频阅读在手机完成 → 视频和封面都要**在手机上预览、反复预览**，切忌在电脑上看过就定了（电脑看OK的封面标题，手机上可能完全不吸引人）。
- **刻意让自己进入懒散的、躺在沙发上胡乱刷视频杀时间的状态**，去看自己刚想出来的标题。
- **"所谓白痴用户，就是他们对你一无所知，也丝毫不感兴趣。"** 要经受别人地狱级别的隔膜、麻木、挑剔；要假设别人对你的内容毫无兴趣，三秒钟觉得莫名其妙就滑走。
- **"千万不要假想别人对你的内容非常好奇！这么想就危险了，极其容易陷入自嗨。"**
- **"要无限逼近目标用户那随机的、毫无目的的阅读状态。这一点很难，需要反复练习、长期练习。"**

## 11. 账号运营与看数据

### 11.1 起号细节

- 刚起号那一周，**给每个关注、点赞的用户送出一朵感谢的小红花，送出了几万朵。**

### 11.2 平台选择

- 一般建议在**视频号、抖音、小红书同步分发**，不做适应平台的不同版本（工作量太大；定位和用户画像不该不一样）。
- **按人群/客单选择重点平台**：
  - 偏女性用户、生活方式内涵强的创始人IP → **小红书**为重点
  - 产品偏大众消费、客单价相对低 → **抖音**为重点
  - 社交推荐占比高的（商业咨询、知识教育类）→ **视频号**为重点
- 想做**高客单**一定要做视频号；想做**优质内容**可小额投流。

### 11.3 优质内容是最好的运营

- **运营最轻**：一个小朋友兼职即可，评论管理也很轻。**不建议重度运营，不提倡过多运营手法、工具。**
- 聚焦优质内容生产：**内容好 → 流量高、涨粉快、可信度高、商业转化率高**。
- **要学会看留言区**，与客户适当互动。**最活跃的留言区，几乎等于一个社区。**
- **"流量有了，运营也就很轻，商业转化也可以很顺。一切都如水就势，无需推动。"**

### 11.4 如何看数据？（两张流量表 / 内容漏斗）

- **区分"求流量的视频"和"求转化的视频"**：
  - 前者**看数据**（不必要求转化）
  - 后者**看后续的商业转化**（不必要求太高的流量）
- **两列流量表的数据要求至少相差10倍。**
- **"不要在一个视频里既要、又要、还要——我们通过不同的视频，实现既要、又要、还要。"**（既要流量，又要转化，还要品牌）
- 追求流量的视频不必太关注转化；追求转化的**专业型视频不必太关注播放量，尤其不要起泛流量标题、做泛流量开头**。
- **"平庸的视频，流量往往为零。一个爆款有时可以一针捅破天。"**

## 12. 团队搭建

### 12.1 这是内容团队，不是市场营销团队

- 很多公司有市场部、营销部、销售部、公关部、广告部，**但没有内容部门**（广告部往往是发标案给外面公司，自己并不生产内容）。
- **"你今天是要来做内容、做3—5分钟短视频，这样的内容团队跟过去的市场部、广告部非常不一样。"**
- 内容需要**持续生产**（每周），必须有自己的内容部门；哪怕跟外部摄影、剪辑合作，也**得有一个自己人懂内容、对内容负责**。

### 12.2 最低配置：一个创始人 + 一个年轻人

- 这个年轻人要**会写、会拍、会剪**（不多见，一般招一个编导配）。
- 哪怕是创始人 + 一个年轻人，在公司内部也是**高配部门**——对未来具有战略意义的**增长部门**。因为**任何公司最值钱、最稀缺的就是创始人的时间**。

### 12.3 中等配置：一个编导、一个摄影师、一个剪辑

- 强调的不是公司规模，而是**你重视这个事**。
- **编导**（最重要）：辅助创始人做内容统筹规划、文字与故事处理，需较强内容生产能力。
- **摄影**：口播为主要求不高；采访型视频要求较高。
- **剪辑**（作用常被低估）：要理解创始人特性，从大量材料中取舍，掌握节奏、画面与文字搭配——**"剪辑才是最后掌勺炒菜的人"**。
- **运营**：一般无需专职，由内容团队某人兼任。

### 12.4 适当放宽招聘要求

- 中小公司很难招到一流内容人才（一流人才在专业团队或顶级品牌，没理由来一个从0开始的中小公司）。
- 最好选择：**年轻人**（大学毕业生、工作两三年、文科有文字能力的；摄影剪辑是专业学校毕业、专业过硬的即可）。
- **不要提太多社交媒体经验要求**（经验丰富者一般已做过大V，没有理由来帮你从0到1）。

### 12.5 MCN 和网红的运营经验，一般不适用于创始人IP

- 不能像MCN那样每天拍10条、快速生产、扔出去看数据——**天天开盲盒找爆款会破坏品牌调性**。
- 创始人不同于全职网红：每天拍10条，创始人什么事都别干了。

### 12.6 区分广告、影视剧与短视频的逻辑差异

- 面试团队时**侧重讲故事的能力、偏短视频的经验**，而不是拍过电视剧或15—20秒广告片。

### 12.7 面试团队需广撒网

- 完全没经验的创始人，**建议面试10个8个甚至更多**（面试本身是了解学习的过程）。
- 对年轻人最重要的不是社交媒体经验，而是**学校、专业，尤其是"靠谱"**。
- 视频拍摄需要摄影、剪辑高度配合，要**团队合作精神、善意、补台而不是拆台**；复盘时**先找自己的问题**，流量起伏时勇于承担责任。

### 12.8 能力不足者不取，风格过强者慎用

- 水平低的人不能用；**水平特别高、想做自己导演的也要小心**。
- **"你的个人风格不能凌驾于我一条的风格"**——媒体有媒体的专业，带一定模式化、程式化、流程化，同时也讲究流程、标准、风格。
- **"不能说摄影师的风格大过创始人本人的风格，或者剪辑的风格凌驾于摄影、凌驾于编导。一定是大家定下来，所有人都要遵循这样一个风格。"**
- 不建议创始人找身边做导演/厉害摄影师的朋友：风格不一样、会凌驾于你，且"杀鸡用牛刀，屈尊俯就"。
- 反而是**与你价值有共鸣、觉得这是机会、充满激情好奇的年轻人**更合适。

### 12.9 择能力最强者做小队leader，但核心还是创始人

- 小团队一开始可不设leader，跑起来看，能力最强者（无论编导/摄影/剪辑）做leader。
- **但最核心的还是创始人本人**——不要把模式、路径、风格的问题都交给这个人，**尤其在从0到1阶段，创始人对自己的了解最清楚**：方向朝哪走？用户是谁？讲哪些故事？什么风格？

### 12.10 创始人的持续学习至关重要

- 线下训练营小班制，20人坐着做作业，可能一个大学生旁边坐着一个大市值公司的创始人，**连着脱产学6天**。
- 创始人角色 = **制片人 + 出品人 + 主演**的奇特组合。这些都需创始人自己理清。

## 13. 最重要的是立项

### 13.1 切勿"随便做做"

- 意识到价值却以"随便做做"自我安慰——**"随便聊聊，还不如不做。"**
- 想清楚做个人IP是不是公司一件大事情？如果是，就**立项**：腾出自己时间，配起基本团队。
- 怕丢脸、留"后路"毫无必要——"做创新之事如果还有这些心理障碍，患得患失，遇到任何障碍都会放弃、缩回去。"

### 13.2 不立项，就谈不上从0到1

- 都说从0到1最难，其实**最难的是达到"0"的状态，也就是立项**。很多人还处于**负数状态**——思维精力陷在传统模式里。
- 他们在隔岸观火，信息中途损耗变形，周围的人同频、意见都是反对、怀疑、观望的。
- **等到他们觉得毫无风险、成功案例越来越多，才结束观望——而这时候一切都晚了。**

### 13.3 行动快的人，最能拿到结果

- 有学员听完课回去就辞职，不折不扣执行，号很快做出来（从几千阅读做到单条200万阅读）。
- 有个浙江制造业创始人说：① 具体怎么做我不知道，但我知道一定要做社交媒体营销；② 已花半年把工作分给几个副总裁，腾出精力；③ 要找最专业的人来做。
- **善于行动的人**：① 下决心（此事非做不可）；② 腾出时间（对所有创始人都要花时间调整）；③ 花时间在手机上研究、出来上课学习请教——**信息茧房顿时被打破，这时才能从0到1起步**。

### 13.4 一上来就想出爆款的人，最容易放弃

- 做创始人IP不是做广告案子（广告是一次性的），**要靠持续输出内容**，天然带极强"私人定制"色彩。
- **前面两三个月基本就是熟悉、测试、总结**（其实两三个月一眨眼就过去了）。
- 有个二手奢侈品手表客户说："我不指望马上出结果，因为如果那么快就能出结果，就说明这个事门槛太低了。"

### 13.5 等待，有时候是最重要的战略

- 做项目很多人忽略一个动作：**等**。就像植物生长需要时间——只要土壤对、种子对、播种动作对，就耐心等待，**不要天天盯着禾苗转**。
- 只要比常人**延迟满足几个月**，可能就非常不一样。**"内容决定读者，优质内容需要优质读者，独特的内容吸引同频之人。"**
- 等有两种：势头好时的"等"= 不设过高目标、不好大喜功；势头一般但动作对时的"等"= **"熬"**。**"时候到了，你想要的东西自己会找上门来。"**

### 13.6 创新都是被逼出来的

- 不遇到恶劣环境、轻松就能赚钱，没人愿意大胆尝试创新。**"当年不是纸媒要完蛋，我也不会走向互联网。转型之后才发现空间比过去大了几百倍。"**
- **"危机危机，危中就有机。"**

### 13.7 产品80分，传播0分，该提升哪一个？

- 很多"工匠型"创始人埋头做产品、线下服务，但客人越来越少。
- 把产品从80分提到85、90分非常艰难且用户未必有感知；**把传播从0分提到60、70、80分，就是打开一片全新天地**。
- 很多时候问题根本不在产品、不在服务，而在于**你很久没做任何传播工作**了。

## 16. 金句与价值观

- **"转型不转行。"** —— 载体一直在变，优质内容永远稀缺。
- **"优质内容 + 超级个体 = 未来最佳模式。"**
- **"网红是表象，个人IP才是本质。"**
- **"做创始人IP之前，'不做什么'比'做什么'更重要。"**
- **"做营销是讲'我的产品有多好'；做内容是讲'读者要看，可以学到什么？'"**
- **"营销目标是花粉，内容是传播花粉的风。"**
- **"唯一不会被平台限流的东西，是内容。"**
- **"专业不是流量的敌人，而是最好的朋友、最长久的的朋友。离开了专业，离开了品位，我就是nobody。"**
- **"一个原创爆款视频，等于一万条低质量的视频。"**
- **"所有的内容和表达，都要务求真实，切勿虚构，切勿模仿，更不能抄袭。"**
- **"破小圈，不破大圈。"**
- **"有留量的流量，才是有价值的流量。"**
- **"内容决定读者。优质内容需要优质读者。独特的内容，吸引同频之人。"**
- **"时候到了，你想要的东西，自己会找上门来。"**
- **"在一本正经与鲜廉寡耻之间，我总能找到合适的姿势。"**
- 核心价值观：**长期主义**、**利他**、**原创**、**专业与审美是护城河**、**不迎合低俗**。

## 17. 对张医生（AI营养师）的可借鉴之处

> 徐沪生的路线与你"医生 → AI营养师"的专业型转型**高度同构**：都是"专业人士 + 优质内容 + 超级个体"，都不该走娱乐网红路线。以下是最可直接迁移的点：

1. **专家型人设**：你的稀缺性是"医生 + AI + 营养"的专业积累，正如徐沪生是"媒体30年"。**卖专业，不卖货**。
2. **内容第一原则是利他**：像"民宿×素食"四选题那样，把营养/健康知识拆成**可教学、可借鉴、可分享**的系列内容，而不是"产品多少钱、最近打折"。
3. **选题颗粒要细 + 5个W**：一条视频讲一个具体问题（"高血压患者早上该不该喝粥"），而非"如何健康饮食"这种大概念。
4. **两张流量表**：把**科普破圈视频**（求流量，起泛流量标题）与**专业转化视频**（求转化，不起泛流量标题）分开做，**不要一条视频既要又要**。
5. **脚本方法论**：录音转文字 → 删到2000—3000字 → **分行排列**逼近字幕 → 定开头（黄金5秒）+ 结尾升华；**不背稿、对着人讲**。
6. **白痴用户思维**：你的目标用户对营养学一无所知且不感兴趣——**在手机上反复预览标题封面**，不要陷在"我是专家"的自嗨里。
7. **平台选择**：健康科普偏专业、偏知识类 → **视频号为重点**（社交推荐占比高）；若做大众向健康内容可兼顾抖音/小红书。
8. **立项优先**：最难的是"从负数到0"——先下决心立项，腾出时间，再谈方法。**行动快的人最先拿到结果。**
9. **团队**：最低配置 = 你（创始人）+ 一个会写会拍会剪的年轻人；招募看"靠谱 + 专业学校背景"而非社交媒体经验。
10. **对照你现有体系**：可直接与本库 [[清华陈晶|清华陈晶]] 的"短视频+直播双轮"打法互补——**徐沪生强在"内容/脚本/人设"的内容供给侧，陈晶强在"直播/转化/小而美"的商业侧。**

## 2. 爆款视频五段式结构

> 把他公开的几条代表性视频逐字稿（合群演讲、劝酒演讲、打工访谈、强者思维）拼起来，结构高度一致，是一个**五段式模板**。

### 2.1 ① 开头 0-3秒：反常识观点直接甩脸

**不是自我介绍，是观点炸弹**。第一句话就抛一个反常识判断：

> "我人生中就打过一次工，就在新东方四年……后来我觉得不能再打工了，因为打工不可能赚到钱，只要打工就永远被别人踩在脚下。" ——《打工不可能赚到钱》

> "大家好，我是李尚龙。我是一个英语老师，但是我更被人熟知的职业，是一个作家，中年滞销书作家，书基本卖不出去，都靠送。" ——《你以为你的合群》

**第二句的精妙**：表面自我介绍，实际是**身份反差 + 自嘲**。"作家"×"滞销"、"英语老师"×"卖不出去"，两秒内制造反差感和好奇心。

> ⚠️ 他的核心理念："**前3秒定生死。3秒留不住人，后面写得再好也没有人看到。**"

### 2.2 ② 第二层：甩一个"具体的人的故事"（他人故事引发共鸣）

开场观点之后不讲道理，先讲故事。典型用法：**用一个普通人逆袭的案例**给观众代入感和"我也可以"的暗示。

- 讲"合群"→ 先讲一个**专科生**专升本、考上北师大研究生的故事
- 讲"劝酒"→ 先讲自己如何被宋方金老师"套路"只喝茅台
- 讲"强者思维"→ 讲自己做考虫时"以终为始"的决策

> **逻辑：故事负责情绪，观点负责记忆。** 观众记不住道理，但忘不掉故事里的人。

### 2.3 ③ 第三层：落到"我"的亲历（身份即证据）

他人故事之后，一定是**自己的血泪经历**——这是整条视频的信任核心：

> "我在新东方四年……看到别人去创业，我也觉得'我也没有比他差，为什么不去试一试'，于是就去创业了。"

从军校退学 → 新东方 → 创业亏光再翻身。**"我"就是他所有观点的论据。**

> ✅ 对照你的"删我测试"：删掉全文的"我"，他的视频只剩一句干巴巴的口号——**身份即内容**。你的"农村娃→医学院→三甲麻醉→开店亏光→AI营养师"是同样的素材。

### 2.4 ④ 结尾：金句收束 + 价值观锚点

最后一句一定是一句**能截图传播的短句**，也就是"传播原子"：

> "真正的青春是无界的。" / "低质量的社交，不如高质量的独处。" / "以终为始、尽人事、听天命。" / "选择不做什么，比选择做什么更重要。"

> ✅ 每条视频 = 一个可一句话转述的观点（传播原子检验通过）。

### 2.5 ⑤ 隐藏层：信息差（差异化内容源）

他做视频**不写稿、每天只花5-10分钟**，靠**信息差**：把海外前沿的科技/教育/AI内容用中文口语化转述。选题本身稀缺，绕开同质化竞争。

> 对照：把**医学指南/国外研究**翻译成老百姓听得懂的话 = 你的信息差。

### 2.6 五段式结构总览

```
① 开头0-3秒 ── 反常识观点炸弹（身份反差/自嘲/痛点直击）
     ↓
② 他人故事 ── 普通人逆袭案例（引发共鸣、"我也行"）
     ↓
③ 我的亲历 ── 血泪经历（身份即证据、建立信任）
     ↓
④ 金句收尾 ── 一句可截图传播的话（价值观锚点）
     ↓
⑤ 信息差选题 ── 别人讲不了的稀缺内容（差异化护城河）
```

### 2.7 弱传播 · 讲故事方法论（混沌大学增长大会）

> **"这个时代从来不缺讲道理的人，缺的是讲故事的人。"**

**为什么讲故事**：短视频时代传播靠"弱传播"——强者示弱、讲道理不如讲故事。一上来就"一二三"讲道理，观众多半直接划走；**把观点包装在故事里，才有人看完**。这也是他视频"风格真实"的底层来源。

**写故事的四个要素**：

| 要素 | 含义 | 例子 |
|------|------|------|
| ① 人物要有变化 | 30秒视频，开头和结尾的人物必须发生巨大变化（不变=没故事） | 专科生→北师大研究生 |
| ② 连贯性与因果关系 | 参考《后真相时代》："国王死了，王后死了"不是故事；"国王死了，王后悲痛欲绝，所以王后死了"才是故事 | 创业失败→所以转做AI |
| ③ 升华到主题 | 普通故事往上走一步就是主题（引用叔本华"人有两次出生"） | 个人逆袭→"人是可以重生的" |
| ④ 注入价值观/意识形态 | 没有价值观的故事不成立 | 每条都指向"不努力不如不活" |

**三个万能故事公式**：
- 公式一：**目标 + 困难 + 努力 + 结局**
- 公式二：**目标 + 困难 + 努力 + 结果 + 意外 + 第二次努力 + 结局**
- 故事必须有目标：《肖申克的救赎》目标=自由、《我不是药神》黄毛目标=活着、《泰坦尼克号》目标=在一起；实现目标=喜剧/正剧，没实现=悲剧

> ✅ 嫁接你的故事：一个顾客从"指标爆表"到"逆转" = **目标**(降指标) + **困难**(外卖/应酬/没时间) + **努力**(营养方案) + **意外**(复查数值反复) + **第二次努力**(调整方案) + **结局**(指标回落)。这条弧线本身就是完整故事，自带传播力。

## 4. AI辅助四步工作流

> 他在AI破局大会公开的可复制流程（也是《AI爆款文案》第五章的核心）。

| 步骤 | 动作 | 核心标准 |
|------|------|---------|
| ① 选题 | 自己感兴趣 + 大众感兴趣 | "有血有肉、又高兴又难受" |
| ② 观点共创 | 让AI给"反常识、别人想不到"的视角 | 跳出固有思维，找差异化 |
| ③ 大纲共创 | 让AI出大纲，反复调优 | **保留个人风格的关键环节** |
| ④ 钩子逐字稿 | 让AI写"前3秒留人"的开头 | 提问/反差/颠覆认知/戳痛点，口语化 |

### 4.1 灵魂动作：让AI反向提问

> **"让AI来问你话，而不是让AI替你说话。"**

- ❌ 错误用法：直接对AI说"给我出个稿"
- ✅ 正确用法：对AI说"**请你针对这个话题，问我10个问题，帮我梳理我对这件事的真实看法**" → 再把你回答的内容喂回给AI整理成脚本

> 核心逻辑：**AI知道全世界所有的知识，唯一不知道的是你的观点。** 这样的内容100%是你的个人风格，完全没有"AI感"。

### 4.2 可直接套用的提示词框架

1. **选题校准**：让AI列出10个"自己感兴趣+大众也感兴趣"的选题，并标注情绪点（共鸣/反差/痛点/爽点）。
2. **观点共创**：让AI找出3-5个"反常识、别人想不到但能戳中用户共鸣"的独特观点。
3. **大纲共创+调优**：让AI生成"开头-中间3个论点-结尾升华"的结构，每部分标注情绪钩子，再反复调优到贴合自己的话。
4. **钩子开头+逐字稿**：让AI写前三秒留人的开头逐字稿，要求口语化、无AI感、能代入本人语气。

### 4.3 《AI爆款文案》核心工具箱（2025新书细化）

- **12大高效指令公式 + 13个高频应用场景**：让AI 10倍速产出，底层逻辑是"**数据洞察 + 算法生成 + 人性共鸣**"
- **STAR公式**（情境Situation-任务Task-行动Action-结果Result）：让AI生成高质量文案
- **AIDA公式**（注意Attention-兴趣Interest-欲望Desire-行动Action）：让AI生成转化型文案
- **EPAC公式**：电商文案销量翻倍
- **短视频文案三套路**（第五章）：让AI帮你写"开头-展开-结尾"三件套
- **关键判断：开头决定播放量** —— 标题/第一句决定用户是否点进来（对应"前3秒定生死"）
- **A/B测试选标题**：让AI批量生成不同风格标题，再测试选最优
- **适用场景**：朋友圈文案、短视频脚本、电商详情页、广告标题、公众号引流、邮件、PPT

- 这与你脚本系统的"价值观锚点"同原理：**重复不是啰嗦，重复是记忆**

**2. 真实感的三个来源**
- **不写稿即兴口播** → 临场感、呼吸感、说错重说 = 老师式表达
- **身份即证据** → 每个观点都有自己"亏过400万/做过3亿营收"的真实经历兜底
- **弱传播姿态** → 自嘲（"中年滞销书作家"）、示弱、不端着，降低观众防御

**3. 有价值常识的观点（大白话金句）**
- 观点都是"人人都懂但没人点破"的常识："你只是看起来很努力""稳定是浪费生命"
- 稀缺的不是知识，是**把常识说破的勇气**

**4. 真实但合规的分寸**
- 他的争议在于"制造焦虑"的部分；你要吸收的是"制造共鸣"的部分
- 真实 = 说真话 + 有经历支撑 + 示弱，**不等于贩卖焦虑**

## 2. 核心理念：短视频+直播双轮驱动

> **核心公式：短视频是电梯广告，直播是大卖场**

### 2.1 双轮驱动模型

```
       ┌─────────────────┐
       │  短视频（电梯广告） │ ← 快速吸引注意力、破圈传播
       │   → 痛点选题       │
       │   → 爆款开头       │
       │   → 人设展示       │
       └────────┬────────┘
                ↓ 流量导入
       ┌─────────────────┐
       │  直播（大卖场）    │ ← 深度转化成交
       │   → 黄金开场       │
       │   → 4步钩子心法    │
       │   → 高客单转化     │
       └─────────────────┘
```

### 2.2 变现逻辑链条

```
爆款破圈 → 吸引注意力
     ↓
人设认同 → 留住用户（70%因价值观买单）
     ↓
产品转化 → 低价课引流私域 → 高客单价成交
     ↓
私域复购 → 用户成长路径：入门→成长→成熟
```

### 2.3 关键洞察

- **短视频解决"广度"**：用爆款内容破圈，让更多人知道你
- **直播解决"深度"**：用实时互动建立信任，当场转化成交
- **人群垂直 ≠ 内容垂直**：内容不要只讲专业，要围绕目标人群的真实生活场景展开
- **两者互补**：短视频引流来的粉丝，到直播间完成信任和成交

## 3. 短视频创作方法论（五大要点）

### 3.1 五大核心要素

| # | 要素 | 具体方法 | 自检问题 |
|:-:|------|----------|----------|
| 1 | **选题** | 罗列行业中用户最关心的前60个问题，逐一解决 | 这个问题你的目标用户真的在搜吗？ |
| 2 | **开头** | 设计爆款开头，结构化话术框架 | 前3秒能让人停住吗？ |
| 3 | **场景** | 画面信息量比语言更大，让场景替你说服人（老师站黑板前 > 端坐） | 观众一眼能看出你在什么场景/身份？ |
| 4 | **清晰度** | 擦镜头、换好手机，清晰度可以"干掉一半对手" | 你的画质在信息流里能脱颖而出吗？ |
| 5 | **对话感** | 不看镜头，想象对面有一个真实的人，去回答他的问题 | 像不像在跟朋友聊天？ |

### 3.2 选题方法论

- **不是自己想讲什么，而是用户在想什么**
- 列出目标用户最关心的60个问题 → 逐个击破
- 每个问题就是一条视频的选题
- 痛点越具体越好，不要"大而全"

### 3.3 爆款案例拆解

**《清华的孩子大概率上不了清华》**（6000万播放，涨粉25万）

```
选题：教育焦虑 + 身份反差（清华人说"上不了清华"）
开头：身份颠覆性陈述，3秒抓住注意力
结构：问题 → 分析 → 解决方案
情绪：先制造认知冲突 → 再给解
传播力：引发了全行业的模仿翻拍 → 成为"教育爆款模板"
```

### 3.4 视频号趋势判断（2026年）

陈晶预判视频号内容创作的五大趋势：

1. **长视频的天下**：优质用户更喜欢深度内容，不是越短越好
2. **强人设 > 强内容**：独特的价值主张比内容技巧更能吸引受众
3. **垂直精准流量竞争**：泛流量时代结束，精准才是王道
4. **打造内容资产**：不是单点爆款，而是有体系、有深度、有价值主张的内容矩阵
5. **全面AI化**：善用AI工具提升效率

### 3.5 成交型短视频破题法（开头深化 · 30%成交型专用）

> **一句话心法**：不是拍热闹，是拍"那个愿意付钱的人"；开头第一句不是让他刷到，是让他认出自己。
> **来源标注**：本小节是对陈晶「开头」要素的落地深化（非陈晶原话），结合成交型短视频实操整理。已同步进 [[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统\|视频号脚本风格系统]]「开场模式D」。

**核心区分：成交型开头 ≠ 流量型开头**

| | 流量型开头 | 成交型开头（破题） |
|---|---|---|
| 目标 | 最大公约数 | 最小精准群体 |
| 第一句话 | 抓所有人 | 筛出"愿意付钱的那个人" |
| 衡量标准 | 2秒停留率 | 目标客户说"这说的就是我" |
| 错的人划走 | 灾难 | 成功（筛选器在工作） |
| 关键词 | 焦虑、好奇、反差 | 点名：病症/指标/处境/花的钱 |

**三层点名法** —— 第一句话完成破题，点得越狠越到位：

| 层 | 点的是什么 | 示例 |
|---|---|---|
| ① 点「人」 | 目标客户的身份标签/处境 | "你朋友圈里有没有这种人——体检报告一堆箭头，天天问'我到底该吃啥'" |
| ② 点「事」 | 他正在经历的糟糕结果 | "你回一句'要不吃点蛋白粉'，然后就没下文了" |
| ③ 点「钱」 | 他花的冤枉钱 / 丢掉的收益 | "不是你产品不行，是你给不出方案" |

**成交型破题公式库（5个）**：

| 公式 | 结构 | 示例 |
|------|------|------|
| 指标点名 | "你[指标]上如果有[XX]，[一句扎心后果]" | "体检报告上如果有'脂肪肝'三个字，医生只会让你少吃油——可你没少吃吧？" |
| 症状处境 | "你是不是[具体处境]，[结果]" | "你是不是每年体检血脂都偏高，回来照样该吃吃该喝喝，然后等着它变成每天吃降压药？" |
| 冤枉钱 | "为了[问题]，你花了多少[钱/力气]，[白花]" | "为了把血糖稳住，你这些年买过多少'降糖茶''降糖饼干'？大概率白花。" |
| 案例结果 | "[人]用[方法]，[结果]，今天拆给你" | "上个月一个阿姨，脂肪肝三年，我帮她算了三个月的营养账——前两天她跟我说了句话，让我想了一晚上。" |
| 客户处境 | "你手上有没有[这种客户]，[你的尴尬]" | "你朋友圈有没有那种人——天天喊'我到底该吃啥'，你回一句'吃点蛋白粉'，就没下文了？" |

**破题3问（写完逐条过）**：
- 目标客户听完会不会说"这说的就是我"？不会 → 没点名
- 第一句里有没有"愿意付钱的问题"？没有 → 只是共鸣不是成交
- 错的人听完会不会划走？不会 → 太泛，筛选器失效

**成交型短视频完整结构（6步）**：

```
① 破题（0-5秒）   点名付费问题，让对的人停下
② 信任（5-20秒）  "我凭什么能解决"——身份→专业→案例→真诚
③ 挖痛（20-35秒） 你为什么一直没解决（诊断，让他对号入座）
④ 解法（35-50秒） 具体怎么做（路径/步骤/方案），不是概念
⑤ 证据（50-55秒） 一个可验证的结果/案例/数据
⑥ 行动（55-60秒） 低门槛、明确CTA——"评论区扣1，我帮你看看"
```

**信任表达4来源**（紧跟破题后，回答"凭什么是你"）：身份背书（三甲医生）→ 专业细节（内行才知道的）→ 案例见证（具体的人+结果）→ 真诚暴露（加一粒"沙子"，暴露一次失败）。

**落地案例**：[[B自媒体大脑/01-视频号创作/交付脚本库\|script-080]] 开头从"总有人问我……"改为点名破题，预测2秒跳出率 38% → 30%。

│+ 做减法 │ │问题"   │ │   做减│
│   拒绝  │ │不是卖  │ │   法  │
│   90%   │ │产品而  │ │       │
│   客户  │ │是解决  │ │       │
└────────┘ │问题    │ └────────┘
           └────────┘
```

### 5.2 人设定位（一体两翼）

> **核心公式：人设 = 有结果 × 有价值观 × 有经历**

- **一体**：你的核心身份（一句话说清你是谁）
- **两翼**：
  - 左翼：专业能力（你做成过什么）
  - 右翼：价值观主张（你相信什么、反对什么）

**关键认知**：
- 客户购买，**70%因为喜欢你的价值观，30%才是专业**
- 你不是在卖专业，是在卖理念、立场、价值观
- **中庸是IP毒药**，敢站队才能吸引同频受众

### 5.3 人群定位（做减法）

- **明确"你想赚谁的钱"**
- 对客户分类：高净值、高刚需、高信任……
- **拒绝90%的客户**，聚焦核心人群
- "弱水三千，只取一瓢"

### 5.4 需求定位（不是卖产品）

- **不是卖"钻子"，是帮客户解决"钻孔"的问题**
- 定位要回答：**帮一个什么样的客户，解决一个什么样的具体问题，达到什么样的结果**
- 要具体到：
  - 谁？（年龄段/职业/场景）
  - 什么问题？（痛点具体化）
  - 什么结果？（可衡量的改变）

### 5.5 定位做减法原则

```
大而泛（大众赛道×低客单） ← → 小而美（小众赛道×高客单）
              二选一
```

> 1万粉丝年入百万，比百万粉丝饿三天更实在。流量不重要，商业模式才重要。

## 6. "小而美"商业哲学

### 6.1 核心理念

> 不追求盲目扩张和融资上市，聚焦小众赛道、做高客单价、将人效做到极致。

**四大不**：不连锁、不扩张、不复制、不融资上市

### 6.2 为什么"小"反而"美"

| **规模** | 追求扩张 | 追求极致 |
| **团队** | 堆人 | 8人2500万 |
| **客户** | 越多越好 | 只服务对的 |
| **增长** | VC驱动 | 利润驱动 |
| **竞争** | 红海 | 细分赛道唯一 |

### 6.3 "跳蚤式创业"概念

- 未来趋势：大量个体会一边旅居创业、一边带娃
- 从"个体户"到"超级个体"
- 非标化创业：不复制别人，做你自己

## 7. 《框架的胜利》核心内容

> 出版时间：2025年4月 | 作者：陈晶 | 出版社：北京联合出版公司

### 7.1 核心主张

**"小胜靠偶然，常胜靠框架。人生的胜利，本质上是框架的胜利。"**

### 7.2 什么是"框架"

| 定义 | 解释 |
|------|------|
| 认知的"脚手架" | 大脑处理信息的底层结构，决定你怎么切入问题 |
| 信息的"筛选器" | 在信息洪流中帮你决定什么重要、什么不重要 |
| 表达的"叙事逻辑" | 内容清晰度和说服力的背后结构 |

### 7.3 框架三阶段构建法

**第一阶段：发现并拆解已有框架**
- 读任何内容时，不只关注内容，更关注作者的组织逻辑
- 用思维导图画"骨架"，不做摘抄式笔记

**第二阶段：构建自己的框架**
- 通用框架：三线法（故事线/逻辑线/启示线）
- 垂直框架：你的领域独有的分析框架

**第三阶段：用框架赋能输出**
- 内容结构 = 框架的可视化呈现
- 框架能带来"降维打击"——用认知工具打败体力竞争

### 7.4 知识创业者三大黄金框架

**① 定位框架——3问定位法**
- 我做什么能比80%的人做得好？（核心优势）
- 这个领域用户愿意为什么痛点付钱？（付费需求）
- 这个领域竞争对手少或我能做差异化？（市场空白）

**② 成交框架——4步成交法**
- 讲痛点 → 给方案 → 建信任 → 促行动

**③ 复购框架——用户成长路径**
- 入门期（99元）→ 成长期（999元）→ 成熟期（9999元）

### 7.5 三大"框架坑"

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 自嗨型框架 | 只关注"我有什么"，不关注"用户要什么" | 先搞懂用户痛点，再用框架解决 |
| 复杂型框架 | 框架太复杂，用户记不住、用不上 | 能"用一句话说清楚"，能"用3步做完" |
| 静态型框架 | 做好就不改了 | 数据监测→用户反馈→对标学习→持续迭代 |

## 四、标题方法论（全网最全汇总）

### 4.1 2026 最新底层逻辑（分析 500 篇 10 万+）

1. **制造"认知缺口"，别把答案写进标题**：80% 爆款标题不给结论，只呈现"具体+有点奇怪"的场景让读者好奇
2. **数字要有参照物**：不说"3 个技巧"，说"用了这 3 个技巧，我每个月多赚了五千块"
3. **让读者在标题里"看到自己"**：用大多数人都有的生活片段，不用"抑郁症患者/创业者"标签框定（"我已经三个月没洗过衣服了" > "一个抑郁症患者的自述"）
4. **"你"字放标题前 1/3**：代入感不断层

### 4.2 老师们的公式库

**粥左罗（学会写作 / 公众号运营实战手册）— 标题 5 条路径：**
①列新奇反问（激发好奇）②总结并包装观点（激发认同）③挖掘危机关联（激发危机）④包装内容价值（展示回报）⑤突出新闻时效（营造紧迫）
核心套路：**"重点前置，后缀共鸣"**——前半段用名人/数据/热点做噱头，后半段表达观点引起共鸣

**吕白（咪蒙前助理，拆解 5000 篇爆文）— 两步法：**
找到"敏感词" → 套入 8 种句型（数字法/对比法/热词法/疑问法/对话法/好奇法/俗语法/电影台词法）

**赵阳 10 大公式**（已在 [[B自媒体大脑/02-公众号创作/创作脚本规则/公众号写作手册]] 落地）：反认知/对比/共鸣/数字/俏皮话/拟人化/热点/负面/速成/修饰

### 4.3 2026 健康赛道 5 大标题公式（张医生重点）

| 公式 | 模板 | 案例（2-4 万阅读） | 心理机制 |
|------|------|------------------|---------|
| **症状+排查** | 「一个常见症状，先排查这几种…」 | "晨起嘴里'发苦'，先排查这几种疾病" | 恐惧驱动 |
| **权威+禁忌** | 「医生提醒：过了 XX 岁，宁愿 A 也别做 B」 | "医生再次提醒：过了 60 岁，宁愿坐着不动，也不要随便做这些运动" | 权威+行为禁忌 |
| **人群+共性** | 「某一类的人，通常有 X 个共性」 | "寿命比较短的男性，睡觉通常有 4 个'共性'" | 对号入座 |
| **自测+恭喜** | 「没有这 X 个情况，说明健康，恭喜」 | "早上起床，如果没有这 5 个情况，说明大脑保养的很好" | 小焦虑+庆幸 |
| **排行+意外** | 「最 XX 的 X 个习惯，第 1 太出乎意料」 | "睡前最养人的 5 个习惯，喝牛奶仅排第三！" | 悬念+反常识 |

**健康类标题高频关键词：** 医生/专家提醒、公认、建议、清肝明目、健脾养胃、缓解失眠、降压降糖、养胃、养肝、养颜（⚠️ 医学功效词慎用，详见合规节）

### 4.4 标题实操清单

- [ ] 每篇列 **10-15 个备选标题**再筛（头部团队做法）
- [ ] 关键词前置（算法识别关键词 + 搜一搜 SEO）
- [ ] 30 字以内，口语化，像跟朋友分享八卦
- [ ] **悬而必决**：标题有悬念，内容必须给答案，否则变标题党

## 五、开头 & 正文 & 结尾方法论

### 5.1 开头（黄金 8 秒）

**三个"留人密码"：场景化别总结 / 冲突前置别铺垫 / 悬念钩子别剧透**

- ✅ 场景 B（完读率 87%）："那天晚上 10 点，我一个人蹲在卫生间洗衣服，客厅里传来儿媳的笑声……"
- ❌ 场景 A（完读率 12%）："时间过得真快，转眼我已经 65 岁了……"
- 开头直接告诉读者三点：**你要讲什么？为什么值得看？看完能得到什么？** 不写背景、不写心路历程

### 5.2 正文结构

| 结构 | 适用 | 说明 |
|------|------|------|
| **总-分-总** | 最稳妥 | 经典不出错 |
| **问题-分析-方案** | 最常用 | 清晰三层 |
| **SCQA**（情境-冲突-问题-答案） | 解决问题类 | 从场景切入 |
| **是什么-为什么-怎么办** | 科普/方法论 | 适合营养科普 |
| **故事-启示-方法** | 个人 IP | 先故事后方法 |
| **清单/步骤式** | 教程/食谱 | 保存价值高 |

**峰终定律**：开头抓人、结尾有力、**中间至少一个"高潮点"**。小标题也是钩子，要有吸引力。

### 5.3 结尾（转发黄金地段）

- 总结升华（一句话收束核心观点）
- 开放式提问（引发评论）
- 明确引导转发（"转给需要的朋友"）
- 设置下篇预告钩子
- ❌ 不要写"感谢阅读"这种废话

**高级技巧：把"转发动机"写进正文**——写稿时就埋下"这份清单转给爸妈/转给家人"的钩子，不是写完再想怎么让人转。

### 中老年爆文内容结构（10 万+ 案例拆解）

## 七、2026 运营策略（算法时代打法）

1. **资产思维，不做流量思维**：一篇文章价值 = 即时流量 + 30 天长尾 + 搜索价值 + 品牌资产。**三天磨一篇精品 > 日更水文**
2. **深耕垂直**：越垂直算法越精准推给对的人 → 被标记为"权威源"。领域杂乱 = 没有标签 = 没有推荐
3. **盯核心指标**：分享率（社交货币）> 完读率 > 收藏复开率 > 互动率，**不是只看阅读量**
4. **冷启动 2 小时**：系统先给 500-1000 曝光测试，打开率/完读率/互动率跑不动就没了。**发文后主动在核心粉丝群/朋友圈/行业群启动**
5. **转发钩子写进正文**：写作时就想好"转给谁"
6. **视频号 ↔ 公众号联动**：公众号做信任+深度教育，视频号做情绪+动态内容（国外资料也强调 dual-platform synergy）
7. **搜一搜 SEO**：微信搜一搜月活 8 亿，贡献 27% 公众号涨粉——标题埋搜索词

## 二、第一篇：爆文创作（核心价值篇）

### 第 1 章 内容定位 —— 让谁看、为什么要看

**读者定位五步法：**

| 步骤 | 动作 | 本质 |
|------|------|------|
| ① 做减法 | 从 A-Z 列出可能读者，划掉不是你的菜 | 排除非目标 |
| ② 挤水分 | 从 A 类 1-10 排序，只留最核心的 | 筛选铁粉 |
| ③ 做乘法 | 取消地域限制，让定位可辐射 | 扩大天花板 |
| ④ 做画像 | 一张图看清读者在哪（年龄/场景/痛点） | 具象化 |
| ⑤ 下定义 | **用 14 个字定位你的读者** | 一句话说清 |

**读者为什么要看的 4 大理由：**
- **价值性**（让他觉得有道理）
- **实用性**（看完能用）
- **趣味性**（看完开心）
- **紧迫感**（现在不看会错过）

> 📌 **爆款逻辑第 1 条：定位越聚焦，内容越锋利。** 一个号服务一个核心读者，比"谁都写"强 10 倍。

### 第 2 章 标题取名 —— 如何取一个网红级标题

**技巧①：特殊字符**
| 字符 | 作用 | 案例 |
|------|------|------|
| 问号 ? | 制造悬念，勾点击 | "单身狗，你是不是也有这样炸天的女上司？" |
| 数字 | 具体可感、降低阅读压力 | "前女友提醒：别做这 5 类招人烦的男闺密！" |
| 推荐词【号外】 | 仪式感、注意力 | "【号外】第一次亲吻时，是不是也被霸道过" |

**技巧②：营造调性（5 种）**
- **私密性**（"收集了 10 年的老电影，拿走不谢"）
- **权威性**（"马云说：创建阿里巴巴是个错误"）
- **专业性**（"大数据营销分析，看看是不是这回事"）
- **急迫性**（"马上要实习，这些职场规则你知道不"）
- **稀缺性**（"华为内部管理资料，好难得"）

**技巧③：10 大标题公式（本书最值钱的部分）**

| # | 公式 | 一句话说明 | 张医生可套用示例 |
|---|------|-----------|----------------|
| 1 | **热点代入** | 蹭当下热点 | "世界肝炎日这天，医生想跟你说句实话" |
| 2 | **修饰词** | 加"最/很/超"强化情绪 | "这是医生最想让你知道的 3 个营养素真相" |
| 3 | **流行俏皮话** | 网络语拉近距离 | "把营养素当保健品，等于把汽油当香水" |
| 4 | **对比** | 制造反差 | "药店 9 块 9 vs 两百多的营养素，差在哪？" |
| 5 | **利益诱惑** | 给明确好处 | "看完这篇，你以后买营养素不会再交智商税" |
| 6 | **共鸣话题** | 替读者说出心声 | "体检报告正常，但你就是不舒服，对吗？" |
| 7 | **拟人化** | 物当人说 | "你的肝在喊：别再用这些方式伤害我了" |
| 8 | **负面词汇** | 利用恐惧/损失 | "别再乱吃营养素了，很多人第一步就错了" |
| 9 | **反认知** | 颠覆常识（重点） | "医生为什么不给你开营养素处方？" |
| 10 | **速成** | 给快速结果承诺 | "3 个方法，普通人也能看懂营养标签" |

> 📌 **爆款逻辑第 2 条：标题决定打开率，正文决定读完率，金句决定转发率。** 打开率 90% 由标题决定，标题没选好，正文再好也白写。

### 第 3 章 正文撰写 —— 有深度、有温度、有趣味

| 要素 | 方法 | 说明 |
|------|------|------|
| **素材收集** | 日常阅读法 / 百度关键词搜索法 / 采访经历法 | 素材是平时的积累，不是写时现想 |
| **人称** | **以"我"开头、以"他"收尾** | 开头用第一人称建立信任，结尾转到读者/他人引发共鸣 |
| **故事** | 具象化描述 + **包袱后放** | 细节要具体（时间/地点/动作），金句/反转放在故事后面，先铺垫后引爆 |
| **理论** | 用心理学/物理学/金融学分析故事 | 给故事一个"为什么"，升级认知层次 |
| **观点** | 写成"他要这样做会更好"，而非"你不要学他" | 正向建议，不居高临下说教 |

> 📌 **爆款逻辑第 3 条：故事让人想看完，道理让人想划走。** 先讲一个只有你能讲的真实故事，再提炼观点。

### 第 4 章 版式设计 —— 醒目且舒服

- 正文字号 14-18px（**16px 最佳**）
- 行间距 1.5-1.75 倍
- 段落间空行，一段不超过 200 字
- 首图清晰、大小适中；图片与内容一致；图片色彩冷暖一致

## 四、可直接抄的 3 个"课里的硬货"

### ① 六段式写作框架（D8）

```

第4段  权威背书（指南/专家/数据，给"转发有理"）
第5段  可执行清单（把专业拆成动作，让人保存）

### ② 小绿书引流玩法（D10·新增）

- 小绿书 = 微信生态图文笔记（公众号/发现页分发），**对标小红书但低门槛**：不涨粉也能被推荐
- 打法：**一条内容双发**——公众号长文讲深、小绿书图文讲浅，图文里带"完整版看同名公众号"
- 优势：健康赛道图文天然适合（食谱/清单/对比图），中老年用户点得动、转得起
- ✅ 这是全课对你最"新"的一块，建议开一个小绿书账号做图文分发试验

### ③ 变现盈利账测算模板（D1）

```
单篇公众号文章 → 阅读量(流量) → 关注转化率(~2-5%)
→ 公众号涨粉 → 引流私域(加微率) → 私域成交(转化率×客单价)
→ 单篇内容的"真实变现价值"
```

> 用这个公式先算清"一篇爆文到底值多少钱"，再决定投入多少——**先算账，后写文**。可做成一张 Excel/表格放在公众号素材库。

# KOC 的价值（含社群运营工作坊）

> 一句话：**运转的是模式，经营的是关系，长出来的是KOC**——"既不是KOL影响用户，也不是领导人影响用户，是用户才能影响用户"。

## 一、重新认识运营

- 都有社群，但真的都有运营吗？一个有价值的社群，不运营全靠自己长，行不行？
- 运营需要提前设计，体验、衔接和流转要不断复盘打磨迭代。

## 二、来自市场的3个故事（社群运营路径）

- **领导人A**："开口做大，方案接准，运营流转顺畅"——业绩+30%、新加入+150%、长客会占比24%（创办人营销总监）。
- **领导人B**："社群运营的灵魂，是伙伴成为朋友圈网红KOC"——"不是需要你原来多美多帅多年轻，是你不断晒变得更美更帅更健康更自信更好的点点滴滴，让别人看到一个不断变得更好的你"。业绩+47%、新加入+80%、长客会20%（高级营销经理）。核心理念：自己是一切的根源，人人KOC；闭环思维：KOC打造+朋友圈+各类社群+1对1；社群矩阵：0趴也能做群主。
- **领导人C**："小故事产生大能量，讲故事是社群转化的关键"——高级主任以上领导人都有三个层次的故事；办写故事比赛、要求骨干交故事、3人编辑部；市场收集故事2000+，成库100+。故事库分：人生价值/学习成长/副业收入（会员群/骨干群）、自用产品体验（各种场景）、老人安享晚年/孩子健康成长（公益群/会员群）。

## 三、社群运营四原则

1. **看起来的自然而然毫不费力，背后都是用户视角用心经营**（丘吉尔：10分钟演讲需要半个月准备）。
2. **公司给的套装只是60%，余下要核心团队自己设计**：KOC故事、用户高光时刻、Q&A答疑、福利投放、氛围游戏、人如何流转、解决方案如何衔接——社群运营要常搞事情。
3. **组合发力**：吸引新朋友，开启循环；用好私域三件套。
4. **用户思维**：每个用户最多只能成为15个品牌私域用户（最少5个左右），所以要精细化运营。
5. **人人KOC 2.0新语系**：讲顾客听得懂的话，幸福成长健康美丽，多讲故事少讲道理。

## 四、KOC 是什么

- KOC = Key Opinion Consumer 关键意见消费者：能影响自己的朋友、粉丝产生消费行为的消费者。
- **美花KOC三大特征**：生活方案的成套体验者、健康幸福的美好呈现者、能量满满的积极分享者。
- 从产品KOC延展到多维KOC：生活方式KOC、幸福能量KOC、美好关系KOC、成长不封顶KOC、又富又美KOC、美好事业KOC。

## 五、伙伴对KOC的常见疑问

- 前后变化很大才算KOC吗？——身材不变、年龄成谜、生活越来越好都是效果。
- 只有伙伴才能当KOC吗？——顾客也可以，用户影响用户。
- 只能分享产品改变吗？——传递产品价值/情绪价值/自用体验历程都是亮点。
- 要有职级才有说服力吗？——不同人影响力维度不同，成套自用、深度体验、真情实感都能影响他人。

## 六、KOC 的业务价值

- 连接双圈驱动双轮：左手快乐生活圈，右手成长事业圈。
- **"转化的速度取决于传播的速度"**。
- 案例·雯雯：28岁160斤多次减重失败→半年减至120斤→组建"吃吃瘦"社群→10人到200人每月开营。金句："透过雯雯的故事，我看见的是未来更好的自己。谢谢你不跟我讲道理，而是让我的眼睛有光了。"

## 七、KOC 如何释放能量（写/讲/用故事）

- 现阶段卡点：只会用嘴讲不会写图文、如何讲健康故事打动人还没风险、如何结合场景用故事、如何让好故事感染更多人、市场KOC少故事库没有借不上力。
- **5种形式**：自由式（随手分享/跟帖发言/真情实感）、短故事（简单描述/照片为证）、海报体（核心要点/对比照片）、短视频（真人出镜/信任升级）、长故事（过程细节/情感链接）。
- **5个模块搭故事库**：微信2途径故事成库、企微4步建库操作。
- **三个阶段**：骨干都是KOC人人写起来→搭建故事库伙伴借力→形成肌肉记忆基因，无招胜有招。

> 敲黑板：线上是新场景，需要社交新能力；全员KOC、人人做群主、大小齿轮打配合；内容再好也不是社群的全部，产品再好也不是解决方案的全部；社群是魂道法术器的结合，人是魂，是核心。

# 如何讲出 KOC 好故事

> 一句话：**你不需要很厉害才开始动笔写，只要写了就会更厉害**——KOC好故事=真人真事真感情，生活化自然展现。

## 一、KOC 好故事讲什么（4大主题）

- 成长蜕变、自我提升、和谐关系、丰盛人生
- 自信/美好人生/良师益友/Plan B创业

## 二、5种形式（可选其一，也可互相转化）

| 形式 | 特点 | 难度 |
|---|---|---|
| 自由式 | 随手分享、群内跟帖、真情实感 | ★ |
| 短故事 | 简单描述、照片为证 | ★ |
| 海报体 | 核心要点、对比照片 | ★★★ |
| 短视频 | 真人出镜、信任升级 | ★★★★ |
| 长故事 | 过程细节、情感链接（图文搭配一步步发，3-5分钟讲完） | ★★★★★ |

> 敲黑板：短故事/自由式都是"自来水"天天都要有；有能力有意愿的短视频版本要做起来；长故事市场必须有，否则社群无法形成能量场。**故事是衔接课程与解决方案的按钮**。

## 三、4步讲出KOC好故事

1. **秀出 Before/After 对比照**（无对比照可用现在状态美照）。
2. **把细节真情实感讲出来**：导演郑晓龙"细节的真实让人相信情节的真实"；过去状态→改变契机→改变过程→现在状态；"那一刻"心动的理由；避免千篇一律，元素为内容服务。
3. **产品/事业机会软植入**：营养素名非产品名，好环境好成长。
4. **链接情感，引发共鸣**：走心的文字，平等的视角。

> 真人真事真感情，生活化自然展现；精选片、有细节、软植入、要共鸣。

## 四、长故事范例（可借鉴结构）

- 击剑体育生女孩：陪朋友参加美丽沙龙→人生第一妆→发掘少女梦→营养早餐改变皮肤→成为健康美肤顾问。美出健康、美出自信、绽放生命原本的光彩。

# 磨出好故事（编辑部工作坊）

> 一句话：打磨故事要达成两个目标——**一要吸引，二要打动**；我们谈打磨故事，其实是谈转型进程。

## 一、编辑部的角色

- "有故事的人" → "故事大王"：自己会写故事、读过很多故事、掌握打磨技巧。

## 二、4步打磨好故事（讨论框架）

带着问题边听边记：
1. 这个故事是写给谁看的？
2. 这个故事吸引你了吗，想一直往下看吗？
3. 这个故事打动你了吗，哪些地方打动你了？
4. 如果请你打磨，你会提什么建议？

## 三、案例打磨示范

### 晨欣的故事（示范精修）
- 原始故事问题：又像讲产品又像讲事业，可拆成两个故事；要展现4元素（过去状态/改变契机/改变过程/现在状态）。
- 调整语言、梳理结构、掂量分寸、确定重点。
- 生活圈还是事业圈？哪些话适合给顾客看、哪些给伙伴看？
- 语言简洁舒服，不建议写"大家好"，降低销售感。
- **好故事要配好名字**：《当敏感肌遇到生活美学》→ 先讲留学经历+婴儿肥+过敏红血丝 → 偶遇雅姿国潮活动 → 用3个月皮肤好转 → 7分吃3分抹，营养早餐内调 → 现在白嫩通透也瘦了。

### 秀月的故事（反面教材+精修）
- 原生态问题：通篇感叹号令人紧张、反常识表述不可信、夸张语言引起反感；只适合高度信任人群，用力过猛风险大。
- 精修《把健康吃回来》：客观陈述子宫异常出血→住院→营养+蛋白质+睡眠→复查正常；"健康主要靠自己，不是医院"。

## 四、语言表达 4要4不要

- 说顾客听得懂的话：与他有关对他有用、生活化表达不装不端。
- 幸福成长健康美丽：不讲疾病，更安全更面向大众。
- 分寸感需匹配场景：关系不同、场景不同、分寸感不同。
- 生活圈和事业圈的故事分开写，逐步影响（不要一网打尽）。

> 重塑"故事会"的意义：打磨故事=打磨伙伴转型进程。

# 匹配场景 用好故事

> 一句话：**KOC故事匹配不同场景、形成联动，才能扩大影响**——多种故事在多个场景高频分享。

## 一、常见痛点（故事不会用）

- "长故事写了之后一年都没用过"
- "分享故事但不知道什么原因没啥效果"
- "就一个故事，不管遇到谁我都发"
- "在公益群会员群发一样的故事，没分过类"
- "很少在朋友圈发故事，觉得太长了没人看"

## 二、陈姐的示范（分类投放、语言朴实社交感足）

- 朋友圈：每天展示体管KOC日常，分享自己和朋友的体重管理故事。
- 公益群/读书会：晒好状态好变化的故事，用"两个吃对"减重故事。
- 会员群：营养早餐的故事、家庭管理员的故事、长期营养的故事。
- 结果：朋友圈私聊渐多、社群互动热烈、池子里鱼多了上目标不难了。

## 三、三场景分析表

| 场景 | 人群构成 | 运营重点 | 故事形式 | 界线 |
|---|---|---|---|---|
| 朋友圈 | 顾客+潜在顾客 | 展示生活方式、建立KOC形象 | 自由式/海报体/短视频/短故事 | "亚健康"是界线 |
| 公益群 | 对健康美好有兴趣但非长期会员 | 带动主动健康氛围、健康美好向往 | 短故事/海报体/自由式/短视频/长故事 | "不讲方案"是界线 |
| 会员群 | 已购买产品解决方案的顾客 | 营造认真吃产品氛围、强化长期用观念 | 自由式/海报体/短故事/短视频/长故事 | "晒方案不晒用量"是界线 |

## 四、敲黑板（各场景要点）

**朋友圈**：
1. 内容短，一眼抓到故事重点
2. 有界限，晒"又美又瘦又健康"，亚健康是界限
3. 四个我，持续晒生活方式建立KOC形象

**公益群**：
1. 营造氛围，结合观念带动主动健康意识
2. 晒好状态，用好变化引发好奇激发需求
3. 不晒方案，但准备好健康生活方案的介绍

**会员群**：
1. 故事结合健康长效观念，用吃出来的健康美丽影响认真吃长期吃
2. 用家庭健康管理员的故事影响管理好家人健康
3. 讲方案讲收获，不讲用量

## 五、联动逻辑

- 朋友圈晒状态（推动转化）→ 公益群晒方案（链接长期营养）→ 会员群晒生活（让人羡慕）。
- 讲好自己的故事、他人的故事、彼此的故事；通过故事自然衔接解决方案、化解问题、带动群友在不同社群流转。

# 大健康 IP 打造 × 互联网工作法（张飞）

> 一句话：**销售就是搞定别人把产品卖好，营销就是搞定自己让产品好卖**——打造个人IP是让自己强大起来，进而去帮助、影响、赋能更多人。

## 一、营销 vs 推销（先立观念）

- 营销=制造"有问题的结果"；微信发出答案的叫"广告"，发出没有答案的叫"营销"，答案一出来没人看。
- 反面教材示例：晒"乙肝病毒从15.9万降到2350"（引导病情讨论，风险高）→ 正确写法：打卡护肝计划，简单方便。
- 打造IP心法：销售让别人变优秀，营销把自己变优秀；用现在最优秀的自己赚未来的钱。
- **量子纠缠：能量相牵**——打造个人IP不是赌气式跟谁比，而是把内心深处蕴藏多年的能量在某一点爆发。

## 二、大健康 IP 定位

**个性签名（定位公式）**：轻断食指导师，糖尿病防控员，健康塑型教练，大健康百万精英发起人，医生营养师社群百佳组长，国家公共营养师，中国营养学会认证营养顾问...
- 强IP打造=装修自己的门面，明确你对他人的价值。
- 置顶朋友圈：高光时刻、优秀的自己、个人价值体现。

## 三、高能量朋友圈（网红朋友圈/T型朋友圈）

- 朋友圈是社交第一阵地；**谁能获取最多注意力，谁就能最大化生产力**。
- 权威数据：爱发朋友圈死亡风险直降12%（2016《美国科学院院报》，加州大学圣地亚哥分校1200万Facebook用户研究）；经常发布照片者死亡风险低于平均30%。
- **大杂家+小专家**：既做展示美好生活的大杂家（我的生活/我的学习/我的朋友），又做身边小圈子里的小专家（营养早餐KOC朋友圈）。
- 小专家朋友圈四要素：立Flag现身说法、身体力行过程感悟、过程监督充分互动、借力公司内容+一点"自己"（自拍出镜个人感受）。
- **你的形象价值百万（5星制）**：1星随便发发90% / 2星随时模仿80% / 3星固定标准20% / 4星创造自己的游戏规则 / 5星高大上白富美。
- **制造期待感**：人物期待、时间期待、结果期待；"最"搭配：①最贵最少见 ②最远最美丽 ③最亮最有名 ④最多最疯狂（激发购买欲望）。
- **朋友圈内容四类**：你很优秀（高光时刻/荣誉/梦想/心路历程）、你的价值（帮助他人解决问题）、你身边一群牛人（大场面高质量圈子）。
- **文案写法**：指令式提问AI（"请以感动为主题给10段朋友圈文案"）+ 90%模仿+10%创新。

## 四、互联网工作法

### 1. 名单管理：打标签
- **100人有效持续跟进名单**：可以聊天的、会回复的、有种子领导人或顾客方向的、能约见面的。搜索200人有效名单，每天工作30*30*30。
- 有效名单进入读书会鱼塘养群 → 顾客名单进会员群（多项目标签）→ 标签私信与群发。

### 2. 资料管理：资料分组收藏，随时用。

### 3. 跟进沟通：FORM法则
- **F** 家庭family：家庭条件、出身、家庭现状
- **O** occupation：现在到底在做什么（对不同职业用不同需求点）
- **R** recreation：娱乐、兴趣、消遣方式
- **M** money：经济状况、增加收入？

## 五、线上社群与线下

- 经营人脉不是搞关系，而是**创造命运共同体**；关系是麻烦出来的（富兰克林：想交朋友就请他帮你一个忙；聪明地麻烦：不帮太大忙、不谈钱、请对方在擅长领域帮忙——罗辑思维）。
- 线下工具：《线上读书会》《群长手册》。

## 六、行动口号

- 鸟巢2028 营销总监；打开生命能量开关。
- 打造个人IP：自动自发自觉、强烈企图心、先跟自己对话再连接世界。

1. 每周在社群讲一个案例/健康故事

# 个人IP打造实操课：新人3步建IP × T字型朋友圈 × 能量维度

> 📌 **本课已归位** —— 同一堂课（张医生内训《打造五星级朋友圈与个人 IP》）已按「讲给伙伴听 → 带团队」归口，**以 [[KC-团队-012-打造五星级朋友圈与个人IP|KC-团队-012]] 为准**（含 2026-09-27 更完整口播：营销≠推销判别式、朋友圈五件套、落地清单）。
> 本卡为 2026-09-05 版逐字稿整理，**内容保留备查**；两版独有细节可互相补充。

> **一句话**：IP不是晒出来的，是让人看见你**从0到1的旅程与能量**——新人2-3个月可立起小IP；朋友圈按 **T字型**发（横=大杂家给情绪价值，竖=小专家给功能价值）；营销只**发结果、不发答案**。
> **对象**：刚进大健康的新伙伴（重点听）+ 做了一段时间想升级的老伙伴。
> **来头**：与「精英班」IP课同源，思路来自广州互联网大咖学费10万的录播课；此前几乎不对新人讲。

## 一、新人 0-3 个月建立 IP：三步走

> 导师林伟博士：一个人不管过去是白纸还是宝妈，想把自己IP打造起来，**3个月足够了**。

### 第1步 · 学习期：不是晒厉害，是晒「我正在学」
- 新手最容易误解：一上来就要证明自己很专业、晒案例、晒舞台 → 很难让人信。
- 正确做法：真实呈现**学习过程与场景**——在学营养基础班、在考营养师证、在看《轻断食完整指南》《吃的营养科学观》……
- 学到什么，**用自己的话讲一遍**即可；不需要专业，最真实的表达最好。
- 案例：街舞老师转型的赵旭老师——从真实记录每天在学什么、哪本书哪句打动自己开始，朋友圈一路攒下来，IP打造非常顺。

### 第2步 · 实践期：帮到自己 + 拿到初步结果 → 人设萌芽
- 学习的人没有IP；**关键节点=拿到第一个初步结果**。
- 学了先帮自己：阿维自己做减脂，把自己瘦下来，就是过程+结果的双重呈现。
- 记录双线：①还在学什么 ②自己/身边人实践的变化。
- 考到证 → 从「学习者」变「拿到证的人」，人设开始成立。
- 接着上舞台：社群讲一堂课、线下做一次分享——把「有人请你讲」的过程晒出来。

### 第3步 · 人设成立：水到渠成
- 标志：名片/标签/门面更新，专业度沉淀；有了证、有了自己的案例、能讲课、能帮学员出案例。
- 别人看着你**从0到1**走过来，信任自动发生 → 咨询 → 成交 → 交付/指导费。
- 全程约 **2-3个月**。

> 🎯 心法：**呈现「旅程」而不是「结果」**——张医生当年练6块腹肌全程记录，最后亮结果时信任感极强。真实记录=信任感。

---

## 二、IP 的本质：能量吸引（先升维，再谈术）

- 案例：第一次去北京，儿科吴医生、北中医内分泌方向罗博士两位**从未见面**的人，请他吃饭、送书、当天开卡。儿科吴医生留言：「一见如故……羡慕张老师蓬勃旺盛的生命力，被深深感染」。
- 为什么？**不是专业**（专业的人很多），是**长期朋友圈IP呈现出来的能量**先影响了他。
- 人影响人的本质=**能量高低**（霍金斯能量表：勇气200为分水岭，向上是能量高；羞愧/内疚/冷漠在最低端）。能量高者自然影响能量低者。
- 张医生的高能量叙事素材（亲测有效）：
  - 26岁、农村孩子出身，投30万开奶茶店（2015）；
  - 三甲医院工作近10年、月入约3万，2020年辞职做大健康。
  - → 别人读到的是「有魄力、敢折腾、有梦想」= 高能量词。
- 转念：当下困难恰恰是**少有的提升能量的机会**（多数人都想平顺）；从困难里爬起来的你，能量才会在身上呈现。
- 破「作秀心结」：打造IP不是跟谁比、不是炫耀，是**让自己强大起来 → 能量出来 → 才能影响人 → 才能帮更多人**。想不通这点，会被自己卡住不敢发圈。

---

## 三、高能量朋友圈：T 字型结构

> 记住一个「T」：上面一横、下面一竖。

| 一竖（小专家） | 一横（大杂家） |
|---|---|
| 小切口 / 专业 | 生活横向 / 真实状态 |
| 功能价值 → 信任+成交 | 情绪价值 → 温度+共鸣+吸引 |
| KOC/KOL | 有血有肉真性情 |
| 学习→考证→陪跑案例 | 生活方式/家庭/孩子/体验/感悟 |

- **横（大杂家）**：美好生活、凌晨看日出、跑步+读书、打球、旅行、成长——积极真实的生活状态。别发负能量、吐槽、八卦、是非。
- **竖（小专家）**：营养赛道小切口的专业呈现——学习打卡、证书、陪跑客户改善案例、KOC内容，用心做。
- 口诀：**大杂家给情绪价值，小专家给功能价值**。只发专业→太硬；只发生活→没价值；一横一竖=高能量朋友圈。
- 权威背书（可截图）：爱发朋友圈的人死亡风险直降12%——《美国科学院院报》，加州大学圣地亚哥分校，1200万Facebook用户研究。
- 反面教材：健康海报/资讯简报原样搬运（没有自己的话）→ 用AI出模板再**加自己的话**，别当信息搬运工。

---

## 四、朋友圈门面 5 件套

名字 / 头像 / 背景图 / 简介 / 置顶内容（置顶视频+置顶朋友圈）
- 置顶放什么：你的**高光时刻、优秀的自己、个人价值、帮别人解决的问题、身边高质量圈子/大场面**。
- 学员做法：学习后把微信5件套整体调整，配网红朋友圈风格。
- 原则：门面是价值传递的第一眼——从「文艺头像+文艺签名」升级为「专业营养IP门面」。

---

## 五、营销 ≠ 推销：只发结果，不发答案

- 「人生无处不营销」——营销中性偏褒；推销才是大家反感的。
- **判别公式**：
  - 发**结果**（谁好了、谁有改善、学员变化）→ 答案留白 → 对方好奇「怎么做到的？」= **营销**，制造期待感。
  - 发**答案**（营养素方案、产品名、步骤方法）→ = **广告**，没人看。
- 微信里，**能把答案发出来的都叫广告**；不发答案的才叫营销。
- 例子：推广轻断食/护肝计划时，两段文案对比——直接给方案的没人看，晒结果+留钩子的有人来问。
- 张医生朋友圈打法：基本只发结果，从不写「我是怎么改善的」。
- 用AI：让AI生成「只讲结果+结尾留一个问题钩子」的朋友圈，不让它写方案。

---

## 六、落地行动清单

- **新伙伴（0-3个月）**：按三步走，每天真实晒「在学什么/在考什么/在做什么」；先想通分享的意义=让自己强大、帮更多人，才发得出来。
- **老伙伴**：升级T字型配比 + 5件套门面 + 只发结果不发答案；别忘了横轴，热爱生活。
- **导演比喻**：一部好电影是每一帧都认真打磨——别只盯最后成交；前端基础动作做到位，后端交付/成交自然简单。
- **最终目的**：线上IP先替你说话——朋友圈能量出来了，线下链接、沟通、办卡才高效；能量高的时候，**是别人来找你，不是你追别人**。

**（放一张2017年兼职做安利的照片——要真实，别摆拍）**

2017年我开始做安利。白天上班，晚上和周末搞这个。

2020年我把工作辞了。从2017年兼职算起，做安利快十年了。

老有人问我：你咋做到的？兼职起步，也没什么背景。

今天跟你好好聊聊。不讲方法，就讲我这些年想明白了哪些事。

**（放银章颁奖或者早期团队的照片）**

第一个事，是我想通了安利到底在干啥。

很多人做安利做得累，因为他觉得安利就是卖货。今天卖一单赚一单的钱，明天不卖就没有。这叫挑水——一天不挑就渴死。

但它的奖金体系、顾客回购、团队复制——这些东西的设计，全是在建管道。前期辛苦铺水管，铺好了水自己流。我想明白这个以后，做法全变了。不再追着人卖东西，开始搭系统。前面三四年确实慢，但管道一通，后面的活不是"干出来"的，是"流出来"的。

**（放一张自己当医生或者刚毕业时的照片）**

第二个事，是我重新想了"价值"这两个字。

我以前觉得做安利的价值在产品。后来发现不是。我做医生的时候给人看病开药。做安利之后，我给人搭饮食方案、讲健康常识、聊创业方向。产品只是过手的东西，我真正给出去的，是我脑袋里的东西。

你对营养的理解、对慢病怎么吃的经验、对这个行业的判断——这些才是你的真东西。你的认知值不值钱，决定了你走多远。

**（放一张学习或看书的照片）**

我养成了一个习惯，到今天还在做——每天往自己的知识库里存东西。今天学到脂肪肝和饮食的关系，存进去。今天听到林博士讲目标切割，存进去。今天看到一句话——"动机是行为的产物，不是原因"——也存进去。

安利的事情太多了，你面对的东西太多。你没有自己的知识系统，学过就忘，天天原地打转。我为什么做安利近十年，还有人主动来找我？不是我多牛，是我的知识库一直在替我干活。

**（放一张在台上讲课的照片）**

第三个事，是我发现"系统"比"个人"厉害。

我上过千人的台，带着团队出过国，我爸妈的营养方案现在是我配的，指标比我还好。

但这些不是我厉害，是系统厉害。

安利真正值钱的东西不是产品，是它这套系统——能让普通人走出来、让成功可以复制的系统。付后坚先生做了几十年，他了不起的地方不是赚了多少钱，是他搭了一个体系——没有背景的人、不会说话的人、没啥资源的人，照着做也能走出来。

我以前也不信。但我是自己走过来的。兼职做到银章，全职做到今天——每一步都是这个系统给的。

**（停顿）**

不过也得说句实话。

很多人把安利搞坏了。急功近利的、拉人头画饼的、把人当流量不当人的。每次看到这些人，我都挺难受的。系统本身没错，是有人把它做成了捞一把就跑的工具。

我自己怎么看安利？就是一个工具。你拿来帮人，就是好的。你拿来收割，就是坏的。就这么简单。

**（放一张梦想清单或者环游中国的照片）**

我的梦想清单上写了一句话：这辈子，做个有故事的人。

安利给了我这个。从一个医生变成一个创业者，从一个人变成一群人——这些不是钱能算的。

**（放一张AI工具或者你自己搭建的知识库截图）**

然后AI来了。2025到2026这一年，变化太大了。

好多人慌，说AI要取代人了。

我看法不一样。我给你说个事——有本书叫《审美之外》，里面有个观点我特别认。它说AI把人类的脑力拆成了两块。一块是能算的执行力——这个AI比你快、比你便宜、比你不知道累。另一块是不能算的判断力——没人告诉你怎么选的时候，你自己能选对的能力。前面那块是AI的地盘，后面那块才是人最后的地盘。

哈佛有个实验，六百多个创业者。判断力强的人用AI，收入涨了15%。判断力弱的用AI，收入反而跌了8%。

AI不会让你变厉害，它只会放大你本来就有的东西。你有，它放大。你没有，它让你更快地冲向悬崖。

我在安利这些年攒的那些东西——对健康的感觉、对客户需求的判断、对这个行业的理解——这些东西AI弄不了。但它可以把这些东西放大十倍、一百倍。

## 一、核心认知：人为什么会生病？

### 1.1 慢性病是生活方式病

- **80%以上死亡源于慢性病**，而非意外或急性传染病
- 医院常规方案：吃药一辈子 + 严重了手术 + 放化疗
- 但慢性病是**生活方式病**，药物只能控制指标，不能根治
- 医生自己也难以自医——医学院教的是一辈子吃药，不是改变生活方式

### 1.2 从细胞层面理解健康

```
人 → 八大系统 → 器官 → 组织 → 细胞（人的基本单位）
```

- 每个人从一个受精卵细胞裂变而来
- 细胞的原材料 = **40多种营养素，分7大类**

**七大营养素：**
| # | 营养素 | 常见来源 |
|---|--------|---------|
| ① | 水 | 饮用水、果蔬 |
| ② | 蛋白质 | 鱼肉豆蛋奶 |
| ③ | 维生素 | 蔬菜、水果 |
| ④ | 矿物质 | 水、蔬菜、肉类 |
| ⑤ | 碳水化合物（糖类） | 米面、水果 |
| ⑥ | 脂肪 | 肉类、油脂、牛油果 |
| ⑦ | 膳食纤维 | 蔬菜、全谷物 |

### 1.3 中国人饮食结构的典型失衡

```
水        →  ❌ 不足
蛋白质    →  ❌ 不足
维生素    →  ❌ 不足
矿物质    →  ❌ 不足
碳水      →  ⚠️ 严重超标
好脂肪    →  ❌ 不足
坏脂肪    →  ⚠️ 超标
膳食纤维  →  ❌ 不足
```

> 典型例子：一碗兰州拉面/山西面——一大碗碳水 + 两三片薄牛肉 + 几颗青菜 + 葱花。除了碳水超量，其他全部不足。

## 二、核心概念：隐性饥饿

### 2.1 什么是隐性饥饿？

**定义：** 胃吃饱了，但细胞还在饿。

- **显性饥饿：** 你知道饿了，会去找东西吃
- **隐性饥饿：** 胃是饱的，但细胞缺乏必需的营养素，你感觉不到

### 2.2 形象比喻：蚂蟥（水蛭）

> 像小时候在田里插秧被蚂蟥咬——不痛不痒，完全没感觉。它在腿上吸血，你都不知道。如果没有外公发现止血，血被吸干了都不知道怎么死的。

**隐性饥饿的可怕之处在于——你不自知。**

它的伤害不是突然发生的，是**一点点累积**的。慢性病不是突然发现的，而是突然发现的。

### 2.3 用数据说话：算清楚隐性饥饿的账

#### ① 水——最简单的例子

**计算公式：** `每日需水量 = 体重(kg) × 30ml`

例：60kg的人 → 需要 **1800ml/天**
如果只喝了1200ml → **缺口600ml → 这就是关于水的隐性饥饿**

> ⚠️ 喝水误区：
> - 不要等渴了再喝（渴的时候细胞已死亡3%以上）
> - 饮料/茶/咖啡不能替代水（含利尿剂，排出的可能比喝进去的还多）
> - 老年人怕喝水伤肾——其实是误区

**喝水少与以下问题直接相关：** 高血压、血糖高、血脂高、便秘、皮肤干、脑子不够用

#### ② 蛋白质——最关键的营养素

**计算公式：** `每日需蛋白质 = 体重(kg) × 1.22g`（中体力劳动标准）

例：60kg的人 → 需要 **约74g/天** → 每餐约 **25g**

**常见食物蛋白质含量（每100g净重）：**
| 食物 | 蛋白质含量 |
|------|-----------|
| 鱼肉（去皮去骨）| ~20g |
| 鸡蛋（1个）| ~6g |
| 牛奶（200ml）| ~6g |
| 豆制品 | 含量高但吸收率低 |

**豆制品的陷阱：** 9种必需氨基酸中，蛋氨酸含量低→木桶效应→不能作为完全蛋白。素食主义者（如大S、方大同）往往严重缺蛋白质。

**典型早餐蛋白质缺口：**
- 一个花卷 + 一杯勾兑豆浆 → 约5g蛋白质
- 需要25g → **缺口20g**
- → 记忆力下降、反应变慢、容易累、容易饿

**总账算法：**
> 每天需要74g，通过食物只吃到40g → **每天缺口34g**
> → 乘以365天，乘以40年 → **一笔巨额的营养负债**

## 三、身体的优先级机制：生命器官 vs 非生命器官

### 3.1 分类

| 类型 | 定义 | 举例 |
|------|------|------|
| **生命器官** | 没了就没命 | 心脏、肝脏、肾脏、肺脏、大脑 |
| **非生命器官** | 没了还能活 | 四肢、胆囊、脾脏、子宫、甲状腺、皮肤组织 |

### 3.2 营养分配规则

当营养不足时（比如只吃到40g蛋白质，需要74g），身体**优先供给生命器官**，非生命器官只能等剩下的。

这就是为什么：
- **膝盖摔了半年好不了** → 营养到不了非生命器官（被生命器官截走了）
- **胃炎吃蛋白粉好了，别人吃没效果** → 因为那个人的蛋白质缺口太大了，一勺蛋白粉（8g）补不上34g的缺口
- **瘦子也有脂肪肝**（"瘦胖子"）→ 严重缺蛋白质，内脏脂肪堆积

## 四、解决方案：基础配方 + 长客会

### 4.1 最基础的三件套（经济条件有限时的最低配置）

| 产品 | 作用 | 解决什么问题 |
|------|------|-------------|
| **蛋白粉** | 补充蛋白质隐性饥饿 | 补蛋白质缺口 |
| **维生素C** | 补充维生素隐性饥饿 | 补维生素缺口 |
| **男士活力组合** | 倍力健（多种维生素矿物质）+ 鱼油（好脂肪）+ 护肝片（肝脏代谢） | 全面补充+护肝 |

> 男士活力组合不是男士专用！男女老少都用——因为人人都有肝脏。

### 4.2 为什么一定要签长客会？

**核心逻辑链条：**
```
隐性饥饿 → 每天需要补充营养素 → 需要长期坚持
→ 长期坚持需要经济划算 → 长客会实现4-6折
→ 因为划算所以坚持 → 因为坚持所以有效果
→ 因为有效果所以愿意分享 → 市场自然裂变
```

### 4.3 长客会优惠计算

#### 类型一：1+N 长客会（蛋白粉+维C，月均907元）

**优惠计算：**
- 每月扣907元，一年共付：907×12 = **10,884元**
- 全年积分总和：**19,047分**（前3个月单倍积分，后9个月双倍积分）
- 积分可换产品：19,047÷5 = **3,809元**（5分=1元）
- 优惠力度：3,809÷10,884 = **35%**

**加上奖金比例后的综合折扣：**

| 个人业绩 | 收入比例 | 券比例 | 产品优惠 | 综合折扣 |
|---------|---------|-------|---------|---------|
| 1250元（100分）| 0% | 6% | 35% | **≈6折** |
| 12,500元（1000分）| 9% | 6% | 35% | **≈5折** |
| 达标（12.5万+）| 21% | 6% | 35% | **≈3.8折** |

#### 类型二：男士活力组合（月均868元，买6送1）

- 付6盒的钱，收7盒 → 优惠力度 **≈15%（85折）**
- 加上奖金比例，综合折扣约 **6-8折**

## 五、签长客会的关键心法

### 5.1 用户思维——站在顾客角度

不要推销"安利产品好"，而要帮顾客算清这笔账：

> **"你每天三顿饭，有没有吃到足够的营养素？如果没吃够，你的身体欠了多少债？这个债不还，慢性病找上门，去医院花的钱是多少？"**

### 5.2 断签的根本原因

不是经济问题，是**观念问题**——顾客不认为他必须每天吃。

> 连做安利的人自己都没认真吃，怎么能要求顾客认真吃？

### 5.3 破除"囤货恐惧"

- 顾客怕每个月寄一堆吃不完
- **根源：** 他不觉得自己每天需要吃
- **解决：** 如果他能坚持每天吃，根本不会囤货——还不够吃！

### 5.4 推荐话术逻辑

```
① 你为什么会生病？（细胞营养缺口）
② 隐性饥饿是什么？（蚂蟥比喻）
③ 算账：你每天缺多少蛋白质/水？
④ 你的身体在"拆东墙补西墙"（生命器官优先）
⑤ 所以你需要每天补充营养素
⑥ 怎么补最划算？→ 长客会（4-6折）
```
