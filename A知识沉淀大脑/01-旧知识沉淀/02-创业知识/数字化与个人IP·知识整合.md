# 数字化与个人IP·知识整合

## 一、总纲

个人 IP 不是当网红，是把"我是谁、我能帮你解决什么"做成一套可被搜索、可被记住、可被转发的资产。它由三件事相乘得来：标签化（定位与门面）、内容力（朋友圈与短视频）、持续积累（时间与势能）。安利做 IP 的独特之处在于：你不是一个人站在前面，身后有成冠的系统托底，IP 只是"另一个维度的 OPP"。本篇顺序：为什么做 → 定差异点 → 搭账号 → 跑内容生产线 → 线上打法与成交。

## 二、核心知识点

### 2.1 为什么要做个人 IP

- 话语权已经转移："互联网最大的改变就是话语权的改变，话语权不在厂商手上，而在消费者手上。"信任的来源从机构与广告，变成了"一个具体的人"。
- 营销与推销的分界："销售就是搞定别人，把产品卖好；营销就是搞定自己，让产品好卖。"推销穿得普通，希望别人鼓掌；营销穿得很帅，别人自动鼓掌。
- 个人 IP = 另一个维度的 OPP（黄安利）。OPP 一次讲给 10 个人，IP 24 小时讲给所有人。
- 一个数据：2016 年 PNAS 刊载、加州大学圣地亚哥分校对约 1200 万 Facebook 用户的研究，"爱发朋友圈"的人死亡风险直降 12%——社交连接本身就是健康资产。
- 熟人社会→陌生人社会（林炜）：熟人社会安全、温暖、强联系，但天花板是你的通讯录；陌生人社会弱联系、市场大、速度快。举证：移动工作室半年覆盖 8000 万人，而此前 20 年累计开卡与购买过的人只有 4000 万；沃尔玛做到 3 万亿用了 53 年，阿里只用了 13 年。
- 熟人反对不再是障碍（林老师）："你哥哥支持就多了一个人，你哥哥反对就少了一个人，在互联网时代一点意义都没有。"
- 个体崛起：自媒体让一个人同时是渠道、内容和信任源，成本从"开店"变成"开号"。

### 2.2 IP 定位与差异点

- IP 公式：标签化 × 内容力 × 持续积累势能。三项是乘法，任何一项为零，结果为零。
- 定位四部曲（2.15 版）：确定领域和定位 → 构建个人品牌和形象 → 输出有价值的内容 → 社交媒体和平台运营。
- 定位清单可直接取用：轻断食指导师、糖尿病防控员、健康塑型教练、大健康百万精英发起人、医生营养师社群百佳组长、国家公共营养师、中国营养学会认证营养顾问。
- 差异点的本质是"圈层差"：此圈大神，彼圈路人。你的参照系必须是你能影响到的那一圈人，不是行业顶流。
- 双轨内容人格（7.20 版）：一条"大杂家"（我的生活小确幸 / 我的学习上不封顶 / 我的朋友相伴美好），一条"小专家"（身边小圈子的专业输出，主线是营养早餐 KOC）。
- 先死后活：先死掉"做专业 KOL"的心，再复活"做行动 KOL"的心。你不是要成为专家，你是要比身边人早走半步并且愿意说。
- 老鹰特质（黄安利）：爱折腾、有企图心、守承诺、在自己领域有建树。找 IP 苗子看这四条，比看勤奋准。
- 赵旭版的提醒最清醒：人设只是水到渠成、画龙点睛，关键是个人的成长到位。顺序错了，人设就是壳。

### 2.3 账号搭建与命名

- 四件套：头像、昵称、个性签名、朋友圈封面。封面用稿定设计 APP → 形象包装 → 朋友圈封面模板，成本几乎为零。
- 三句话定位法：一个封面 + 一张头像 + 一句签名，回答"我是谁 / 我帮谁 / 我解决什么"。范例："爱健身的王小宝""营养顾问""亲子专家"。
- 命名原则：可被搜索、可被记住、带身份或地域；不要生僻字、纯英文缩写。
- 置顶朋友圈三类：①高光时刻 ②你的价值（你帮谁解决过什么）③正能量的大场面与高质量圈子。
- 好友标签体系（张飞）：A001 陌生人脉；B001 有效跟进（A 类经 5 次搭讪或见面后升级）；C001 顾客；D001 小组伙伴；另加来源标签 HG / TS / FM。用途是发圈分组与群发精准。
- 好友数量是硬指标（林老师）：先加到 5000。"在互联网时代，你好友都没有 1000 人，你说你不穷谁穷了？"5000 人里找到 6 个"要的人"，开出 6 条线，做到钻石轻而易举。
- 个人号 + 视频号 + 小红书，是从熟人池到陌生人池的漏斗。

### 2.4 内容生产流程

- T 型朋友圈（7.20 版把"网红朋友圈"正式更名）：横是广度（生活、学习、朋友），竖是深度（一个专业切口扎到底）。
- 形象五星：1 星随便发发（90%）；2 星随时模仿（80%）；3 星固定标准（20%）；4 星创造自己的游戏规则；5 星高大上。
- 期待感三要素：人物、时间、结果。"最"字搭配四条：最贵最少见 / 最远最美丽 / 最亮最有名 / 最多最疯狂。
- 小专家三式：立 Flag 现身说法、身体力行的过程与感悟、过程监督 + 充分互动；配固定标签 #营养早餐第 N 天 #美好生活天天见 #改变故事。借力公司内容时必须加"自己"：别人的图 + 你的自拍出镜。
- 1:7 配比（陈默君）：每天 10 则动态 = 7 则生活 + 3 则商业，另配每日一条短语音。
- 30 支短语音 / 30 天日更，每支 90 秒：前 10 支卖自己（原生家庭、想成为谁、要去哪），中 10 支晒事业，后 10 支晒产品。
- 真人出镜短视频 6 步（2.15 版）：自拍录像讲自己的故事作旁白 → 素材码放 → BGM 选纯音乐避开重音鼓点 → 简单修饰 → 封面（图片里有"我"、标题"抓人"、8–10 字）→ 去片尾 logo 导出。
- AI 文案：文小言指令示例"请以感动为主题，给 10 段朋友圈文案"；二次编辑原则是 90% 模仿 + 10% 创新。
- 社群内容日历（2.15 版）：每月 1 次健康读书会打卡跟学；每周二 KOC 故事会；每周五健康知识讲座（安利 APP / 安利云知道）。
- 真实是唯一的护城河："真实才有力量"（陈文聪）。线上负责真实分享，线下负责情感链接。

### 2.5 轻创业的线上打法

- 定位→标签→吸粉→转化，四步顺序不能乱：定位决定吸谁，标签决定发给谁，吸粉决定基数，转化决定收入。
- 吸粉渠道：微信群、论坛、学习群、同学群、老乡会、小红书、豆瓣、兴趣群、物业群。共同点是"你已经在的场"。
- 转化靠工具接住：在线客服 + 8 万个问题库 + 2 万多个内容，把"答不上来"变成"查得到"。
- 一对一变一对多（黄安利）：2015 年起用微信群讲课，最多 21 个群同时开，零成本万人会议——"每个人都插上了翅膀"。
- 家庭聚会管熟人，社群管陌生人（林炜的边界）："转化熟人不用社群，家庭聚会就可以了。社群的目的不是转化熟人，是转化陌生人。"陌生人只能广种薄收，再靠数据筛选。
- 花园—家园—果园（陈默君，即成冠金三角）：花园=晒生活；家园=每天对 3 个对象讲销售推荐服务、认识 1 个陌生人、打 10 通电话；果园=收成与复制。
- 三个团队样本：张舒怡（100 多位伙伴 90% 来自互联网）；刘会霞（3S 搬上线、全员朋友圈、公益群、三人小群 + 直播）；陈文聪（"自用加分享"，33 人小群起步）。
- 线上人才成长速度：刘会霞用费曼学习法带营养讲师，20 天到 1 个月上台。

### 2.6 小程序工具

华客小程序后台 11 步，可压成四段：

1. 店铺底座：基础资料 → 配送与运费模板 → 小程序配置（Appid / AppSecret）→ 图片空间 → 店铺分类 → 添加商品。
2. 模板与代码：模板市场 → 综合电商页面管理 → 下载代码 → 代码包管理 → 下载无社区代码包并解压。
3. 域名配置：微信公众平台 → 配置服务器域名。
4. 发布：微信开发者工具导入 → 编译 → 上传 → 版本管理 → 提交审核 → 发布。

工具的意义不是技术，是让下单、留资、复购可统计。



### 2.7 KOC 案例

- 吴晓君：2018 年彩超发现 4×3mm 钙化灶或肝内胆管结石，经医生营养师社群营养干预，2021 年复查无异常；另有肺结节案例。起点是"宿舍里敢给舍友打头皮针"——敢开口的人才有故事。
- 陈默君：多囊卵巢、生理期 4–8 个月一次、被判不孕，营养早餐调理后受孕；日更"阿默姐姐成长日记"就是把这类故事一天一条讲出去。另三个案例：IG 上观察两年的男生一年做到白金；被诈骗 140 万的家庭主妇两年还清；00 后电商女孩月流水 100 万台币、收入仅 3 万，一年做到创办人白金。
- 陈文聪的三个案例：法务部爱美的女生，营养早餐没放水就开始发圈，做到营销总监；26 年 IT 主管，同学会问护肤，答"给你 10 万整好"，对方说"一分钱都不要，你自己去买"；工地妹 3000 元工资、零人脉，做到新晋经理。
- 黄安利：曾博士 25 岁读博，半小时看懂办卡，打印收入单发现"能买一辆马六"，全职后做到经理、钻石，带出两副总监——人才需要正反馈；陈文聪 2016 年溧阳大会两张票，会后会当天宣布"我们团队今天正式开始"。

## 三、关键数字 / 案例 / 话术

- 好友基数 5000 人；群发邀约 600–800 人 / 半小时，到场 100–200 人，从中捞 20 人、开出 2 条线。
- 案例·张舒怡：23 岁抓风口年入百万→亏损、焦虑、身体出问题→纽崔莱；2018 高级主任→6 万分红宝石→2021 营销经理→2022 营销总监。
- 案例·刘会霞：月活前排约 30 个，个人小组每月超 2 万分；个人直播七八百场，团队精品课程超 500 节。
- 话术·陌生人的第一句（黄安利）：对方通过视频号找来，第一句问"你通过什么认识我的"，第二句问"你有没有安利卡"。
