# 大健康 · 慢病解决方案机遇 — 文案讲稿

> **用途**：讲「大健康机遇」的**落地篇**——大健康到底在哪里落地、怎么落地。
> **一句话主线**：**大健康落地 = 做慢病解决方案**（不是卖产品，卖产品没前途）。
> **讲法顺序**：先讲需求 → 再讲医生解决不了 → 再讲根在生活方式 → 讲信息差 → 讲我们的服务链路。
> **来源**：张医生口述录音整理 · 关联 → [[大健康机遇-事业发展框架-讲稿大纲]]

---

## 一、开场：大健康怎么落地？

引流的健康人群进来，到哪里落地？—— **落到大健康。**

那大健康怎么落地？—— **做解决方案，不是卖产品。**

> 记住一句话：**卖产品是没有前途的。** 产品谁都能卖，方案才是壁垒。

我们的路线是**做解决方案**。现在整个系统已经跑通了几个**成熟的解决方案**：

| 板块 | 现状 |
|---|---|
| **体重 / 肥胖** | 最强板块之一 |
| **痛风 / 高尿酸** | 成熟 |
| **糖尿病** | 强项，做到「逆转」 |
| **高血压** | 成熟，有完整的逆转方案 |
| **妇幼 / 孕期** | 很成熟 |
| **儿童营养**（增高、身高管理、视力发育） | 都跟营养相关 |

---

## 二、为什么是慢病？需求井喷

现在整个的体量，**需求量非常大**：

- **肥胖 / 超重**：中国超重人群已占 **50.7%**，约 **7 亿人**；国家专门出台「体重管理三年行动」。
- **痛风 / 高尿酸**：**过亿**，而且**年轻化**，二十多岁的已经很多。
- **糖尿病**：过亿，持续增长。
- **高血压**：**井喷式发展**。

需求是真的，而且是**过亿人的刚需**。

---

## 三、老百姓的路径，和医生的武器

关键来了：需求这么大，老百姓怎么办？

**老百姓出现这些问题，是不是都去找医生？** —— 是。

**那医生能做什么？** 要么**手术**，要么**药物**。

**手术和药物，能不能解决这些问题？** —— 解决不了。

为什么？因为 **所有问题的源头是生活方式**。手术和药物解决不了生活方式，它们只能**对症、控制指标**。

**这就是整件事的突破口。**

---

## 四、以高血压为例，把逻辑讲透

拿高血压讲最清楚。（下面这套讲法，可以原样讲给客户听。）

### 4.1 高血压真正的病理改变是什么？

**两大方面：**

1. **血管壁弹性下降、血管硬化** → 血管弹性差了，血压就上来。（冠心病的冠状动脉粥样硬化是同一回事。）
2. **血管里的血液垃圾多、"瘀积"** → 血糖高、血脂高，脂质斑块沉积在血管壁上，**管腔变窄，阻力变大** → 血压升高。

一句话：**要么血管壁的问题，要么血管内容物的问题。**

**那血管弹性为什么会下降？**
- **维生素 C 不够**。维 C 促进胶原蛋白合成，胶原蛋白是血管弹性的基础。随年龄增长胶原蛋白本就在减少，很多人维 C 又不够 → 胶原蛋白合成下降 → 血管变脆、弹性下降。
- **抽烟**。抽烟会消耗大量维 C 去解尼古丁的毒 → 血管这边维 C 更不够用。**所以抽烟的人高血压高发，这是一个很重要的因素。**

**那血管里的垃圾为什么会多？**
- **高糖饮食、血糖血脂高、肥胖** → 垃圾多、斑块沉积。

**你发现没有 —— 这些全是生活方式的问题。** 维 C、抽烟、高糖、肥胖……**源头就在这里。**

### 4.2 那医生是怎么解决的？

到了医院处理高血压，**基本都是用药**（高血压做不了手术）。主流的降压药分**三大类**：

| 类别 | 代表药 | 降压机制（一句话） |
|---|---|---|
| **血管扩张剂** | 硝苯地平（地平类） | 血管窄了？把你的血管**扩大一点** → 血压降下来 |
| **利尿剂** | 呋塞米、氢氯噻嗪（噻嗪类） | 把血管里的**液体排少** → 血少了，血压就下来 |
| **β 受体阻滞剂** | 美托洛尔等（洛尔类） | **减慢心率**，心跳别那么猛 → 血流冲击慢了，血压降下来 |

医生很聪明，机制都成立，**降压确实有效**。

### 4.3 但是：能降压 ≠ 解决根本

关键一问：

- 这些药，**有没有恢复血管弹性？** —— 没有。
- 有没有**清理血管里的垃圾？** —— 没有。

它既没解决血管壁的问题，也没解决血管内容物的问题。**它只是控制指标。**

结果就是：**终身用药，问题只会越来越严重** → 一种药压不住加两种、两种压不住加三种 → 最后这个人还是因为血管的问题走了。**没有一个是用药物真正解决的。**

### 4.4 机会就在信息差里

老百姓为什么会一直走这条路？—— **因为不知道。**

**这就是信息差。** 老百姓不知道，认为「医生帮我搞定了」；**很多医生也不知道，来了就按流程开药，他自己都高血压。**

而我们知道这个逻辑。**如果我们把这个逻辑讲给老百姓听**：这个问题要真正解决、把药慢慢减下来，是可以的 —— 关键是要**回归到源头去干预**。

**以高血压逆转方案为例：**
- 血管弹性 → 想办法**恢复**它；
- 血管垃圾 → 想办法**清理**它；
- 肥胖 → **减肥**（男性 BMI 要控制在 **22 以下**，这是高血压逆转非常重要的指标，效果非常好）；
- **控盐**（盐摄入超标要控）、**戒烟**。

你看，所有方案是不是都**作用到了根本问题**上？—— 所以它**一定有效果**。

> ⚠️ **分寸**：药物有药物的作用，**该用还得用，不能与药对抗**。血压高时先用药物控制住；但**控制不是终点**，终点是回到源头，慢慢帮客户调养。

## 五、我们怎么服务一个客户

所以当一个客户来找我们，我们**不会像医生一样直接开药**，而是：

1. **讲逻辑** —— 把上面这套病理和机制讲通，让他自己明白；
2. **出方案** —— 生活方式干预 + 营养补充，帮他调养；
3. **做陪跑** —— 建服务群，长期跟进；
4. **见改善** —— 3 个月、6 个月后指标改善；
5. **成口碑** —— 客户变成 **KOC**、变成**忠实客户**，还会带来新客户。

**顺带就成交了**：当客户理解了逻辑，**他就能接受用产品了**。产品不是硬推的，是方案里自然的一环。

---

## 六、为什么一定是慢病，不是配餐

有人会问：做配餐行不行？—— **不行，配餐没有痛点。**

给别人搭配饮食，**没有痛点，就没有付费意愿。**

**慢病才有痛点**：过亿人的刚需、井喷式发展、老百姓找不到出路 —— **有痛点才有付费，有方案才有复购。**

> **做大健康，一定是走慢病。**

## 七、落地打法

**公域获客 → 做解决方案。**

前端（公域）解决「人从哪来」，后端（解决方案）解决「人怎么留下、怎么复购」。

---

## 八、现场常被追问（备好答案）

- **"这不是跟医生对着干吗？"** → 不对抗。药该用还得用，我们做的是医生没时间做的那半段：生活方式 + 营养 + 长期陪跑。
- **"凭什么信你说的？"** → 讲逻辑，不讲结论。先把血管壁、血管内容物两条病理线讲通，对方自己就明白了。
- **"配餐不是更简单吗？"** → 配餐没痛点，慢病才有付费意愿。
- **"为什么用大品牌的产品？"** → 客户吃出问题，丢的不是产品，是你在客户那里的信任。
