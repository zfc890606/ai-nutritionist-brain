## 一、整体逻辑（一条线讲完）

**框架 → 需求 → 医生路径 → 根因 → 信息差 → 打法 → 平台**

本质就两块：**互联网（获客）+ 大健康（落地）**。
需求是过亿人的真需求 → 老百姓都去找医生 → 医生只能手术+药物、控指标不治根 →
根在生活方式 → 这是**信息差**，也是我们的机会 →
我们做**解决方案**（不卖产品）→ 安利提供**工具 + 人才** → 一个人也能做成千万级事业。

| 01 | 封面 · 大健康机遇 | 抛数字：中国成人超重/肥胖 **50.7%、约 7 亿人**。这不是小众需求 |

| 03 | 引流走 3.0 | 三步：**做内容（公域）→ 沉社群 → 接需求**。不是加好友刷屏，是用内容把需求吸过来 |
| 04 | 六大成熟解决方案 | 体重/肥胖 · 痛风高尿酸 · 糖尿病 · 高血压 · 妇幼孕期 · 儿童营养。**每个板块背后都是营养干预的空间** |
| 05 | 需求井喷 | 50.7%（≈7 亿）· 痛风过亿且年轻化 · 糖尿病高血压持续增长。**需求真实，供给端却只有手术和药物** |
| 06 | 老百姓都去找医生 | 医生的武器只有两样：手术、药物 → **只能对症控指标，解决不了源头** |
| 07 | 三大类降压药 | 血管扩张剂（硝苯地平）· 利尿剂（呋塞米/氢氯噻嗪）· β 受体阻滞剂（洛尔类）。各自机制一句话讲清 |
| 08 | 能降压 ≠ 解决根本 | 一句重话：**没有一种降压药，是去恢复血管弹性、清理血管垃圾的**。药物该用还得用，但不与药对抗 |
| 09 | 根在这两件事 | ① 血管壁弹性下降、硬化 ② 血管里垃圾沉积、管腔变窄 → 同一个结果，两个来源 |
| 10 | 源头都在生活方式 | 弹性差 ← 维 C 不足 / 年龄 / 抽烟；垃圾多 ← 高糖 / 肥胖 / 血脂血糖。**全是生活方式 → 意味着可以干预** |
| 11 | 机会就在信息差里 | 大众：出问题→找医生→开药；我们的视角：追生活方式→营养+行为干预→出方案陪跑。干预方向含 **男性 BMI 控制在 22 以下** |
| 12 | 服务一个客户的链路 | 讲逻辑 → 出方案 → 陪跑 → 见改善（3–6 个月）→ 成口碑 → **成伙伴** |
| 13 | 为什么一定是慢病 | 配餐**没有痛点**；慢病是**过亿人的刚需**。有痛点才有付费意愿，有方案才有复购 |
| 14 | 安利给的第一样：工具支持 | 不建厂、不做供应链。纽崔莱 **93 年**：稳定、安全、商誉。品牌倒了，你的口碑也跟着倒 |
| 15 | 第二样：人才平台 | 伙伴办卡开店，不用你发工资、算钱、报税。**你只做两件事：获客 + 带人**。一个人 1000 万干不动 → 100 人 × 10 万很轻松 |
| 16 | 结语 | 互联网把人带进来 · 大健康把人留下来 · 安利让你做得大 |

## 三、现场易被追问的点（备好答案）

- **"这不是跟医生对着干吗？"** → 不对抗。药物该用还得用，我们做的是医生没时间做的那半段：生活方式 + 营养 + 长期陪跑。
- **"凭什么信你说的？"** → 讲逻辑，不讲结论。先把血管壁、血管内容物两条病理线讲通，对方自己就明白了。
- **"为什么不用便宜的品牌？"** → 供应商要够稳。客户吃出问题，丢的不是产品，是你在朋友圈里的信任。
- **"我一个人做不动怎么办？"** → 不是让你一个人扛，是让 100 个人每人做一点。
