## 二、邵艾伦的核心理论体系

他把个人成长拆成「身体 + 大脑 + 心态」三件套，再由 AI 串联：

```
孙学（脑子）   → 认知升级：理解财富、自由、机会
薄肌（身子）   → 身体升级：主动健康管理
黄毛（耳朵）   → 心态铠甲：屏蔽外界噪音，认定对的就彻底执行
AI（掌舵者）   → 接入整套系统：记录数据、分析方向、辅助执行
```

> 一句话：**孙学管脑子，薄肌管身子，黄毛管耳朵，AI 管方向。**

## 三、薄肌理论（= 用户问的「搏击理论」）详解

### 3.1 本质：只有两件事

按邵艾伦原话，练出薄肌本质就两件事：

1. **有肌肉量**（build muscle）
2. **让肌肉不被脂肪盖住**（lose fat）

> 世界上不存在「薄肌」这种肌肉，也**没有「薄肌卧推」「薄肌飞鸟」**这种动作——薄肌只是一个**组合状态**。

**成品图景**：穿衣显瘦、脱衣有肉——脸干净清爽、下颌线在、肩膀挂点肌肉、胸有厚度、腰没赘肉、腹肌一崩六块八块。

**薄肌 vs 大块头**：
- 薄肌拼实用，「练给日子用」
- 大块头拼围度，「练给镜子看」

### 3.2 三大支柱（理论层）

| 支柱 | 核心论述 |
|------|---------|
| **肉体是「碳基服务器」** | AI 时代人可指挥大量 AI 工作，唯一单点故障风险是自己的身体崩溃 → 健康是**一票否决**项 |
| **肌肉是「抗风险储蓄」** | 肌肉 + 心肺占健康权重约 50%；肌肉像身体里的**银行账户**，要趁年轻像存钱一样存肌肉 |
| **认知先于身材** | 先立理论，再谈肌肉；认知先于身材存在 |

**寿命量化模型**（孙宇晨在访谈中升级）：把寿命打 100 分，其中心肺 25 分、肌肉 25 分——抗阻训练是拿满这 50 分的关键。

**⚠️ 警惕减重陷阱**：司美格鲁肽等药物可能「减重同时削减肌肉」，导致基础代谢断崖式下跌，陷入「越打药 → 代谢越低 → 越易反弹 → 晚年肌无力」的循环。

### 3.3 训练唯一心法：渐进式超负荷（Progressive Overload）

> 「如果这期只记一个概念，就是它。」

健身没什么秘诀，健美圈喜欢把简单的事复杂化（一组六下还是八下、空腹有氧还是饭后有氧、蛋白什么时候吃——都不重要）。真正决定身材的只有四件事：

1. 训练重量有没有增加
2. 蛋白质有没有吃够
3. 总热量是盈余（surplus）还是缺口（deficit）
4. 有没有长期坚持

**操作极简**：
- 今天卧推 40kg×6 → 下次 42.5kg×6 → 再下次 45kg×6
- 重量到瓶颈就加次数：90kg 做 4 下 → 下次争取 5 下 → 再下次 6 下，「多做的这一下都是进步」
- **别看泵感、孤立训练、酸不酸痛，直接看重量、看记录，Numbers don't lie。**

**参考书单**：他大二读的《Bigger Leaner Stronger》，给了他完整的健身 foundation。

### 3.4 体脂标准与「画质」分级

**薄肌男孩体脂区间：12%～16%**（皮下脂肪要薄，绝不能有腹型肥胖——不能丢下颌线、不能有啤酒肚）。
**臂围别超过 40cm**——练太狠就成了「厚肌」「麒麟臂」。

邵艾伦的「画质」比喻：

| 体脂 | 档位 |
|------|------|
| 10% 以下 | 传奇皮肤 |
| 13% | 原皮肤（及格入场券） |
| 15% 以上 | 720P（五官被吃掉） |
| 18% 以上 | 420P（几乎没法看） |

**反直觉操作**：目标定得比想要的更低。想练到 13%，就定 10–11%，给生活留 2–3% 的缓冲，否则一浮动就滑到 15–16%。

### 3.5 训练步骤（可照抄版）

**频率**：
- 力量训练 **每周 3–4 次**，以复合动作为主
- 训练日与非训练日**交替（一天隔一天）**
- 有氧辅助每周 2–3 次，每次 20–30 分钟（慢跑、跳绳、爬楼机），只为控体脂露线条，「过度会掉肌肉」
- 「薄肌战神计划」＝一周三天，围绕四大项设计

**动作**：
- **四大项优先**：深蹲、硬拉、卧推、杠铃推举——「只练这四个，肌肉量都会暴涨」
- 核心复合动作：卧推、深蹲、硬拉、引体、划船；每个动作 **4 组 × 每组 8–12 次**，重量不用太大但要动作标准
- 分化安排示例：推日（胸/肩/三头）——上斜卧推、卧推、杠铃肩推，可选飞鸟
- **零成本自重版**：俯卧撑、引体、深蹲三个基础动作，「地板还没开始收费」，同样贯彻渐进式超负荷

**蛋白质**：
- 每公斤体重 **1.6–2.0 克**（有版本写 1.6–2.2g/kg）
- 邵艾伦自述目标：**每天 148–150 克**
- 补充：**蛋白粉 25 克 + 肌酸 5 克**；他强调蛋白粉「就跟吃蛋白一样」，不是「科技」，主要作用是减轻必须吃大量食物的压力

**饮食**：
- **三戒**：奶茶炸鸡、配料表数不过来的零食、越觉得好吃的越要戒
- 原则：**高蛋白、适量碳水、少油少糖**，热量保持轻微缺口或维持，**不要节食**
- 进食顺序：**先吃高蛋白的**
- 减脂缺口控制在 **600 千卡以内**，目标是增肌减脂同时进行

**邵艾伦本人的 AI 工作流（7 步）**：

1. 起床后先工作，然后吃第一餐
2. 饭前饭后各拍一张照给 AI（Claude），算卡路里并提示进食顺序
3. 补蛋白粉 25g、肌酸 5g
4. 训练日练硬拉、深蹲等主动作（训练日/非训练日交替），非训练日正常工作
5. 训练时由教练拍视频，发给 Claude Code 记录「每组 12 次、做三组、用多少公斤」
6. 用 Oura Ring 抓睡眠与卡路里数据，与摄入相减，缺口控制在 600 千卡以内
7. Claude Code 每天出**日报**，追踪渐进超负荷与完成情况，计划先看三个月效果

> **一句话总结**：练薄肌 = 渐进式超负荷做力量训练 + 吃够蛋白质 + 控制热量（增肌期盈余、减脂期缺口）+ 长期坚持，把体脂压到 12%～16%、臂围不超过 40cm，其余都别纠结。

### 3.6 争议与提醒（务必如实标注）

- 批评者认为：3–6 个月根本练不出搏击/薄肌，除非不上班、每天只吃练睡，或有运动底子、体脂低
- 普通人三个月不请教练可能连动作都没掌握；薄肌要长期控饮食、保低体脂，**维持很难**
- 若只谈「吸引异性」，性价比不高
- ⚠️ 薄肌 ≠ 极致低体脂，不必照搬硬练，**尤其女生**；体脂过低或过高都有健康风险（有荟萃分析显示体脂率与全因死亡风险呈 **J 形**关联）
- 网络流传的「每周六练、每次 40 分钟」「9+15 轻断食」「一天一粒奥利司他」等属于**他人自拟方案，非邵艾伦核心教程**，需区分

## 四、孙宇晨 × 邵艾伦 4 小时 22 分对谈 · 核心内容整理

> 全片：约 4 小时 22 分（部分整理稿称 4.5 小时），2026-10-09 发布于 X，标题《年轻人如何抓住 AI 时代的机会》。孙宇晨访谈中自称 36 岁。

### 4.0 总框架：版本答案「孙学 + 薄肌 + 黄毛 + AI」

- **孙学**：解决怎样理解财富、自由和机会，升级认知与决策系统
- **薄肌**：不追夸张肌肉，追低体脂、线条干净、肌肉紧致，强调主动健康管理
- **黄毛思维**：当选择不符合主流期待时，能承受质疑，继续执行
- **AI**：接入整套系统，记录真实数据、分析方向、辅助执行

### 4.1 开场：孙宇晨的「全 AI 化一天」

- 吃饭前后各拍一张餐桌照丢给 Claude Code 算卡路里，安排进食顺序（先吃高蛋白）
- 补剂：蛋白粉 25 克、肌酸 5 克
- 训练日：深蹲、硬拉等，教练拍视频记录组数、重量，按渐进超负荷加码
- 睡眠和消耗用 Oura Ring 采集
- 所有数据存本地 Markdown 文件，**换模型也能接着用**
- 蛋白质目标 140–150 克
- 练薄肌起因：被 AI 一句话点醒——「**你物质上是个富人，但身体上是个穷人**」

### 4.2 重回 20 岁、没人脉没资源怎么开始

- 孙宇晨回答「也还是不难」，强调**认知决定命运**
- 即使月可支配收入不到 1000 元，也可先用便宜国产 AI 工具（智谱、Kimi、豆包）把生活、健身、日程数字化
- 三件套零成本武装自己：孙学（升级对金钱/财富/万事万物的认知）· 薄肌（主动健康管理）· 黄毛理论（认定对的就彻底执行）

### 4.3 百分百相信 AI

- 自称「百分百相信 AI」，让 AI 当掌舵者，人只做约 **10% 的微调**
- 但也会跟模型吵架、补充条件重新分析，并对比多个模型
- 建议先积累 **2–4 个月的现状数据**，再统一交给 AI 分析方向

### 4.4 先探图，再下注（侦察兵思维）

- 用游戏（红警、星际）里的斥候作比喻：不要只顾在基地攒兵，先了解地图
- 引申：买房先看 100 套、买车看 100 辆、择业先摸清大量行业岗位，先建立信息基准再决定
- 被评价为经典的「**最优停止问题**（秘书问题）/ 37% 参照系套利」——先观察约 37% 的候选项，之后遇到明显优于此前所有选项的机会再行动（注：访谈中黄金分割说法与经典 37% 结果并不完全一致）

### 4.5 全球商机（信息差套利）

- 以不同国家 AI API 和订阅服务价格差为例（token 在阿根廷、土耳其、尼日利亚便宜，美国贵）
- 商业机会来自**地区信息差、成本差、供需差**
- 主张把全世界消费者当潜在客户
- 共同特征：**凡是被数据和自动化重做一遍成本结构的地方，都藏着机会**

### 4.6 财富观与人生目标

- 「**先自由，后财富**」：自由首先意味着灵活，能换城市、换行业
- 建议年轻人 **30 岁前尽量轻资产**，别被房贷车贷锁死；早年提「30 岁前不买房、不买车、不结婚」，核心是**保留选择权**
- 用「逐水草而居」形容自己——哪个地方能发挥最大作用就去哪里
- **财富自由后仍想去上班**：想获得其他公司的第一手经验和员工视角，甚至表示愿意倒贴 5000 万美元去 OpenAI 或 Anthropic 工作、一分钱工资不要
- 强调保持 **Small Ego**、放下自我、持续更新认知

### 4.7 概率思维与投入产出比

- 把「这事能不能成」换成「有多大可能成、成了赚多少、败了亏多少」——从二值判断换成**分布判断**
- 投入产出比最大化：能赢就行，过程中别人怎么评价，不计入成本

### 4.8 Crypto 的终极本质

- 把区块链定义为：**把人类古老的货币翻译成 AI 与机器听得懂的可编程语言**，为硅基 Agent 经济体提供高精度微支付与即时清算基础设施
- ❗ 其中关于加密资产的内容仅为个人看法，**不构成投资建议**

### 4.9 访谈结尾的细节

- 邵艾伦提到：一年前曾给孙宇晨各平台发过一封长自荐私信想加入其团队做内容、没有回音；一年后他坐到了孙宇晨对面完成这场访谈
- 孙宇晨最后说「应该是 cover 了所有的话题」

- 网上对孙宇晨的评语：「**孙哥的币你别买，孙哥的话你得听**」
