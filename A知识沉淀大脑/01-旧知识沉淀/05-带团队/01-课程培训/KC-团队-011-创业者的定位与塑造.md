# 创业者的定位与塑造

> 一句话：**定位决定顺位**——创业者的定位分两头：**对内是"由内而外的成长"（起心动念），对外是"与世界相处的方式"（成冠十字理念）**。这两头立住了，做事业根本不需要技巧。

## 一、课程背景

- 场景：全成冠年会（全球约 1 万人）后的**线上复盘分享**，由朱森伟主持、张飞医生主讲。
- 主讲人身份：从三甲医院麻醉医生转型的安利创业者（B31），做安利近 10 年。
- 主办方的判断：年会"一年只有一次"，把最新、最重要、最核心的**创业者能力**集中传递，"没有一句废话"；现场 1 万人的场域本身就是内容的一部分。

## 二、核心框架：创业者定位的两个维度

```
创业者定位 = 对内（个人的起心动念）+ 对外（与世界相处的方式）
             ↑ 定位决定顺位
```

### 维度一 · 对内：由内而外的成长（起心动念）

| 要点 | 说明 |
|------|------|
| **通用性** | 无论事业、工作还是家庭，"拿到好结果"的核心相通：**由内而外、真实的自己在成长** |
| **成冠精神** | 一句话：**变得更好** |
| **困难是常量** | 任何行业、任何场景都有挑战，人生没有十全十美、没有一辈子顺畅 |
| **关键分水岭** | 遇到困难时，是**保持成长的内心、自我鼓励、自我肯定、无条件自信**，还是被困难困住 |
| **多数人卡在哪** | 卡在**发心**——没想过"活出希望、活出精彩、让一个更好的自己诞生"，于是活在负能量里，成为"乌合之众" |
| **起心动念的力量** | 主讲人自述："在医院看不到希望，但我选择**不被环境控制**，选择起心动念去找那个我想成为的自己" → 于是去创业、去挑战、去尝试。**偶然，也是必然** |

> 💡 **自我肯定的句式（可直接给伙伴用）**：
> "我能在一个三甲医院工作，能把一条生命从濒临死亡的状态抢救回来——外面没有比这更难的工作了。带娃难吗？学。演讲难吗？学。销售难吗？学。找人、沟通难吗？学。"

### 维度二 · 对外：与这个世界相处（成冠十字理念）

> "决定自己可以，并不一定能成功——因为**没有英雄的个人**。个人能力很微弱，但个人影响力很大。"

**指南针 = 成冠理念十字：尊重 · 诚信 · 独立 · 合作 · 挑战**

| 理念 | 内涵 | 反面（自我检视） |
|------|------|----------------|
| **尊重** | 做一个受人尊重的人；先值得被尊重——靠谱、言而有信、对自己高要求，让领导放心、伙伴放心、顾客放心 | 不守时、拖拉、不靠谱、做事不用心 → **尊重是有条件的，是要配得的** |
| **诚信** | 对得起自己的良知，不蒙骗别人，不伤害别人的利益（对顾客、对团队都一样） | 蒙骗、伤害他人利益 |
| **独立** | 有独立面对市场的能力 | 事事依赖、无法独立作战 |
| **合作** | 懂得欣赏别人、团队合作；拥抱周围每一个伙伴，**借助一切可以借助的力量**；为此要收掉自己的个性 | 单打独斗、放不下个性 |
| **挑战** | 遇到困难（生活/家庭/工作）敢于迎接，**习惯**迎接 | 一遇问题就恐惧、退缩 |

> **落地检验**：把这十字用在**每一天、每一件事**上——对家庭、家人、合作伙伴、团队、领导人、顾客、每一个新朋友。做到了，一定让更多人喜欢你、认可你，你也就影响更多人。

### 维度三 · 变与不变

| | 内容 |
|---|---|
| **会变的** | 方法。每个时代方法都在变——只要肯学习、肯扎根、肯钻研，任何时代的方法都能掌握 |
| **不变的** | 两个内核：① 个人的起心动念 / 愿力 / 自我肯定；② 与世界相处的方式 |

> 这两头做好，做事业**根本不需要技巧**——"技巧很 low，'搞定别人'很 low"。你会成为一个发光者、一个能量发射器。

## 三、为什么"必须到场"

> 白纸黑字放在这里，你不一定听得明白、感受得到。

- 同样的内容，只有身处**1 万人的场域**里才能真正感受、真正领悟。
- **有些东西必须亲自体验**——体验 → 领悟 → 印在心里 → 理解到位 → 才会行动。
- 结论：这类会议"是创业路上最难的一个部分"，解决了它，很多东西就变简单了。**有机会一定要争取参加。**

## 四、落地动作：复盘

- 方式：**安静下来，用纸和笔写**。
- 虽然"百日筑基"提醒复盘，但**没有百日筑基，人生也要不断复盘**。
- 复盘问自己：这段时间哪方面可以做得更好？是不是可以不那么偷懒？对待他人能不能更到位？能不能不那么急、更心平气和、更耐心？
- 底层认知：**只有自己才真正了解自己**；参照成冠理念指引自己的一切行为，不断修炼自己。
- 心态：**成功是水到渠成的；但更重要的是，在成功的过程中一路在成长。**

## 五、主讲人目标（现场表态）

- **近期**：翡翠没问题——已掌握当下最好的生产力，思路清晰，公域流量、社群都已打通，接下来**勤快努力达至翡翠**。
- **长期**：希望 **10 年之内做到 FC**，实现人生终极目标。

## 六、金句库（可转述 / 可做朋友圈素材）

1. **定位决定顺位。**
2. 让别人看到，一个更优秀、正在成长的自己，正在诞生。
3. 没有英雄的个人——个人能力很微弱，但个人影响力很大。
4. 尊重是有条件的，是要配得的。
5. 你能做多大，取决于你能影响多少人。
6. 当你把内核这两件事做好，做事业根本不需要技巧。
7. 成功是水到渠成的，但更重要的是成功的过程里，你一路在成长。
8. 有些东西，必须你亲自去体验——体验了，才能印在心里。
