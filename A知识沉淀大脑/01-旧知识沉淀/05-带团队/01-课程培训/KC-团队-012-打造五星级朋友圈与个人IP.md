# 打造五星级朋友圈与个人 IP

> 一句话：**IP 的本质不是专业，是能量。** 新人用 2–3 个月走完「学习 → 实践 → 人设成立」三步立住 IP；再用 **T 字型朋友圈**（横＝大杂家·情绪价值，竖＝小专家·功能价值）把能量呈现出来；发圈**只发结果、不发答案**——做营销，不做推销。

> ⚠️ 本卡为**团队内训存档**（私域内部），非对外内容。

---

## 一、开场：为什么这堂课重要

- **信息泛滥时代，真正有价值的信息是稀缺的。** 没有清晰定位、没有未来目标的人，很容易在"信息垃圾"里迷失自我。
- **大健康行业本质上是营销的一门学问。** 营销不是贬义词——**人生无处不营销**，它中性甚至偏褒义。
- 人要晋升、要带一群人做事、要处理家庭问题，都得学会**营销自己**：把你内心真正有价值的价值观推出去，别人才会认同你；认同你的人多了，做事就变简单。
- 人是群居动物：只要跟社会产生联系，就必然遇到"人跟人不同"——想法不同、认知不同。差别就在于你会不会把自己"销售"出去。

> 📌 **课程的来历（为什么要认真听）**：这堂课来自广州一位互联网大咖的**录播课**（对方自己报班花了 **10 万**），张医生听完之后才对 IP 打造、朋友圈打造有了概念。课程分两堂：
> ① **新人如何用 2–3 个月建立 IP**（本课的起点，新人重点听）
> ② 人设成立后，如何把"小 IP"打造成"大 IP"（后端品牌）

## 二、新人如何 2–3 个月建立 IP

> 导师**林伟博士**说过一句话：**一个人不管你过去是什么——是一张白纸也好、是宝妈也好——想打造 IP，三个月足够了。**

```
第1步 从学习开始     →  真实记录你在学习、成长的过程（不是展示你多厉害）
第2步 从学习 → 人设  →  自己的效果 + 考证 + 上舞台（学习者 → 拿到结果的人）
第3步 人设最终成立   →  名片/标签/专业度到位（水到渠成）
```

### 第 1 步 · 从学习开始

| 要点 | 说明 |
|------|------|
| **核心动作** | 把你在学大健康、学营养的**日常和场景真实呈现出来**——学基础班、考营养师证、看什么书、哪一点打动了你、你认同什么 |
| **最容易犯的错** | 一上来就告诉别人"我很厉害"（晒案例、晒讲课舞台）——**没那么快，别人接受不了** |
| **正确姿势** | 学到什么，**用自己的话讲一遍**即可，不需要很专业，**最真实的表达最好** |
| **本质** | IP 的起点是"一个正在认真学习的人"，而不是"一个已经成功的人" |

> 🎯 **案例 · 赵旭老师**：原本是街舞老师、健身教练，**不是大健康行业的**，但 IP 打造非常到位。原因就是——他从**学习**开始，真实地记录：看了哪本书、书里哪点打动自己、自己认同什么，一条一条发出来。他事实上也在做，所以**非常真实**。

### 第 2 步 · 从学习者 → 人设成立

- 光"一直在学"是**没有 IP 的**——学习的人只有学习者身份，撑不起人设。
- 关键节点：**你自己的效果 / 实践结果**。学了之后先帮到自己，把过程记录下来。
  - 例：伙伴阿维自己在减肥，就一边学、一边记录"我怎么把自己瘦下来的"。
- 再往前一步：**考证**。一张证 = 一个人设的支点，你从"学习者"变成"拿到证书的人"。
- 然后开始有**舞台**：在社群里讲一堂课、在线下做一次分享……每一次经历都记录、都呈现。
- **让别人相信这个 IP 是真的——因为它不是一个结果，而是一段旅程、一个过程。**

> 🎯 **张医生自己的例子**：当年把"6 块腹肌"练出来的全过程一直在记录，最后呈现出来时，**信任感、IP 感非常强**。

### 第 3 步 · 人设最终成立

- **标志**：你的**名片更新**了——别人看到的你的标签、人设、专业度，整体变得很专业。
- **这一步是水到渠成的**：从小白 → 拿证 → 做案例 → 讲课 → 上舞台 → 学员案例呈现，别人看着你一步一步走过来，自然觉得你专业，人设自动成立。
- **后续自然发生的**：客户信任 → 咨询 → 成交 → 指导费 → 客户交付。
- **周期**：整个过程不需要太久，**大概 2–3 个月就够了**。

## 三、高价值 IP 的本质：能量

### 1. 北京的故事

张医生去年一个人去北京玩，在鸟巢拍了照，见了两个人——**都是第一次见面**：

- **吴医生**（儿科医生）
- **罗博士**（北京中医药大学，内分泌专业博士，当时快毕业，至今保持紧密沟通）

这两个人，**第一次见面就请他吃饭、送书送礼物，当天就开了卡**。

> 为什么？不是因为他专业——**专业的人很多**。是因为长期的朋友圈打造，人设和品牌吸引了他们：**他们已经认可这个人、认同他，像朋友一样，已经被影响了。**

当时发的朋友圈，吴医生回复：**"一见如故……我羡慕张老师蓬勃旺盛的生命力，被深深感染。"**

> 💡 **结论**：真正 IP 的本质 = **你强大的生命力、价值、能量吸引了别人**。

### 2. 人与人的根本区别：谁的能量更高

- 任何事情——哪怕生活琐事、单位里的人事——最大的区别点都是"**谁影响谁**"。
- 而谁影响谁，**取决于能量高低**。你的能量比他高，你的能量就会传导、就会影响他。

**霍金斯能量等级表**（课堂引用）：

| 区间 | 说明 |
|------|------|
| **200 勇气** 及以上 | 数值越往上越高：勇气、魄力、敢折腾…… |
| **200 以下** | 能量越来越低：羞愧、内疚、冷漠…… |

> 那两个人看到张医生，看到的是**他身上高能量（350？400？）的部分**——不是他这个人本身，是他的能量影响到了对方。

### 3. 怎么提升自己的能量？

- 能量是由很多具体的事产生的。**恰恰是在困难里爬起来、跟命运抗争、做高能量的事**，你的能量就会呈现出来。
- 能量越高，就越能影响更多的人；做任何生意、做任何工作要往高处走，**一定是你的能量更高，才会影响别人、获得认同**。

> 🎯 **张医生的两个"高能量事件"**：
> 1. **2015 年，26 岁**：农村出来的孩子，按常理最传统保守，却自己投 **30 万开奶茶店**。
> 2. **2020 年**：在三甲医院工作近 10 年、**月收入约 3 万**，**选择辞职**不做医生，转做大健康。
>
> 陌生人看到这两件事，看到的是**勇气、魄力、敢折腾**——全是高能量词。

> 💡 **当下生活困难，其实不用怕**：它恰恰是你**提升能量的机会**。人生提升能量的机会并不多——大部分人都喜欢平顺，一遇困难就失衡、就趴下。能看懂的人，会把它当成**提升能量维度的机会**；维度一高，做任何事都会变简单。

### 4. 打造 IP 到底是什么？（认知纠偏）

| ❌ 不是 | ✅ 是 |
|--------|------|
| 作秀、表现自己、晒自己多厉害 | 把一个人内心深处**蕴藏多年的能量**，在某个事件点上**爆发出来** |
| 功利、跟人赌气、要超过谁 | **自动自发自觉**的行为，需要**强烈的企图心** |
| 让自己爽 | 让自己强大起来，**让别人看到你能量的高维度**，从而影响、帮助、赋能更多人 |

> 🎯 **张医生自己的"坎"**：他原本是个"文绉绉"的人——喜欢写书法、玩音乐、追求高大上；个性签名是文艺长句，头像是艺术背景，朋友圈发的都是很有文化的东西。那时要做安利、晒案例、推产品，**心里有很大的坎，很难接受**。
> **根本原因是：对 IP 的理解不够、维度不够。** 认知到位了，才做得对；否则**永远被自己卡住**。

> 📌 **打造 IP 的完整链条**：先跟自己对话 → 再走出去跟世界链接 → 让自己强大起来 → 能量呈现 → 影响/帮助更多人。

## 四、T 字型朋友圈（高能量朋友圈的结构）

> 朋友圈是打造 IP 的重要阵地（视频号亦然）。

> 📊 **课堂引用数据**：发表在美国科学院报、加州大学对 **1200 万名 Facebook 用户**的统计——**爱发朋友圈的人，死亡风险直降 12%**。（鼓励大家习惯分享）

**T 字型 = 上面一横 + 下面一竖：**

| 笔画 | 定位 | 内容 | 提供的价值 |
|------|------|------|-----------|
| **横（一）** | **大杂家** | 多维展示真实生活状态：生活感悟、家庭、孩子、体验、运动、学习、旅行、成长…… | **情绪价值**——温度、共鸣、吸引（要有血有肉、真性情） |
| **竖（丨）** | **小专家** | 小切口 / 小圈子里的专业：营养赛道、你的专业、你帮了多少人、你的证书、你的成长、陪跑客户 | **功能价值**——信任、成交（KOC / KOL） |

> 一句话记法：**朋友圈内容一定要做 T 字型结构——既做杂家，又做专家；既是人生的百科全书，又是小圈子里的专家。**

> 🎯 **张医生的朋友圈示例（横的部分）**：宁波早上 4 点起床去看日出、一边跑步一边读书、打球、学习、旅行……
> 都是**热爱生活、积极、有温度**的一面。
> ⚠️ **不要发**：负能量、吐槽、八卦、是非——这些体现不出你的人生状态。

> ⚠️ **常见误区**：做大健康就**天天只发案例、只发知识、只发健康海报**，忘了生活。**你要去热爱生活。**

> ❌ **反面教材**：模板化的"健康信息简报"（AI 批量生成的卡片式内容）。**真正要发的是用自己话表达的内容**——现在有 AI 大脑，可以训练 AI 出模板，但**一定要加上自己的话**。

## 五、营销 vs 推销（发圈的核心铁律）

**我们是做营销，不是做推销。** 营销是正面词；推销是中性偏负面词——**没人喜欢被推销**。

> 🔑 **核心区别：营销 = 制造"有问题的结果"。**
> **只发结果，不发答案。**

| | 发什么 | 结果 |
|---|--------|------|
| **营销（✅）** | 只发**结果**：这个人好了、这个学员改善了……**但不告诉他怎么做到的** | 对方会想"这是怎么弄的？方案是什么？"——**制造期待感** |
| **推销（❌）** | 发出**答案**：营养素方案、产品、各种配比细节全盘托出 | 一旦能看出答案的，**都叫广告；广告没有人看** |

> 🎯 **课堂练习**：轻断食 / 护肝计划各有两段话，判断哪段是营销、哪段是推销——**判断依据就是这个**：有答案的是推销，只有结果的是营销。

> 📌 张医生自己的朋友圈：**基本全是"结果"，从来没有"答案"**——怎么做到的，永远不说。

## 六、朋友圈门面：五件套

IP 成立之后，要把"门面"做专业——它是**传递价值**的第一入口：

1. **背景图**
2. **简介**
3. **名字**
4. **头像**
5. **置顶**（置顶朋友圈 / 置顶视频）

**置顶放什么**：你的**高光时刻**、你的个人价值、你帮别人解决问题的成果。

**其他可发**：身边正能量的圈子、大场面、高质量的圈子——让别人看到你在不断成长、跟很多优秀的人在一起，**这些都在提高你的能量**。

> 🎯 **学员实践**：学习之后，把自己的**朋友圈五件套全部重新调整**一遍。

## 七、收尾：基础工作做在前面，链接才轻松

- 把这堂课的东西做好、从小白一步步做起来，**持续做这些基础工作**，再去做线下链接，效能会非常高——**因为别人已经在朋友圈"看过你"了，你的 IP 和能量已经出来了。**
- 反之：朋友圈什么都没有、能量也没呈现出来，你跟他本来同能量、甚至你比他还低（他是老板，你只是小护士），却去讲健康、讲安利、讲大健康——**很难，因为你的能量没出来。**
- 那时的典型症状：跟进困难、对方听不进去、get 不到你的东西——**停留在"术"的层面（方法的层面）**，总觉得好难。
- **能量上来了，很多工作都是别人来找你**，而不是你拼命去推销。"术"是最后才呈现的东西。

> 🎯 **对照北京那一幕**：很多工作早就做完了——最后办卡、沟通，都变得非常简单。

## 八、金句库（可转述 / 可做朋友圈素材）

1. **人生无处不营销。**
2. 一个人不管你过去是什么，想打造 IP，**三个月足够了**。
3. IP 的起点不是"我很厉害"，而是"我正在认真学习"。
4. 让别人相信的，不是一个结果，而是一段旅程。
5. **IP 的本质不是专业，是能量。** 专业的人很多，能影响人的能量很少。
6. 人与人最大的区别点：**是谁影响谁**——取决于能量高低。
7. 当下越困难，越是提升能量的机会。
8. 打造 IP 不是作秀、不是功利、不是让自己爽——是让别人看到你能量的高维度，从而帮助更多人。
9. **朋友圈既要当杂家，又要当专家**：横是情绪价值，竖是功能价值。
10. **做营销，不做推销——只发结果，不发答案。**
11. 能量没上来，你就永远停在"术"的层面。
12. 能量高的时候，很多工作是**别人来找你**，不是你拼命去推销。

## 九、落地清单（给伙伴的作业）

- [ ] 朋友圈**五件套**（背景/简介/名字/头像/置顶）全部重做一遍
- [ ] 打开自己的朋友圈，数一数：**横（生活）占几条？竖（专业）占几条？** 只有竖的，先补横
- [ ] 本周起，**每天记录一条"学习过程"**（看了什么书、哪点打动你），用自己的话写
- [ ] 检查最近 10 条朋友圈：**有没有发出"答案"（方案/产品/配比）？** 有则改成只发结果
- [ ] 写 3 条自己的"高能量事件"（越难时做的决定越算），作为个人故事素材
- [ ] 删掉/停发：转发式健康信息简报、吐槽、八卦、是非
