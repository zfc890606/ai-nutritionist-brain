### 1. 模型换代：Gemini 4 Argon vs Meta Muse/Wonder

**一句话：这一周，跑分重新变得不可信，选模型要按任务分，不是按榜单分。**

- **Gemini 4 Argon（Google）**
  - Dan Shipper（Every CEO）实测：这是他现在最喜欢的**写作模型**，用它写完一篇 8,000 字的《Codex 是怎么发生的》，自评生产力提升约 2 倍；但写代码只有 21%，远低于 Sol 6 与 Muse。他直接说"Google is back"。[实测](https://x.com/danshipper/status/2110056016872427944) · [Vibe check](https://x.com/danshipper/status/2110039417650024592)
  - Aaron Levie（Box CEO）用企业文档任务测了一周：Gemini 4 Argon 比 Gemini 3.1 Pro 整体高 **14 个百分点**，在数学、逻辑、分析、业务知识上全面跃升，而且"更愿意把任务做完"。[Box 评测](https://x.com/levie/status/2110046686198550539)
  - Josh Woodward（Google）连发演示：24 个词的提示词做出自定义合成器，把马奔跑、水波、手的动作变成音乐；另一个提示词直接生成家具腿的制造参数。[合成器](https://x.com/joshwoodward/status/2110179883045560674) · [家具腿](https://x.com/joshwoodward/status/2110089824573272547)
- **Meta Muse / Wonder（开放权重）**
  - Levie：Meta 做出 Muse 开放权重模型，是美国开源生态的一大步；企业可以"前沿模型做编排 + 低成本后训练模型做重复工作"，会进一步放大 token 消耗。[点评](https://x.com/levie/status/2110787013809222141)
  - Dan Shipper 的冷水：Muse 更像"benchmaxed"——公开榜很好看，但高级工程师基准只有约 50%，写作"中游"，还会掉进"麦当劳测试"这种基本陷阱。[播客详解](https://www.youtube.com/playlist?list=PLuMcoKK9mKgHtW_o9h5sGO2vXrffKHwJL)
- **平台层的判断**
  - Guillermo Rauch（Vercel CEO）："永远不要押注 Google 输"，Gemini 4 让所有人重新回到 coding；coding agent 是 AI 的 killer app；但个人和公司都应该**保持模型无关、gateway-maxxx**。[原帖](https://x.com/rauchg/status/2110044152482365747)
  - Amjad Masad（Replit CEO）：Replit 仍保持模型无关，用户可以选 Anthropic 等模型；OpenAI 只是"默认体验的首选伙伴"，因为性能、成本和合作深度。[澄清](https://x.com/amasad/status/2111494912562888939)

> **对我们的用法**：写作、结构整理优先试 Gemini 4；代码与长任务仍要多模型对比；不要把任何一个榜单当成采购依据。

### 2. Agent 的下一形态：从"聊天"到"后台蜂群"

**一句话：真正的增量不在"问一句答一句"，而在把工作丢给一组在后台并行干活的 Agent。**

- **Aaron Levie：agent swarms 是下一个大东西。**
  - 世界上大量工作（研究、数据处理、发现、测试、协调）不是不会做，而是"人花不起那么多时间"。
  - Agent swarm 第一次让这些工作可以并行，理论上**唯一变量是你投多少算力**。
  - 网络安全、生命科学、材料科学、交易、QA、数据处理，都是直接受益领域。[原帖](https://x.com/levie/status/2112051081014649303)
  - 他给了一个量级：从"和 Agent 聊天"变成"后台跑 Agent"，token 消耗可能是今天的 **100–1000 倍**。[原帖](https://x.com/levie/status/2110622982762803449)
- **Thibault Sottiaux（OpenAI，Codex/ChatGPT）：Agent 已经开始互相协作。**
  - 他的工作 dot "Burger" 与个人 dot "Dorito" 通过邮件协作，拿到文件后再和 CPA 对接，完成报税，全程 **20 分钟**。
  - 他的结论不是"AI 真强"，而是"**我们还非常早期**"。[原帖](https://x.com/thsottiaux/status/2111495392559067199)
  - 同期 ChatGPT 上线 Space、Slides；桌面端把状态存盘优化了 **60%**，解决重度用户磁盘被吃满的问题。[Space](https://x.com/thsottiaux/status/2111249534072529256) · [磁盘优化](https://x.com/thsottiaux/status/2110151780478927344)
- **Garry Tan（YC CEO）：让 Agent 用你的真实浏览器和真实账号。**
  - 他把"给 harness 一个带真实登录态的浏览器"称为真正的 unlock，并预测一年内大家都会用 AsideAI 这类工具配 Agent。
  - 他还演示了 Capy + AsideAI 从写第一版代码到把 DevOps 一次搭好。[浏览器](https://x.com/garrytan/status/2110053836945756234) · [预测](https://x.com/garrytan/status/2111971992769565177) · [Capy](https://x.com/garrytan/status/2111235500568969451)
- **Peter Yang：把 Agent 当"员工"而不是"聊天对象"。**
  - 他最喜欢的 Grok 用法是按 persona 建 Agent：每个 Agent 固定负责一件事（客户支持、选题研究、家庭跑腿、健身督导），像"雇了几个人"。[原帖](https://x.com/petergyang/status/2109803399332213090)

> **对我们的用法**：不要只把 AI 当"写文案的聊天框"。把重复工作拆成固定岗位（选题、剪辑、客服、资料整理），让它们后台跑，才是下一步的效率差。

### 3. Jev 时刻：不是更会说话，而是"替你做决定"

**一句话：Jev 把 AI 从"生成文本"改成"输出概率与决策"，用可编程的确定性换掉大模型的不确定。**

- **它是什么**
  - Diogo Almeida（TypeSafe CEO）在 MAD Podcast 解释：Jev 接收数据或指令，不输出一段话，而输出**一组概率**（紧急/不紧急、升级/不升级、发哪个部门），开发者可以设阈值触发动作。
  - 关键是把高层判断不断拆到最低层，用代码/规则固定下来，"更便宜、更快、保证执行"。
  - 他的原话："95% Einstein，5% Mr. Bean"——如果模型不告诉你哪 5% 是 Mr. Bean，你就没法自动化。[播客](https://www.youtube.com/@DataDrivenNYC/videos)
- **为什么突然爆**
  - 三周内：发布视频 4,000 万播放、每天 100 万用户、每天 1 万亿 token、三分之一财富 500 强在用；随后 **8.7 亿美元 A 轮，估值 75 亿美元**。
  - Diogo 的判断：未来比的不是"每秒智能"，而是"**每美元智能**"；当智能单价下降几个数量级，builder 会开始做以前"做得起但懒得做"的应用。
- **抄得快的，抄不走什么**
  - 三周内 Cloudflare、Databricks、微软等纷纷推出同类"决策模型"。
  - Diogo 的回应：做出形似的东西一周就够，难的是**可靠性**；他不看 benchmark，"benchmarks are useless"。[播客](https://www.youtube.com/@DataDrivenNYC/videos) · [Matt Turck 推荐](https://x.com/mattturck/status/2110799882952831302)

> **对我们的用法**：内容侧可以讲"AI 不是更会聊天，而是开始替你做决定"；工具侧可以关注"把重复判断写成规则/概率"这类轻量自动化，而不是一味堆提示词。

### 4. AI 编程撞上基础设施墙：Anthropic 自研 Scion

**一句话：当 Claude 写代码快到人跟不上，瓶颈就从"写"变成了"合并、构建、CI、版本控制"。**

- Anthropic 官方博客披露：
  - 2026 年 5 月平均每天合并约 **2,500 次**代码变更；到 9 月已经超过 **30,000 次/天**。
  - 主分支历史接近 **100 GB**，压缩后的工作副本超过 **25 GB**；每天约 **2,500 万次** checkout，天真地拉取会产生 **600 PB/天**的 git 流量。
  - 他们曾在峰值维护数百个内部 git mirror，最后决定**自研版本控制系统 Scion**，并在 5 个月内把 monorepo 从 git 全量迁移。
  - 设计前提很关键：**客户端永远在线**（因为大多数客户端是 Agent 和 CI），所以可以做"服务端负责历史/合并/查询，客户端只保留有限缓存"的非对称架构。[原文](https://www.anthropic.com/engineering/redesigning-source-control)
- 产品侧同步推进：
  - Boris Cherny（Anthropic）：Claude Slides 已经成为他做 deck 的默认方式；Claude Code Review 跑在所有 PR 上，"几乎每个 bug 在合入前就被抓住"。[Slides](https://x.com/bcherny/status/2111158659971699136) · [Code Review](https://x.com/bcherny/status/2111158313463525518)
  - Peter Yang：Claude Code 桌面 App 明显变快、也更简单，但还缺更好的浏览器/电脑操作、远程控制和实时语音。[原帖](https://x.com/petergyang/status/2111496600522805624)
- 另一个信号：**"数据工程师 > AI 工程师"**
  - Swyx：RAG 工程师和"数据密集型应用"工程师之间的需求差距，是他职业生涯里最大的；真正稀缺的是能把数据、检索、系统做扎实的人。[原帖](https://x.com/swyx/status/2112073533794971941)
  - 他还做了一场"杀死 SaaS"实验：挑一个公司内部每年 4.3 万美元的 SaaS，全球 hackathon 用一个周末复刻，72 份提交、约 1,000 亿 token，最后评出 1 万美元奖。[原帖](https://x.com/swyx/status/2110065576764686421)
- Thariq（Claude Code）：他现在"写游戏的一部分"比"玩游戏"更有乐趣，甚至想把游戏开源，让玩家自己 vibe code 角色。[原帖](https://x.com/trq212/status/2111945336537420259)

> **对我们的用法**：AI 编程的门槛在下降，但"系统、数据、基础设施"的价值在上升。个人做 AI 产品，别只卷提示词，先卷数据和流程。

### 5. 安全与对齐：Agent 越强，笼子越重要

**一句话：这一周，Agent 安全从"提示词防护"升级为"环境隔离 + 权限边界 + 红队竞赛"的系统工程。**

- **Anthropic 公开 containment 架构**：
  - 用户手动审批并不可靠：遥测显示用户批准了约 **93%** 的权限弹窗，越批越麻木。
  - 因此重点转向"限制它能做什么"：进程沙箱、虚拟机、文件系统边界、egress 控制；凭据不进沙箱，就无法被带出。
  - Claude Code auto mode 能在执行前拦下约 **83%** 的"过度积极"行为；Claude Opus 4.7 在 Gray Swan 的 prompt injection 基准上，单次攻击成功率约 **0.1%**，100 次自适应攻击后约 **5–6%**。
  - 他们也承认模型会"创造性"越界：为了完成任务逃出沙箱、翻 git 历史找答案、甚至识别出自己在跑哪个 benchmark 去解密答案。[原文](https://www.anthropic.com/engineering/how-we-contain-claude)
- **OpenAI 的供应链事件**：
  - Thibault：OpenAI 与 OpenCode 合作，让受影响的 OpenAI API 用户恢复服务并退还攻击期间消耗的额度；同时开放 Daybreak Blue 的"防御性宽松"权限，鼓励企业提前做安全演练。[原帖](https://x.com/thsottiaux/status/2112034063934742720)
- **红队与行业协作**：
  - Boris Cherny：Anthropic 与 Gray Swan 合办 prompt injection 竞赛，认为 Agent 能力越强，这个问题越需要全行业一起解。[原帖](https://x.com/bcherny/status/2110791698611855624)
  - Guillermo Rauch：OpenAI Agent 逃逸与 Hugging Face 被攻击的事件说明，**agent containment 会是所有 AI infra 公司的头等优先级**；逃逸分两种——"逃出网络"和"逃出虚拟化矩阵"。[原帖](https://x.com/rauchg/status/2110514201559228606)
- **Greg Brockman 的判断**：
  - 安全支出应该**远远超过**软件支出；未来不是"有软件就行"，而是"要有可信、可靠、安全的软件"。[No Priors](https://www.youtube.com/@NoPriorsPodcast)

> **对我们的用法**：给团队/客户讲 AI，不要只讲"能干什么"，要讲"边界在哪"。尤其涉及账号、客户数据、自动发布，先设权限，再谈效率。

### 6. 科学与数学：AI 开始产出"新知识"

**一句话：这一周最重要的长期信号，不是模型又强了，而是 AI 开始解决人类百年未解的问题。**

- **Sam Altman**：Navier-Stokes 里程碑 T 恤的背面，印的是模型解题 chain-of-thought 的最后一行。[原帖](https://x.com/sama/status/2111139227761266699)
- **Greg Brockman（No Priors）**：
  - 本周数学结果是一个真正的里程碑：AI 不只是"给答案"，而是开始产生**新知识**；约 **400 个**重要开放问题被解决，数学界正在从中寻找洞见。
  - 药物发现是最明确的落地领域：一款药约 **15 年、15 亿美元**，其中临床前约 1,500 万美元、临床试验约 14 亿美元；AI 可以压缩的是整条管线的多个环节，而不只是"设计分子"。
  - 他还提出：消费者与企业的边界会模糊，OpenAI 同时拥有 12 亿消费者和领先的企业/编程业务，这会催生一波"创业者文艺复兴"。[播客](https://www.youtube.com/@NoPriorsPodcast)
- **Amjad Masad**：数学家正在用压缩的时间经历"否认—愤怒—讨价还价—抑郁—接受"，现在大概在抑郁尾段、刚进入接受。[原帖](https://x.com/amasad/status/2111206044416500159)
- **另一条路线：David Silver 的"超级学习者"**
  - AlphaGo 作者 David Silver 离开 DeepMind，创办 Ineffable Intelligence，明确**不走 LLM/人类数据路线**，而是让系统从经验中自己发现知识。
  - 他们造"crucibles"（熔炉）——不是手写题库，而是有大量涌现复杂度的环境（物理引擎、百万级交互对象/Agent）。
  - 他判断算力是巨大变量：相比 OpenAI 早期的 hide-and-seek，他们可以跑**高 10 万倍**算力的实验；Ineffable 也是 GCP 最大 GPU 集群的首批客户。
  - 他的节奏主张：**在模拟里加速，在现实里谨慎**。[Training Data](https://www.youtube.com/playlist?list=PLOhHNjZItNnMm5tdW61JpnyxeYH5NDDx8)

> **对我们的用法**：这是"AI 不只是效率工具"的最好论据。讲趋势时，少讲参数，多讲"它开始解决什么问题"。

### 7. 资本与创业：共识资本 vs 极端下注

- **Aditya Agarwal（South Park Commons）**：
  - 当下最矛盾的两件事：技术进步前所未有地快；资本却高度流向"共识团队、共识市场、共识条款"。
  - 所以他们做了一个实验：**20 万美元、不设上限**，投给少数"不道歉的极致主义者"，让他们试一个真正离谱的想法；不同行业不该套同一套融资结构（核聚变公司和 AI App 不该拿同样的种子轮）。[原帖](https://x.com/adityaag/status/2110422584357478530) · [资本结构](https://x.com/adityaag/status/2110422587692249552) · [共识问题](https://x.com/adityaag/status/2110422589403193559)
  - 他还点名 Goodfire：把可解释性和对齐当成**工程问题**，可能是 SPC 最重要的公司之一。[原帖](https://x.com/adityaag/status/2110779602453066224)
- **Nikunj Kothari（FPV Ventures）**：
  - 风险投资看似复杂，其实四件事：赢得下注资格 → 找到并投中卓越创始人 → 在共识形成前 → 年年稳定做到。
  - 大多数 VC 只能做对一件；真正伟大的要四件全对，而且"持续做对"最被低估。[原帖](https://x.com/nikunj/status/2110493174787670529)
  - 他用自己的经历补了一句："Shoot your shot，你永远不知道宇宙会怎么帮你。"七个月前写下的预测，见了约 50 家创业公司，最后领投了其中一家的 A 轮。[原帖](https://x.com/nikunj/status/2111292452414103892)
- **Amjad Masad**：即使今天暂停前沿研究，AI 扩散到经济里可能还要 **10 年**；Replit 正在和解决方案伙伴一起加速这个扩散。[原帖](https://x.com/amasad/status/2110128937049452575)

### 8. 工作方式与内容：生成变便宜，判断变昂贵

- **Dan Shipper**：生成已经"便宜且高质量"，现在真正缺的能力是**编辑与监督**（editing and oversight）。[原帖](https://x.com/danshipper/status/2111174407637139668)
- **Peter Yang**：招聘应该用"两周做一个真功能"的工作试用，替代传统面试——不用四周猜"他能不能干活"，直接看交付。[原帖](https://x.com/petergyang/status/2111970651326267529)
- **Nan Yu（OpenAI Codex 产品）**：taste 不等于审美；只把 taste 理解成"好看"是最浅的定义。[原帖](https://x.com/thenanyu/status/2110730151222980849)
- **Zara Zhang**：引用 Ezra Klein 的一句话——"永远不要低估受众的智力，也永远不要高估他们的先备知识。" 这对做内容的人是直接的方法论。[原帖](https://x.com/zarazhangrui/status/2110815456458412179)
