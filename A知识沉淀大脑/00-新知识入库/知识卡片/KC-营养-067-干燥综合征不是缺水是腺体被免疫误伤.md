# KC-营养-067-干燥综合征不是缺水是腺体被免疫误伤

> **一句话本质**：干燥综合征不是「身体缺水」，而是免疫系统把泪腺、唾液腺当成目标，淋巴细胞浸润后「产水能力」下降。补水只能缓解症状，**控炎、护腺、防并发症**才是主线；营养是辅助，不是治疗。

---

## 🧩 因果 / 原理

### 1. 免疫层：耐受被打破

- 正常情况下，免疫系统对「自己」不攻击（中枢耐受 + 外周耐受）。
- 干燥综合征时，B 细胞过度活化，产生**抗 SSA/Ro、抗 SSB/La 抗体**，T 细胞和 B 细胞浸润外分泌腺。
- 结果不是「免疫力低」，而是**免疫反应打错了目标**。所以「增强免疫力」是方向性错误，正确说法是**免疫调节 / 免疫平衡**。

### 2. 腺体层：水厂被破坏

- 泪腺、唾液腺被淋巴细胞浸润 → 腺泡萎缩、导管扩张 → 泪液、唾液分泌减少。
- 于是出现：眼干、口干、鼻干、皮肤干、阴道干。
- 唾液减少还会带来第二层问题：**龋齿、口腔念珠菌、吞咽困难、说话费劲**。

### 3. 系统层：不只是「干」

约三分之一到一半的患者有腺体外表现：

| 系统 | 表现 |
|:----|:----|
| 全身 | 疲劳（最常见）、低热 |
| 关节 | 关节痛、关节炎 |
| 血管 | 雷诺现象（遇冷手指发白变紫） |
| 肺 | 干咳、活动后气短（间质病变） |
| 肾 | 夜尿多、反复低钾（肾小管酸中毒） |
| 神经 | 手脚麻、刺痛（周围神经病） |
| 血液 | 贫血、白细胞减少、淋巴瘤风险升高 |

### 4. 症状闭环（解释「为什么越调越累」）

```
腺体分泌减少 → 眼干、口干、鼻干
        ↓
鼻黏膜干燥/鼻炎 → 鼻塞 → 夜间张口呼吸
        ↓
口腔咽喉水分蒸发加快 → 口干加重 → 凌晨觉醒
        ↓
睡眠碎片化 → 皮质醇节律紊乱 → 疲劳、情绪差
        ↓
不想动、不想坚持 → 调理中断
```

**打破闭环的三个杠杆**：治眼干、通鼻塞、稳睡眠。

## 🔍 关键数据 / 证据

| 项目 | 数据 / 结论 | 备注 |
|:----|:----------|:----|
| 性别 | 女性约 90% | 40—60 岁高发 |
| 患病率 | 我国约 0.3%—0.7%（文献范围） | 不同研究差异大 |
| 干眼 | Schirmer ≤5 mm/5 min 为异常 | 正常 >10 mm |
| 系统受累 | 约 1/3—1/2 | 肺、肾、神经、血液 |
| 淋巴瘤 | 约 5%（部分队列 5%—10%） | 绝对风险仍低，但需随访 |
| Omega-3 与干眼 | 证据不一致：DREAM 研究（NEJM 2018）阴性；干燥综合征小样本有症状改善 | 可作抗炎底料，不作主力 |
| 维生素 D | 干燥综合征患者缺乏常见；与自身免疫关联以观察性证据为主 | 查了再补，不盲补 |
| 肠道菌群 | 干燥综合征存在口腔/肠道菌群失调 | 益生菌证据有限，可作辅助 |

### 诊断（2016 ACR/EULAR 分类标准，供理解，不作为自诊）

5 项，≥4 分且至少 1 项阳性：

1. 唇腺活检灶性淋巴细胞浸润，灶性指数 ≥1（3 分）
2. 抗 SSA/Ro 阳性（3 分）
3. 眼表染色评分 ≥5（1 分）
4. Schirmer 试验 ≤5 mm/5 min（1 分）
5. 非刺激性唾液流率 ≤0.1 ml/min（1 分）

> 诊断由风湿免疫科完成。营养师只做膳食与生活方式建议。

## 🛠 落地应用（营养师视角）

### 1. 先转诊，再谈营养

- **眼科**：干眼分型（水液层 / 脂质层 / 黏蛋白层）、角膜损伤。
- **风湿免疫科**：确认诊断、评估系统受累、决定是否用羟氯喹等。
- **耳鼻喉科**：鼻炎分型，排除结构性鼻塞。

### 2. 营养支持四条线

| 线 | 做什么 | 关键点 |
|:--|:------|:------|
| 抗炎 | Omega-3（EPA+DHA 约 2 g/d）、少精制糖/油炸/加工肉 | 证据不一致，别承诺「治干眼」 |
| 黏膜原料 | 蛋白质 1.0—1.2 g/kg、维生素 A、锌、B 族 | 黏膜修复需要原料，不是「补水」 |
| 免疫营养 | 先查 25(OH)D，再补维 D | 不盲补、不超量 |
| 肠道 | 膳食纤维 25—30 g、益生菌按需 | 从低量开始，2—4 周评估 |

### 3. 生活方式

- 加湿器 40%—60%；避免空调直吹。
- 热敷眼睑 + 睑缘清洁；无防腐剂人工泪液。
- 少量多次饮水；无糖口香糖/木糖醇；含氟牙膏；定期看牙。
- 睡眠：固定起床、早晨见光、睡前降光、咖啡因中午后禁。
- 运动：快走 20—30 分钟，每周 3—5 次；不追求强度。

### 4. 中医方向（课程框架）

- 燥证，肺胃阴虚为主，兼肝肾阴虚、肝郁。
- 眼干 → 肝开窍于目；口干 → 脾胃津亏；鼻干 → 肺开窍于鼻；凌晨 1—3 点醒 → 肝经当令。
- 方向：滋阴润燥、养肝血、润肺、疏肝；**忌温燥大补**（人参、肉桂、鹿茸、羊肉、辛辣）。
- 药食：银耳、百合、麦冬、沙参、玉竹、枸杞、桑葚、黑芝麻、梨、山药、莲藕。

## ⚠️ 边界 / 红线

**不能说：**

- 「干燥综合征能调理好 / 能根治」
- 「增强免疫力」
- 「多喝水就好了」
- 「吃三个月就能停药」

**不能做：**

- 用营养素替代药物
- 自行加灵芝、黄芪、蜂胶、紫锥菊等「增强免疫」类（活动期先问风湿免疫科）
- 用清肠、断食、排毒处理口干（会加重脱水）
- 大剂量维生素 A（脂溶性，过量伤肝；孕期致畸）

**必须就医：**

- 视力骤降、眼痛、畏光、角膜异物感加重
- 腮腺/淋巴结持续肿大、反复发热、夜间盗汗、体重下降
- 干咳、活动后气短
- 明显乏力、夜尿多、反复低钾
- 情绪持续低落、失眠加重、自伤念头
