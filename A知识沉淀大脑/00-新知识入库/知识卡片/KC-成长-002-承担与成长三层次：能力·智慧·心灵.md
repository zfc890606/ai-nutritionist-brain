# KC-成长-002-承担与成长三层次：能力·智慧·心灵

## 🔑 Key Insight（核心洞察）

**承担是成长绕不开的唯一途径，成长分三层：能力的成长（靠事上练）、智慧的成长（靠良知）、心灵的成长（靠格局）。** 林伟总监用三位偶像把这三层讲透——周恩来教承担（能力）、王阳明教良知（智慧）、林则徐教格局（心灵）。

> 一句话：能力在承担里磨出来，智慧在良心里长出来，心灵在格局里大起来。

---

## 📖 Knowledge（知识体系）

### 三层成长框架

| 层次 | 成长什么 | 靠什么 | 偶像与金句 |
|------|---------|--------|-----------|
| 第一层 | **能力的成长** | 事上练（实际承担） | 周恩来："在实际的斗争里增长才干，勇敢承担" |
| 第二层 | **智慧的成长** | 良知 / 知行合一 | 王阳明："事上练""致良知" |
| 第三层 | **心灵的成长** | 格局（做事难免有过） | 林则徐："世事难从无过立""苟利国家生死以" |

### 关键概念

1. **能力成长 = 承担出来的**
   - 不是先有才干再承担，是先承担才有才干
   - 每一次承担、每一次被抱怨，都是"事上练"（见 [[DJ-认知-027-事上练：每一次承担每一次被抱怨都是修炼]]）

2. **智慧成长 = 良知优先于规则**
   - 王阳明心学三句话：心即理、知行合一、致良知
   - "知"首先是**良知**——你知道什么该做、什么不该做
   - 再好的规则，没有良知的团队也运转不了（呼应韦伯《新教伦理与资本主义精神》、诺奖《国家为什么失败》：制度之上是人）

3. **心灵成长 = 接受"做事必有错"**
   - 林则徐"世事难从无过立"：想做事，一定会有过错
   - 被贬、被冤枉也不当回事，格局一开，世界就大了
   - "苟利国家生死以，岂因祸福避趋之"——为对的事承担，不计祸福

### 底层链条

```
承担（任劳＋任怨）→ 事上练 → 能力成长
                              ↓
                    良知 / 知行合一 → 智慧成长
                              ↓
                    接受过错、格局打开 → 心灵成长
```

## 🔗 Context（上下文/边界）

### 适用条件
- ✅ 团队带头人做价值观/信念建设时，用"三层成长"给伙伴一条清晰的成长路径
- ✅ 自己或伙伴遇到"被抱怨、怕担责"时，用来重构认知
- ✅ 讲"承担为什么是好事"时，作为讲稿骨架

### 边界/局限
- ⚠️ 这是价值观层面的成长框架，不是操作方法论——具体带法另见 [[KC-团队-001-情景领导力S1-S4：对不同的伙伴用不同的带法]]
- ⚠️ "良知优先于规则"的前提是团队有共同价值观；纯靠自觉没有制度的团队，也会散
- ⚠️ 三层有先后：没承担过（第一层），谈良知和格局容易变成空喊口号

### 跟已有知识的关联
- 与 [[KC-成长-001-环境选择是认知升级的第一推动力]] 互补：一个讲"外部环境推你成长"，一个讲"内部承担逼你成长"
- 与 [[DJ-成长-010-梦想由心而发责任是外界的期待]] 同属"责任/承担"议题：梦想是内生的动力，承担是外压的修炼，两者都不可缺

## ⚡ Kick（行动指引）

1. **给自己贴一层标签**：我现在卡在哪一层——是能力没磨够（去扛事）、智慧没长够（回良知）、还是格局没打开（接受过错）？
2. **找一件"会挨骂"的事主动承担**：从任劳走向任怨（见 [[DJ-成长-012-承担是两件事：任劳＋任怨]]）
3. **带伙伴时把三层讲给他**：先让他上手扛事（能力），再点他"什么该做什么不该做"（良知），最后让他看淡一次被冤枉（格局）
