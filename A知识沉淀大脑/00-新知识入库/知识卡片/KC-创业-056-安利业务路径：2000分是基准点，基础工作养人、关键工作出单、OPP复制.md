# 安利业务路径：2000分是基准点，基础工作养人、关键工作出单、OPP复制

> 一句话：**安利所有工作都收敛到一个基准点——2000分。先靠基础工作（朋友圈/社群/短视频）养出信任，再用关键工作（讲项目/讲方案/讲产品）出单；自己做到2000分后，靠 OPP 复制出下一个能复制2000分的人，复制4个就上银章。**

## 一、为什么是2000分

- 2000分是"个人"必须拿下的基本工作量（不含团队、不算龙卷风），是衡量"你到底会不会做安利"的基准点。
- 业务路径不清晰，就会"胡子一把抓"：今天想着出单、明天又懵，抓不住节奏。有了2000分这个基准点，每天的工作才有轻重、才出得来结果。

## 二、三层链条：基础工作 → 关键工作 → 2000分

| 层级 | 是什么 | 作用 |
|---|---|---|
| **基础工作** | 朋友圈认真发、社群养人输出、短视频/自媒体建IP | 让客户信任你、愿意听你讲——它是关键工作的"门票"，不能马上出单但不可或缺 |
| **关键工作** | 坐下来给客户讲项目/讲方案/讲产品（轻断食怎么减、糖怎么降、产品示范） | 客户听懂了才办卡，2000分从这里出来 |
| **2000分** | 对产品/项目有感觉 → 找到10-20个顾客 → 讲好方案 → 成交 | 结果，不是动作 |

- 对项目有感觉，才会主动找到对应的人：对轻断食有感觉，才会去找想减肥的人。

## 三、复制2000分 = OPP → 跟随团队 → 辅导陪跑

1. **OPP（讲价值）**：找到下一个能复制2000分的人，讲的是价值不是技巧——这是复制最关键的能力。
2. **跟随团队**：社群、复盘会接住这个人，让他留下来、跟着系统跑。
3. **辅导陪跑**：把你"怎么做到2000分"原样教给他（对项目的感觉、关键工作怎么做、社群朋友圈怎么配合），让他也长出2000分的能力。
4. 复制4个2000分 → 银章；银章之后继续复制，上经理不难。

## 四、认知决定你重不重视基础工作

- 认知不到位，会觉得"发朋友圈没用"，于是基础工作荒废、关键工作没有门票、2000分就出不来。
- 认知一旦到位（知道朋友圈在养信任、社群在养兴趣），这些"不能马上变现"的工作就变得重要、就会认真做。
- 迷茫焦虑的根源是"模糊"：遇到问题不拆解（为什么没成交？需求在哪？哪里没讲好？），就只剩一句"好难"；拆解清楚，模糊就消失，该补哪补哪。

## 五、边界条件

- **2000分是个人基本工作量**，是辅导路径，不是对外承诺"做到2000分就能赚多少"；创业线不承诺收入、不夸大结果。
- **复制的前提是自己先做到**：自己2000分没出来，复制就是空话（呼应 [[KC-团队-004-团队复制四步法]]）。
- 合规：讲个人经历可以，讲"必然成功"不行；对外不引导问诊、不承诺结果。
