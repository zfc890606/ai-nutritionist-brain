# 《社群运营双群漏斗——公益群养新人，共修群转顾客》

> **一句话本质**：把社群做成商业闭环的"底盘"——公益群转化新人（项目/方案），共修群转化顾客（常客会/伙伴），主理人轮值 + AI 提效，一群人合力运营，避免唱独角戏。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
- 公域、朋友圈来的人"飘着抓不住"，没有承接载体，流量白白流失
- 一个人运营群 = 累 + 唱独角戏；大家各做各的群 = 没氛围、难坚持
- 自媒体做完后面没东西兜住，等于白干

**双群结构（漏斗式承接）**

```
朋友圈 / 公域（释放信号，被看见）
   ↓
公益群（有沟通基础的新人）→ 转化项目 / 方案
   ↓
共修群（办了卡 / 做了方案）→ 转化常客会 / 伙伴
   ↓
陪跑群（专属指导，跟进落地）
```

- **公益群**：只拉有沟通基础的人——公域看过你的、聊过健康/项目没成交的；不拉纯陌生人（开发成本高）
- **共修群**（家庭健康管理实操群）：只拉办了卡、做了方案的顾客，讲营养实操、常客会、大健康机会
- **入群标准**：没办卡的新人留在公益群养着；办了卡就"升级"到共修群，不用在多个群来回折腾

**主理人轮值制**
- 一个月四周，每周一个主理人，负责安排课程、主持、KOC、主讲嘉宾
- 人人参与、人人露脸练 IP，避免"啥都是张医生一个人"

**内容分级（见 [[DJ-团队-028-认知分层：客户认知10分就只给10分内容]]）**
- 公益群：通用观念 + 生活方式，不讲具体案例/方案/产品，只"发结果不发答案"
- 共修群：营养实操、常客会、大健康机会，都可讲

**固定栏目 + AI 提效**
- 固定栏目：周二 KOC 分享 + 周五健康微课堂 + 早晚打卡（早营养餐 / 晚护肝）
- 月课表海报、群公告、邀约话术、课程推广图，全部交给 AI 提效

---

## 🛠 可执行方法

### 最小行动
把原有各自为战的读书会群拆掉、合并成"一个公益群 + 一个共修群"，先定下本月四周的主理人排班。

### 完整执行步骤
1. 拆旧群 → 合并成双群，重新邀约"沟通过、有基础、没成交"的人进公益群
2. 定本月课表（按季节、按人群），做月课表海报 + 每场微课推广图（AI 生成）
3. 排主理人轮值表（四周四人），定主持、KOC、主讲嘉宾
4. 写群公告（统一命名：城市+姓名+推荐伙伴）+ 邀约话术 + 转群话术
5. 固定栏目运转：周二 KOC、周五微课堂、每天早晚打卡
6. 漏斗滚动：进人 → 筛选 → 转化，办了卡/做方案的转共修群，形成小闭环，再挂到系统大闭环

---

## 📍 场景与边界

### 适用场景
- 团队一起运营社群（高级主任市场合力）
- 有自媒体流量需要后端承接

### 边界条件
- 公益群绝不过早输出产品/方案/具体案例（认知没到，先教育）
- 不想进群的人，放朋友圈养，不硬拉
