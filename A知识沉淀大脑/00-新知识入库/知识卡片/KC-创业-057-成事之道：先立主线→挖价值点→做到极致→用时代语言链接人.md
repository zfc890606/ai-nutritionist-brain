# 成事之道：先立一条主线 → 挖出价值点 → 做到极致 → 用时代的语言链接人

> 一句话：**成事不复杂——先立一条主线当筛子，再从你真正做成过的事里挖出价值点，跟业态挂钩、选一个打磨到极致，最后用这个时代的语言（自媒体）让别人看见；财富和认同，是价值被认可后的结果。**

## 一、先立主线，学习才不变成盲目堆料

- 成长路上最普遍的问题：一直在学，却说不清为什么学。
- 主线就是一把筛子：有主线，才知道哪些该学、学了对自己这条路有没有用。
- 没有主线，东学西学，越学越乱，最后陷入迷茫。
- 判断标准只有一句：这件事学完，能不能直接服务我的主线？不能，就先放下。

## 二、成事公式：个人价值 → 帮助他人 → 财富与认同

```
找到个人价值 → 用它帮到别人 → 社会认同 / 金钱回报
```

- 财富的本质，是社会对你价值的认同；赚钱的背后，是你的价值对别人有帮助。
- 外在方法、技巧再多，都要回归这条主线：我的价值是什么，我怎么帮到别人。
- 做自媒体之前先答这两问——这本身就是商业定位课。

## 三、价值点怎么挖：只问一句"我过去做成过什么"

原则：回顾人生到现在，找自己真正做成的一件事，哪怕很不起眼。

| 类型 | 例子 |
|---|---|
| 结果型 | 腰突改善、把娃带到 985、减肥成功、把一件事做成 |
| 经历型 | 从三甲医院的迷茫焦虑里走出来、创业亏钱又爬起来、把几个孩子带大 |

- 标准：这件事要"拿得出手"，别人才会觉得你对他有帮助。
- 两个动作：① 先尽量列出来（可能有很多）；② 再筛——只留跟当下业态挂得上钩的。

## 四、跟业态挂钩，选一个，打磨到极致

- 不是每件做成的事都要用上；做安利、做自媒体，只选跟业态有关联的几个。
- 选一个，聚焦打磨，做到极致——成功的人都是把某一件做到极致。
- 粗糙就没有突出："减了 20 斤"遍地都是，凭什么成功的是你？
- 极致不是完美，是能被指认的结果：做减肥，就练出腹肌马甲线；做营养，就把方案讲到客户听得懂、愿意试。
- **赢一次，赢一辈子**；做成一件极致的事，你自己就是广告。

## 五、链接人：用这个时代的语言

- 普通人没有资源，链接人的办法是——让更多人看见你。
- 每个时代有每个时代的语言和工具；当下的语言就是自媒体。
- 不懂自媒体，等于不会用这个时代的语言，别人听不到你的价值。
- 自媒体不是随便拍拍：表达、打光、拍摄、选题，都要研究到极致——这些学习都聚焦在主线这一个点上。

## 六、认知高度决定执行强度

- 练马甲线只为好看，大概率练不出来，因为动力不够。
- 把它上升到人生层次：每一斤、每一块腹肌都在打造人生资产，人就会坚持，甚至急迫。
- 认知不到位 → 不觉得重要 → 不会认真做 → 做不到极致。
- 所以"心力不足"背后，往往还是"认知不足"。

## 七、边界条件

- 讲个人经历可以，不承诺"必然成功"、不承诺收入。
- "做到极致"是对自己的要求，不是拿来贬低别人的标准。
- 创业线不点名攻击传统行业或具体公司。
