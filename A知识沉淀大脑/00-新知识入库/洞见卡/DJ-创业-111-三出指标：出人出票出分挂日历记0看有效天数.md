# DJ-创业-111-三出指标：出人出票出分挂日历记0看有效天数

> **一句话洞见**：做安利就是三件事——出人（拉人）、出票（开卡/办会）、出分（出业绩）。三样今天都是 0，就等于今天没做安利。挂一本日历，每天记 0 或数字，两年后翻出来，看自己真正"有效工作"了多少天。

---

## 🧩 因果 / 原理

峰哥用一个朴素指标戳破"我做了很久"的幻觉：问伙伴"今天卖了多少东西？零。开了多少卡？零。出了多少票？零"——三样是 0，就是没做。

他让伙伴把日历挂家里，每天在日期下写个 0 或数字，两年后翻出来数"有效天数"。对比外卖员：送 14 小时见 50 个人挣 200 块；你一天见 50 个人、长期坚持讲 OPP，折到每天的价值远比那 200 块高。

核心：结果不是时间堆出来的，是"有效动作"堆出来的。用三个硬指标，把"我在做"和"我做了"分开——开卡两年 ≠ 有效工作两年。

## 🛠 可用方法

- 每天睡前用三个数自测：出人几个、出票几张、出分多少；三 0 = 今天没干活。
- 挂日历记 0/数字，月底数"有效天数"，别拿"在安利两年"骗自己。
- 约人用大数法则：峰哥国庆约 800 人来 4 个——问题不是技巧是工作量，约的量够了自然有人来。

## 📍 适用场景

- **脚本类型**：痛点共鸣型 / 方法教学型
- **位置建议**：开头用数字反差（"开卡两年，有效工作不到半年"）或结尾做行动号召（"睡前数三个数"）
