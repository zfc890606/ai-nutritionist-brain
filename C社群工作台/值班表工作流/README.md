# 公益群 / 共修群 · 月度运营值班表制作规则

> 用途：每月把「讲师 + 课程内容 + 排班」变成一张可直接发群、可直接打印的 Excel 值班表。
> 母版：[[C社群工作台/公益群:共修群运营值班表.xlsx]]（2026.10.5 — 11.1）
> 生成器：`C社群工作台/值班表工作流/gen_roster.py`
> 输入模板：`C社群工作台/值班表工作流/templates/2026-11.json`

---

## 一、这张表到底是什么

不是普通排班表，是**双群漏斗的月度作战图**：

- **健康公益群** = 养新人、建信任、做观念教育 → 目标是把人推进共修群
- **健康共修群** = 已办卡顾客、做实操、做复购与转介绍 → 目标是常客会和合伙人

两个群同一套周节奏，但**课程深度和讲师配置不同**：
公益群讲「观念 + 结果」，共修群讲「方法 + 实操」。

---

## 二、表的解剖（照这个骨架做）

一个 Excel，两个 sheet：`健康公益群`、`健康共修群`。

```
A1:I1  合并标题：《健康公益群》运营值班表（2026.11.2 — 11.29）
第 2 行  表头（9 列）
第 3 行起 第一周…第四周（11 月有 5 个周一，排到第五周，即第 7 行）
```

| 列 | 表头 | 填什么 | 规则 |
|---|---|---|---|
| A | 周次 | 第一周 / 第二周… | 固定 |
| B | 日期 | 11.2 - 8 | 周一到周日，跨月写全 |
| C | 主理人 | 本周总负责人 | 团队核心轮值，一人一周 |
| D | 主持人 | 本周群内主持 | 可与主理人不同，练伙伴 |
| E | 海报推广 | 做海报、发圈、邀约的人 | **默认 = 主理人**（原表 4 周全部一致） |
| F | 工作一·早晚营养餐打卡 | 固定文案 | 公益群：`每日早晚营养餐打卡，日常活群`；共修群：`每日早晚营养餐打卡` |
| G | 工作二·周二KOC故事分享会 | 故事标题 + 分享人 | 周二晚，案例见证型 |
| H | 工作三·周五微课堂（主题） | 课程名 | **红色加粗**，按下方命名公式优化 |
| I | 微课堂讲师 | 周五讲课人 | 优先博士 / 医生 / 护长等专业背书 |

**周节奏（固定不变）：**
- 每天：早晚营养餐打卡，日常活群
- 每周二：KOC 故事分享会（真实改变案例）
- 每周五：健康微课堂（知识干货 + 解决方案）
- 每周一位主理人，四周轮完一轮

### 公益群（绿色系）

| 斑马纹 | 偶数周浅绿 `#F7FBF7` |
| 课程名 | 微软雅黑 10.5 加粗，红 `#C62828`，左对齐 |
| 正文 | 微软雅黑 10.5，深灰 `#212121`，垂直居中，自动换行 |
| 边框 | 全表细黑线 |
| 冻结 | A3（锁标题 + 表头） |

### 共修群（蓝色系）

| 元素 | 规格 |
|---|---|
| 标题 | 微软雅黑 15 加粗，深蓝 `#0D47A1` |
| 表头 | 微软雅黑 11 加粗，白字，蓝底 `#1565C0` |
| 斑马纹 | 偶数周浅蓝 `#F5F9FF` |
| 其余 | 同公益群 |

### 列宽 / 行高

```
A 9 | B 13 | C 10 | D 12 | E 12 | F 20 | G 34 | H 36 | I 10
```

> 原表两张 sheet 的字号有 10 / 11 不统一、公益群标题只有 11 号，属于手工留下的不一致。本工作流统一成上面一套，视觉更整齐，风格不变。

## 四、课程名怎么起（这是这张表最值钱的部分）

### 公益群 · 两行式（拉新 / 观念层）

**公式：第一行给结果，第二行交底。**

```
第一行 = 具体结果 + 数字 / 时间 / 反差
第二行 = 这是「方案 / 路径 / 关键 / 清单」
```

原表已验证的四个样本：

```
全营养轻断食·7天科学甩脂
不挨饿也能瘦的减脂底层方案

血糖一步步回到安全线
糖尿病营养逆转的真实路径

孩子一年长高10cm的秘密
儿童追高益智科学营养方案

一人懂营养·全家少生病
做好家庭健康管理员的3个关键
```

**好用的词：**
- 结果词：甩脂、回到安全线、长高、少生病、睡得沉、气色回来、指标稳了
- 数字钩子：7天、10cm、3个关键、90天、30斤、1:8.5:100
- 反差词：不挨饿、不忌口、不花冤枉钱、别再……
- 交底词：底层方案、真实路径、科学方案、3个关键、清单、避坑指南

### 共修群 · 单行书名号（顾客 / 实操层）

**公式：《主题词 + 具体能拿走的东西》**

原表样本：

```
《营养早餐黄金配方》
《不同人群蛋白粉应该每天吃多少》
《儿童追高益智方案》
《AI+大健康赛道副业》
```

共修群不玩悬念，要**具体、可执行、一看就知道能学到什么**。
好句式：《XX 到底怎么吃》《XX 的 N 个搭配》《XX 人群的 XX 方案》。

### 命名三条硬规矩

1. **一行不超过 14 个字**，两行加起来不超过 28 个字，手机上要一眼看完。
2. **标题承诺「讲清方法」，不承诺「包治结果」**。
3. **合规红线**：不写治愈、根治、包治、永不复发、替代药物、停药；不写收入数字、躺赚、月入。
   - 原表「糖尿病营养逆转的真实路径」偏激进，建议以后改成「糖尿病营养管理的真实路径」或「血糖一步步回到安全线 · 糖尿病营养管理怎么做」。

## 七、交付前检查清单

- [ ] 两个 sheet 名称：`健康公益群`、`健康共修群`
- [ ] 标题周期与 B 列首尾日期一致
- [ ] 周次数量 = 实际周数（4 周或 5 周），日期与星期对得上
- [ ] C 列主理人 = E 列海报推广（除非你明确要求分开）
- [ ] 每周二 G 列、每周五 H 列都有内容，没有空周
- [ ] 课程名不超过两行 / 单行不超过 14 字
- [ ] 课程名合规（无治愈、根治、收入承诺）
- [ ] I 列讲师与 H 列课程对得上
- [ ] 文件已保存到 `C社群工作台/`，能正常打开、无错位
- [ ] 打开后整体看一眼：颜色、边框、换行是否正常

## 八、文件说明

| 文件 | 作用 |
|---|---|
| `README.md` | 本规则（版式 + 命名 + 输入模板 + 提示词） |
| `gen_roster.py` | 读 JSON，直接生成同样版式的 xlsx |
| `templates/2026-11.json` | 11 月输入模板（5 周，把「待定」换成真实内容即可） |
| `templates/2026-12.json` | 12 月输入模板（4 周，示范跨月周期写法） |
| `../公益群:共修群运营值班表-2026-11-模板.xlsx` | 11 月空表，用来确认版式 |
| `../公益群:共修群运营值班表-2026-12-模板.xlsx` | 12 月空表，用来确认版式 |

**生成命令：**

```bash
cd "C社群工作台/值班表工作流"
python3 gen_roster.py templates/2026-11.json --out "../公益群:共修群运营值班表-2026-11.xlsx"
```

> 每月复制一份 `templates/2026-11.json` 改成 `2026-12.json`，改内容、改周期、改输出名，跑一次即可。
