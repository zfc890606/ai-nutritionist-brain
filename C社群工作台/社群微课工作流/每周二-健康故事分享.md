## 六段式图文讲稿框架

**整体格式：** 文字段落 + `[插入图片]` 标记，每段文字读完配一张图

---

### 第一段：接触营养的过程 + 改变图片

**目的：** 交代背景，引发"我也是"的共鸣

```
📝 文字写什么：
- 最初的状态（健康问题/困惑/不满意的生活状态）
- 怎么接触到营养/纽崔莱的（朋友介绍/偶然机会/自己搜索）
- 当时的心理活动（怀疑/好奇/试试看）
- 做的最初的改变是什么

🖼️ 配图位置：[建议插入：改变前的照片/刚接触营养时的记录]
```

---

### 第二段：做KOC的分享 + KOC改变图片

**目的：** 展示从受益者到分享者的转变

```
📝 文字写什么：
- 什么时候开始决定做KOC/分享
- 第一次分享的感受（紧张/兴奋）
- 收到的反馈（谁被你影响了）
- 自己在这个过程中的成长

🖼️ 配图位置：[建议插入：做KOC期间的照片/改变对比图]
```

---

### 第三段：影响其他朋友 + 对比图和截图

**目的：** 用他人的改变证明价值，增强说服力

```
📝 文字写什么：
- 影响的第一位朋友是谁，ta是什么情况
- ta的改变过程（简述）
- 后续影响了多少人（数字）
- 这种帮助别人的成就感

🖼️ 配图位置：[建议插入：朋友对比图/对话截图/感谢反馈]
```

---

### 第四段：学习考证转健康赛道 + 学习场景图片

**目的：** 展示专业度，建立信任

```
📝 文字写什么：
- 为什么决定系统学习（发现自己不够专业）
- 学了什么课程/考了什么证书
- 学习的过程（难不难/怎么坚持的）
- 拿到证书的那一刻的感受
- 转型做健康的决定

🖼️ 配图位置：[建议插入：学习场景照/证书/培训现场]
```

---

### 第五段：大健康的收获

**目的：** 升华，展示这份事业的全方位价值

```
📝 文字写什么：
- 身体健康上的收获
- 心态/认知上的成长
- 经济上的收获（不露数字，可以说改变）
- 圈子的变化（认识了什么人）
- 家庭的改变（家人态度/家庭氛围）
```

---

### 第六段：结语与感谢

**目的：** 收尾，给听众信心和行动方向

```
📝 文字写什么：
- 总结这一路走来的核心感悟（一句话金句）
- 感谢听众的时间
- 鼓励有同样想法的人行动起来
- 行动号召："想了解更多的私信我"
```

## 📊 PPT大纲格式

> 由六段式讲稿提炼而来，一段一个核心画面。每页包含「标题」「核心要点」「配图建议」，用 `---` 分隔页：

```markdown
第1页：封面
  标题：[故事主题]
  副标题：[一句话金句]
  主讲人：[嘉宾称呼/本群主理人]
  配图建议：[主题相关的温暖背景图]

---

第2页：目录
  ① 接触营养的过程
  ② 做KOC的分享
  ③ 影响其他朋友
  ④ 学习考证转健康赛道
  ⑤ 大健康的收获
  ⑥ 结语与感谢

---

第3页：接触营养的过程
  核心要点：
  · 最初的状态（一句话）
  · 怎么接触到的（一句话）
  · 做的第一个改变（一句话）
  配图建议：[改变前的照片/对比图]

---（以此类推，六段各一页）---

最后页：行动号召
  核心信息：一句话金句总结
  联系方式/私信引导：想了解更多的私信我
```

## 🎨 PPT 固定风格（不再出提示词 · 直接出片）

**固定风格：万病寻源版** —— 米白纸感底 `#F5F0E8` ＋ 玫红 `#FF3A8D` / 青 `#00D4E6` / 黄 `#FFD400` 信息块 ＋ 左上小标签＋大标题 ＋ 右下页码 ＋ 页脚出处小字；全场只 2–3 页反色（黑底金句 / 玫红警示）。

规范：[[C社群工作台/社群微课工作流/PPT风格规范-万病寻源版|PPT风格规范-万病寻源版]]（2026-10-30 定稿）

执行方式：

```python
from deck_style_wanbing import *
new_deck()
s = slide()                      # 米白页
head(s, "第一段 · 小标签", "这一页的大标题", 1)
band(s, "一句话结论压底", Inches(5.6))
s = slide(BLACK)                 # 反色页（全场 2–3 页）
save("主题-YYYY-MM-DD-期号.pptx")
```

故事分享类按「时间线 / 前后对比」排出，六段各一页，加封面、目录、结尾共 9–12 页；出片后跑边界自检，数据页补出处。

> 🚫 已停用：扁平变形人设、NotebookLM/Kael.im 风格提示词、黄底黑字·时尚杂志风——一律不再输出提示词，直接交付 .pptx。

## 推广文案模板

**第一条输出**就是推广文案，按此格式生成：

```
@所有人 
《我的健康我做主》
我的健康故事专栏

今天晚上将会请到我们本群优秀[嘉宾称呼]，与大家分享[主题内容]

1 [要点1]
2 [要点2]
3 [要点3]
4 [要点4]
………………
大家今晚20：00本群，敬请期待[嘉宾称呼]的分享哦[鼓掌][鼓掌][鼓掌]
```

**填入规则：**
- 嘉宾称呼：如"红利老师"、"李老师"，如果自己分享则写"本群主理人[你的名字]"
- 主题内容：一句话概括分享主题
- 要点：4-6个提纲，从分享内容中提取最吸引人的亮点
- 时间：统一为"今晚20：00"
- 表情：统一用 `[鼓掌][鼓掌][鼓掌]`
