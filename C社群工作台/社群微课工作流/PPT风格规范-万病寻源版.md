# 🎨 社群微课 PPT 固定风格 · 万病寻源版

> **一句话：** 米白纸感底 + 玫红/青/黄信息块 + 左上小标签＋大标题 + 右下页码 + 页脚出处小字。
> **状态：固定**——所有社群微课（周二故事分享 / 周五健康微课堂）PPT 默认且只走这一套，**不再询问风格**、不再出 NotebookLM 提示词、不再用黄底黑字版。

---

## 一、为什么固定这套

2026-10-30 张医生定：万病寻源那套版式的可读性和专业感更适合讲课场景——米白底不刺眼，色块分区让手机上看也清楚，页脚带出处显得严谨。旧版「黄底黑字·时尚杂志风」满屏高饱和，投屏久了累眼，信息密度也上不去。

---

## 二、六个不可改的骨架（每份 PPT 都要有）

| # | 元素 | 规格 |
|---|------|------|
| 1 | 底色 | 全篇 `#F5F0E8` 米白纸感 |
| 2 | 页头 | 左上角小标签（13pt 粗体 玫红）＋下方大标题（36–40pt 粗体黑） |
| 3 | 页码 | 右下角 `x / 总页数`（10pt 浅灰） |
| 4 | 结论条 | 每页底部一条整幅色块，压一句话结论 |
| 5 | 资料来源 | 数据页页脚固定一行小字写清出处（机构+年份） |
| 6 | 反色节制 | 全场只有 2–3 页反色（黑底金句 / 玫红警示），其余全部米白 |

## 四、页面类型库（按内容挑，不要每页一个样）

1. **封面** —— 顶部玫红细条 + 英文小标签 + 两行大字标题 + 玫红短粗条 + 副标题 + 右上角一个大色块数字（用你最有说服力的那个数） + 底部黑条写主讲人与时间。
2. **目录** —— 5 行隔行浅米块，左侧玫红序号 `01–05`，右侧浅箭头。
3. **问题页** —— 一句灰引子 + 一个大号玫红关键词 + 一个问句；底部黑条放受访者原话。
4. **三卡并列** —— 3 个整块色卡（玫红/青/黄），大数字在上、说明在下。
5. **条形归因页** —— 隔行浅米，左侧标签，横向色条按比例长度，条右端标百分比。
6. **左右对比页** —— 两张卡片，顶部各一条色带（红 vs 绿），左侧写"谁在做什么"，右侧同理。
7. **双卡编号页** —— `①②` 色块 + 标题 + 两行说明。
8. **双大卡页** —— 两张整色卡（玫红/青）讲两个并列概念。
9. **警示行页** —— 每行左端一条红色竖条，左标题、右解释。
10. **数据实证页** —— 两个浅米块，超大数字（78pt 级）+ 下方两行小字。
11. **结构图页** —— 上两个色块向下汇流，中间一个黑块写"工具+底座"，中间用黑色细线连接。
12. **反色金句页** —— 黑底白/黄大字，玫红短条分隔，底部浅灰注脚；或玫红满版。
13. **编号清单页** —— 隔行浅米，左侧玫红 `01–04`，中标题、右说明。
14. **三步页** —— 3 张卡片，顶部色带写"第一步/第二步/第三步"。
15. **结尾页** —— 黑底，两行结论（白+黄），玫红短条，一条玫红号召条，页脚免责小字。

## 五、怎么做（执行步骤 · 免询问）

```bash
cd "C社群工作台/社群微课工作流"
# 1. 复制引擎用法，写本期生成脚本 gen_XX_XX_deck.py
# 2. 跑脚本 → 输出 .pptx
# 3. open 打开
```

```python
from deck_style_wanbing import *

new_deck()
TOTAL = 19            # 按本期页数改

s = slide()                                   # 米白页
head(s, "第X部分 · 小标签", "这一页的大标题", 1)
band(s, "一句话结论压底", Inches(5.6))
note(s, "数据来源：《XXX报告（年份）》")

s = slide(BLACK)                              # 反色金句页
...
save("主题-YYYY-MM-DD-期号.pptx")
```

**写脚本时的三条硬要求：**

1. **先算字宽再定位**：中文按「字数 × 字号 ÷ 72 = 英寸」估宽度，英文按 0.55 折算，超出文本框就降字号或拆行——不要靠 PowerPoint 自动缩，导出会溢出。
2. **出片后跑边界自检**：遍历所有 shape，`left < 0` 或 `left+width > 13.333` 或 `top+height > 7.5` 一律报错重排。
3. **数据必须带出处**：每个用了数字的页面，页脚 `note()` 写清机构 + 年份；没有可靠出处的数字不用。

## 六、禁止清单

- ❌ 满屏高饱和黄底（旧版黄底黑字风格已停用）
- ❌ 每页换一套配色（整套只用上面四色 + 黑白灰）
- ❌ 超过 3 页反色（反色是用来"顿一下"的，不是常态）
- ❌ 数据页不写出处
- ❌ 中文用衬线宋体做大标题（这套版式用黑体，衬线会失去现代感）
- ❌ 输出 NotebookLM / Kael.im 风格提示词（已改为本地 python-pptx 直接出片）
