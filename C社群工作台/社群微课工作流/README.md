# 🎙️ 社群微课工作流

> **一句话：** 你给我主题和参考文件，我给你讲稿 + PPT 大纲 + 直接用本地技能生成好的 PPT。
>
> **适用场景：** 大健康社群日常运营，每周两场固定微课

---

| 时间 | 栏目 | 定位 | 对应文件 |
|------|------|------|---------|
| **每周五** | 🏥 **健康微课堂** | 知识干货型 — 讲一个健康话题，拆解知识，给解决方案 | [[C社群工作台/社群微课工作流/每周五-健康微课堂\|每周五-健康微课堂]] |
| **每周二** | 📖 **健康故事分享** | 案例见证型 — 讲一个真实故事，引发共鸣，带出方案 | [[C社群工作台/社群微课工作流/每周二-健康故事分享\|每周二-健康故事分享]] |

> **每次微课统一输出四样：** 📢 推广文案 + 🎙️ 完整讲稿 + 📊 PPT大纲 + 📑 直接渲染好的 PPT（.pptx）

## 🔄 通用工作流

```
你提供：
  ① 今天星期几 → 自动匹配对应工作流
  ② 主题内容
  ③ 参考文件（可选）

AI 执行：
  ① 读取指定/相关本地文件
  ② 必要时联网搜索补充
  ③ 按对应框架生成讲稿
  ④ 生成 PPT 大纲
  ⑤ 用 python-pptx 直接渲染 .pptx（[[C社群工作台/社群微课工作流/PPT风格规范-万病寻源版|PPT 固定风格·万病寻源版]] + `deck_style_wanbing.py`）→ 存工作流目录并打开
```

> ⚡ **直接执行不询问**：给主题 → 直接出全套（含生成 PPT），不用确认、不用等指示。

## 🎨 PPT 固定风格（2026-10-30 定 · 不再询问）

**所有社群微课 PPT 一律用「万病寻源版」风格**：米白纸感底 `#F5F0E8` ＋ 玫红 `#FF3A8D` / 青 `#00D4E6` / 黄 `#FFD400` 信息块 ＋ 左上小标签＋大标题 ＋ 右下页码 ＋ 页脚出处小字；全场只 2–3 页反色。

- 规范：[[C社群工作台/社群微课工作流/PPT风格规范-万病寻源版|PPT风格规范-万病寻源版]]
- 引擎：`deck_style_wanbing.py`（`from deck_style_wanbing import *` → `new_deck()` → 出页 → `save()`）
- 样板：`AI大健康赛道副业怎么做-万病寻源版-26-23期.pptx`（19 页）
- ❌ 已停用：黄底黑字·时尚杂志风（Yellow × Black Editorial）、NotebookLM 风格提示词输出

## 📐 交付命名规范（2026-10-16 定 · 张医生）

交到 `C社群工作台/社群微课工作流/` 的文件（讲稿 `.md` / PPT `.pptx`），文件名统一带 **日期 + 期号**：

```
《主题》-YYYY-MM-DD-期号.后缀
例：蛋白质-不同人群每天吃多少-2026-10-16-26-12期.pptx
   蛋白质-不同人群每天吃多少-讲稿-2026-10-16-26-12期.md
```
- 日期取当天（`date` 实取，不猜）
- 期号延续上期数字
- 讲稿文件在主题后加 `-讲稿`
