# 工作台插件 · 一键复刻提示词

> 用法：点下面代码块右上角的复制按钮，把整段发给对方的 AI 助手（Claude Code / Claudian / 任何能读写文件的工具），让它在自己的 Obsidian Vault 根目录执行。执行完完全退出 Obsidian 再打开即可。

你是 Obsidian 插件工程师。请在我的 Obsidian Vault 根目录里，从零创建并启用一个本地插件 zfc-workbench，做出「内容生产工作台」首页。最终效果：打开 Obsidian 自动进入工作台；页面顶部是题库横条，下面是六个流程卡片；点任意卡片弹出操作框；填一句主题点「开始操作」，标准指令自动填进 Claudian 输入框，但绝不自动发送。

全程只做新增：不删除、不移动、不改名任何已有笔记，不改写已有笔记正文。唯一允许修改的既有文件是 .obsidian/community-plugins.json 的插件启用列表。

function pickChatInput() {
  const scope = document.querySelector(".claudian-active-input-slot") || document;
  const selectors = ["textarea", '[contenteditable="true"]', ".cm-content", 'input[type="text"]'];
  for (const selector of selectors) {
    const candidates = Array.from(scope.querySelectorAll(selector)).filter((el) => {
      const rect = el.getBoundingClientRect();
      return rect.width > 0 && rect.height > 0;
    });
    if (candidates.length) return candidates[candidates.length - 1];
  }
  return null;
}

async openClaudian(prompt) {
  const plugins = this.app.plugins;
  const available = Boolean(plugins && plugins.plugins && plugins.plugins.realclaudian);
  if (available) {
    try { this.app.commands.executeCommandById("realclaudian:open-view"); } catch (error) {}
  }
  await new Promise((r) => setTimeout(r, available ? 800 : 100));
  if (!available) return false;
  const input = pickChatInput();
  if (!input) return false;
  input.focus();
  if (input.tagName === "TEXTAREA" || input.tagName === "INPUT") {
    const proto = input.tagName === "TEXTAREA" ? window.HTMLTextAreaElement.prototype : window.HTMLInputElement.prototype;
    const setter = Object.getOwnPropertyDescriptor(proto, "value").set;
    setter.call(input, prompt);
    input.dispatchEvent(new Event("input", { bubbles: true }));
    input.dispatchEvent(new Event("change", { bubbles: true }));
    return true;
  }
  if (input.isContentEditable) {
    try { document.execCommand("insertText", false, prompt); }
    catch (error) {
      input.textContent = prompt;
      input.dispatchEvent(new InputEvent("input", { bubbles: true, inputType: "insertText", data: prompt }));
    }
    return true;
  }
  return false;
}

注意：textarea 必须用原生 value setter，直接赋 value 会被框架忽略。绝不自动发送、绝不模拟回车。

5.7 生命周期与首页
onload 顺序：await this.loadSettings()；registerView(VIEW_TYPE, leaf => new WorkbenchView(leaf, this))；addRibbonIcon("layout-dashboard", "打开张医生工作台", ...)；addCommand({ id: "open-workbench", name: "打开张医生工作台", callback: ... })；addSettingTab；然后 this.layoutReady = false、this.reopening = false；app.workspace.onLayoutReady(() => { this.layoutReady = true; if (this.settings.openOnStartup) this.activateView(); })；再 registerEvent 监听 layout-change：当 layoutReady 为真、openOnStartup 为真且不在重开中，如果 getLeavesOfType(VIEW_TYPE) 为空，就置 reopening 为真并调用 activateView()，完成后 finally 复位。效果：工作台常驻，手动关掉会自动重开；只有关掉设置里的「启动时自动打开工作台」才会停止。
activateView：先 workspace.getLeavesOfType(VIEW_TYPE)[0]；没有就 workspace.getLeaf("tab") 再 await leaf.setViewState({ type: VIEW_TYPE, active: true })；最后 workspace.revealLeaf(leaf)。
onunload：this.app.workspace.detachLeavesOfType(VIEW_TYPE)。
loadSettings：Object.assign({ openOnStartup: true }, await this.loadData())；saveSettings 用 saveData。

先让用户完全退出 Obsidian（Cmd+Q），再修改 .obsidian/community-plugins.json，避免退出时被覆盖。

九、回退方法
1、设置里关闭「启动时自动打开工作台」。
2、从 community-plugins.json 移除 "zfc-workbench"。
3、删除 .obsidian/plugins/zfc-workbench 目录。
4、想恢复 Hearth，把 "hearth" 加回启用列表。

十、移植到别人的 Vault 只改这些
1、manifest.json 的 id、name、author 可改，但 id 必须和插件目录名、community-plugins.json 里的字符串完全一致。
2、MODULES 可增删；每个模块的 files 换成对方 Vault 的真实路径；build 里引用的规则文件名同步改。
3、LIBRARY_LINKS 换成对方的选题库。
4、对方没有 Claudian 也能用，会自动降级为复制到剪贴板。
5、对方 Vault 没有对应规则文件时，不要编造流程：把 files 指向真实存在的笔记或留空，并在最后列出缺失路径让对方补。
